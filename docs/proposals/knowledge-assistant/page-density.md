# 知识库页面的信息密度调整

状态：2026-10-31，按用户本轮反馈已实施；验证见[页面迭代记录](../../records/knowledge-library.md#页面密度迭代)。基于现有[文本入库契约](../../reference/knowledge.md)，只调整页面组织，不改变后端检索或资料归属。

## 目标与取舍

1. 库列表改为文件夹式响应网格，宽屏一排多个，窄屏自然单列。名称、两行以内用途、文档数和更新时间用于定位；隐藏切片数和每库重复的“可检索”。空库单独提示等待添加。
2. 库内先展示文档列表。上传按需展开，格式限制、演示导入与队列留在操作区；完整用途按需阅读，不用长说明占据首屏。保留上传重试、请求标识及未完成上传的离开保护。
3. 保留库内 BM25 检索测试。向量/混合检索实验不等同于正式页面接入；向量计算需要 Embedding 模型，但相似度查找和融合可不调用聊天模型。本轮不扩大到模型部署。

## 验收

在同一桌面视口比较首条文档位置，核对一排多个库；检查320px、390px和中等宽度。库名/用途长文本、空库、无匹配、上传区开合与失败重试均可用；库内检索及来源深链保持原行为。结果合入[实施记录](../../records/knowledge-library.md)，生效组织回写页面模块说明。
