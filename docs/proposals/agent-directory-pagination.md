# 员工目录顶部分页

日期：2026-10-31。范围：员工目录的查询工具栏与分页；状态：已实施，验证见[验收记录](../records/agent-directory-pagination.md)。

搜索与岗位筛选在工具栏左侧，分页在右侧；移除列表底部旧分页。使用 shadcn/ui 的 Pagination 组合，保留项目 Button/Base UI、日夜令牌与焦点规则，前后页仅显示 Lucide 箭头，提供中文可访问名称；页码可直接跳转，长页数使用省略号，窄容器只显示当前页和两侧箭头。

沿用已有 AgentStore 和管理/公开列表接口，不增加后端 API。每页 20 位，翻页只更新 URL offset，保留关键词、分类、状态和技能；分页总数使用当前条件响应的 total。搜索或筛选重置第一页，加载期间禁用分页，保留已确认卡片；末页失效继续回到最后有效页。

验证覆盖首尾、直接跳页、保留条件、加载禁用、空结果、失效末页与窄屏/主题。真实目录不足两页时，跨页行为使用隔离接口替身验证并说明限制，不向用户库写入演示员工。当前规则见[员工模块](../../frontend/src/pages/agents/README.md)及[设计系统](../../frontend/src/design-system/components.md#列表分页)。
