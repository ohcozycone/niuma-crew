# 常见问题与排查

本文面向平台使用者和部署者。先按现象核对当前配置及执行记录，再进入对应指南；配置保存、连接检查和实际工作成功是不同结果。

## 员工无法开始对话

1. 确认以管理员或普通成员身份登录；游客仅可浏览。
2. 在员工目录确认员工已启用并选择可用大脑。技能不是开始聊天的必要条件。
3. 管理员检查模型标识与凭据，再用直接文字请求验证实际生成。连接检查只验证模型目录访问。

配置流程见[配置一名可以工作的员工](../product/workflows.md#配置一名可以工作的员工)，身份规则见[身份与权限](../reference/auth.md)。

## 模型连接检查成功，但对话失败

检查连接与实际生成调用不同的上游能力。核对本次执行提示、模型标识、账号额度、上游可用性和网络；修改配置后提交新的请求。密钥只在管理入口配置，不放进消息或公开截图。

模型配置与真实调用边界见[模型连接](../reference/model-connections.md)。

## 工具服务能连接，员工却无法使用

按「服务可用 → 账号有效 → 工具清单已确认 → 员工具有具体许可 → 使用者绑定相容连接」逐项核对。个人账号方式不会借用其他人的连接，技能中的文字也不能授予工具权限。

完整操作见[接入工具并绑定使用账号](../product/workflows.md#接入工具并绑定使用账号)。沙箱和可信本机程序的部署要求见[基础工具接入](agent-tools.md)。

## 上传了知识资料，但回答没有引用

1. 确认资料已完成手动处理，原件暂存不代表已进入检索。
2. 在库内测试关键词或已有向量索引的检索，确认能找到对应内容。
3. 在员工的「我的知识库」中装配本人资料库，核对检索方式。
4. 查看实际执行中的检索和来源动作。按需模式不保证每次都调用检索；无命中和技术失败需分别处理。

操作和限制见[知识资料与员工问答](../product/workflows.md#管理知识资料并核对来源)、[知识库契约](../reference/knowledge.md)。

## 关闭页面后，工作是否停止

关闭页面或断开网络只会停止观察，后台可能继续工作。重新打开对话读取已保存进度；需要结束处理时使用明确的停止操作。已经发生的外部操作不会自动撤销。

发送超时、结果未知时先核对原请求；符合条件的失败、取消或中断回复才使用重试。具体行为见[停止、断线与重试](../product/workflows.md#停止断线与重试)。

## 员工说文件已生成，但无法下载

核对正式回复是否提供文件入口，以及执行记录是否确认交付。沙箱临时路径和模型文字不是可下载成果；文件需要保存到平台、关联到消息，并通过当前用户访问检查。

完整过程见[从附件到成果文件](../product/workflows.md#从附件到成果文件)。

## 本地服务启动失败

检查终端中的首个失败原因：依赖安装、数据库迁移、3000 端口占用、配置缺失或已有后端持有运行锁。统一启动器不会自动迁移数据库、创建管理员或结束其他服务。按[本地开发指南](local-development.md)逐项恢复；数据与密钥维护见[后端操作](backend-operations.md)。
