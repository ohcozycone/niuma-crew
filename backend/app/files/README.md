# 持久文件与引用

文件模块保存用户材料、运行取得的来源以及生成的成果，让它们在页面刷新或沙箱回收后仍可按稳定标识读取。字节保存成功后返回文件引用；是否可以在某段对话中下载，由对话业务检查。

## 模块设计

### 文件引用怎样指向可靠字节

`StoredFile` 保存用户、来源运行、用途、名称、大小、摘要和内部存储键。文件名只是展示，客户端不能提交任意宿主路径。保存先检查单文件上限及剩余空间，把临时字节刷盘后原子改名，再在短事务中检查账号/运行总量并写入元数据。

先字节后引用使数据库不会公开一个尚未可靠保存的成果。反方向失败可能留下没有数据库记录的磁盘对象，因此需要后续清理，不能假定两个存储一起提交。读取按内部键打开，检查大小和摘要，避免引用正确却读到被替换的内容。

### 上传、输入与输出是不同关系

上传返回个人输入引用，发送时 `capture` 检查新输入归属，或确认文件已经在当前对话允许范围内，再固定本轮输入路径。运行获得来源材料或生成输出时，用注入的保存操作记录用途和来源 Run。

输出存在磁盘不代表已交付。对话发布核对运行、用户、用途和摘要后关联到回复，下载再检查当前对话访问权。这样未发布输出不会因知道文件 ID 就被下载，持久字节也不随临时环境销毁。

### 清理为何需要业务提供保留依据

文件服务知道年龄和存储事实，却不知道哪份材料仍被消息或动作引用。bootstrap 合并对话和知识模块的保留查询后注入清理过程；它保护消息附件、活动运行、实际来源/结果以及知识文档原件引用。服务按有界候选批次删除过期未保留元数据，再删除对应字节，并核对无元数据的孤立对象。

默认目录从数据库位置派生，也可显式配置。单文件、每次运行、每用户总量和磁盘余量分别约束不同风险；备份文件目录、数据库和密钥时保持各自角色清楚。

## 目录与职责

```text
files/
├── models.py                      # 记录稳定文件标识、用户/运行归属、用途、内容摘要和内部存储键，供引用和完整性核对
├── service.py                     # 处理元数据、配额和输入捕获，组合可靠字节存储并返回文件引用
├── storage.py                     # 原子写入本地字节并核对摘要，供元数据事务组合
├── cleanup.py                     # 按各模块注入的持有依据回收过期和孤立文件
├── schemas.py                     # 定义上传及授权列表返回的文件概要，让页面传引用而不是宿主存储路径
└── config.py                      # 集中定义目录、单文件/用户/运行限额和保留期，供保存与清理使用
```

## 与其他模块协作

API 实施有界上传；[conversations/files.py](../conversations/files.py) 管理列表/下载权限和保留关系，[acceptance.py](../conversations/acceptance.py) 建立正式附件关联。[execution/runtime](../execution/runtime/README.md) 通过注入接口读写，[environments](../environments/README.md) 只提供临时工作副本。

本模块依赖数据库与受控本地文件系统。共享技能资产由 skills 独立保存，不使用个人文件保留策略。

知识模块拥有文档原件关联和本人下载规则，其保留查询与对话查询在启动装配中合并，文件服务不反向依赖任一业务模型。

## 维护入口

端到端过程见[附件到成果](../../../docs/product/workflows.md#从附件到成果文件)，权限、API 和上限见[工具与文件契约](../../../docs/reference/agent-tools.md)。[基础工具测试](../../tests/test_agent_foundations.py)覆盖保存、完整性、配额、关联与清理；备份与实际磁盘容量仍按部署环境核对。

Run 在正式业务接纳之前也持有执行输入及成果文件。执行所属查询与对话、知识所属查询由 bootstrap 组合，清理代码不反向查询业务表；checkpoint 删除不解除成果持有。

## 执行证据文件

`evidence` 是私有诊断用途，与 input/source/output 分开；不进入普通附件、来源列表或模型文件选择。prepare 先写字节，register 使用调用方事务登记，以便与动作引用一起提交。证据单独计量，动作持有引用参与原清理查询；下载由执行查询在业务授权后提供。见[契约](../../../docs/reference/execution-evidence.md)。
