## 问题与决策

旧实现的普通页面上限为 1450px，对话单独限制为 840px，工具和个人连接页又使用不同宽度；侧栏在不同视口间使用 232 / 210px，卡片和配置列数经常依据视口而非实际内容空间。现有 1450px 没有可追溯的研究或行业标准依据。

本次从组件内容、状态和操作预算推导页面空间，再迁入正式组件。具体取值、可行区间、取舍与官方参考仅在现行布局规范维护；不在方案复制另一套目标表。宽工作区与文字行长各自约束，避免扩大对话后把普通回复排成长行。

## 实施归属

| 层级       | 已接入内容                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------------- |
| 设计来源   | theme.css 维护几何令牌和公共布局工具类，spec.ts 只登记分类与用途                                    |
| 外壳与页面 | 共享侧栏占位；PageContainer 与水平 frame 管理公共上限和可用区留白；整页加载、错误和权限状态共用宿主 |
| 资源与配置 | 员工、能力、复杂连接按类型自动填列；员工构图响应卡片容器；主辅、字段与文件编辑按区块预算重排        |
| 对话       | 滚动适配器只管理滚动；页面拥有消息、输入与反馈宽度；对话常态居中限宽、宽屏逐档扩展；导航保持原样    |
| 基础组合   | Dialog 尺寸角色与视口约束、关闭命中区、菜单避碰、Tabs 与分页重排、粗指针控件                        |
| 独立页面   | 帮助正文、资产局部缩放、规范目录、登录品牌场景按任务模式处理；样板消费正式组件                      |
| 文档与展示 | 组件分类和源码清单、设计推导与响应式矩阵；/design-system#layout 展示实际计算值与同源字段样例        |

未改变身份授权、数据库、保存、提交、模型调用、历史读取等业务契约。组件内容与原有操作保持原职责，页面没有新增平行的配置或对话实现。

## 验收与维护

正式页面使用隔离只读样例完成布局检查，源码回归检查原有交互契约。已完成的检查、发现及修正、证据和限制只在实施验收维护，早期几何原型继续作为设计证据，不能替代真实组件测试。

后续组件信息、操作数量或密度目标变化时，先修改组件预算，再计算列数和分栏阈值；更新同源样例与相关验证。没有遗留的独立页面宽度迁移批次。Safari / Firefox、真实移动软键盘和外部服务的端到端验证不由本次只读浏览器检查推定为通过。
