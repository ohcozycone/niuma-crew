# 工具按需发现验收

2026-11-09，当前工作区的 builtin_tools、工具发现和组织资源执行接线。本文记录专项结果；真实业务库迁移、正式部署及最终全项目检查由统筹任务另行验收。当前规则见[运行契约](../reference/runtime.md#工具发现与实际可见范围)，职责和实施范围见[设计方案](../proposals/执行与Agent能力架构设计.md)。

## 实现与控制边界

文件、知识、结果读取和发现入口位于 builtin_tools；文件操作继续使用官方中间件。MCP 反馈转换位于 agent/mcp_tools，各构造入口绑定异步 normalizer；通用工具门消费统一 ToolOutcome，不再解释 platform_outcome、builtin_outcome 或命令退出码。

发现仅搜索受理时捕获的已授权目录。模型实际可见集合、当前选中 MCP 绑定复核、预算和模型动作登记同事务完成。工具调用检查父动作及该次请求的真实曝光；并行发现采用官方集合 reducer，新轮用 Overwrite 清空。结果先保存，再返回 Command；没有生产全量工具回退。

本轮快照为 8，线程标识从同一版本常量生成。旧个人资源线程不载入新图；经过原归属校验后，新轮显式重置工作上下文，页面历史保留。历史知识捕获显式传入受信 owner/thread，知识来源资格仍由知识服务复核。

## 关键词检索：真实目录，人工查询

夹具来自本机组织资源切换前已确认目录：Tavily 5 项、Notion 77 项，共 82 项。仅保存原始工具名称、描述和参数结构，不包含账号、凭据、知识正文或用户对话。目录与查询分别固定在[目录夹具](../../backend/tests/fixtures/tool-discovery-catalog.json)和[查询夹具](../../backend/tests/fixtures/tool-discovery-queries.json)。

首轮纯 BM25 在 23 条人工英文关键词上命中 22 条，创建页面漏召回。最终使用通用的操作名多词匹配优先、BM25 排序，并采用 FTS5 英文 Porter 词项处理，23 条查询的 top5 全部包含预期工具。没有供应商专用同义词、自动描述翻译、额外模型回合或全量回退。

同一批需求直接以中文检索，命中为 0/23。这是词项检索的限制，不能将人工英文查询的结果表述成中文语义召回通过；真实模型改写另行验证。参数描述提取有深度、节点和文字上限，覆盖布尔、组合、嵌套与本地定义，不读取远端引用。

用户明确授权本次向已有 Kimi 连接发送测试需求和已确认工具元数据。凭据仅用于既有模型连接认证，没有写入材料或工具参数；未发送知识正文和用户历史对话。使用临时数据库副本读取配置，使用官方 Agent 引擎、新发现中间件及独立 checkpoint；外部 MCP 执行由验收宿主全部拦截，只记录选中的操作和参数，不访问真实业务资源。

## 回归与限制

专项测试覆盖：同批搜索猜名拒绝、发现后撤权阻止下一模型请求、并行发现合并后超上下文不发请求、结果保存失败不生成 Command、缓存重建状态、控制字段不可覆盖、新轮清空发现、旧线程重置、候选数量/字节与模型预算分离，以及现有文件、多模态、结果分页、取消与恢复。

运行相关定向回归曾有 254 项通过，剩余旧权限夹具由统筹修正；后续对话、考核、独立执行、stdio 和结果读取的消费链路 99 项通过。需要本机端口与子进程的两组恢复测试在允许环境中执行，18 项通过；受限环境的 PermissionError 不作为代码失败修正。各命令覆盖有重叠，不合并成测试总量。类型检查覆盖配置中的 48 个入口，通过；执行展示的 4 个测试文件、16 项测试及前端类型检查通过。最终全项目结果见[组织员工资产改造验收](组织员工资产改造验收.md)。

真实 MCP 协议业务调用、GLM 等其他模型、真实 Linux 沙箱、资源回收和正式业务库切换不在本次真实模型探针范围。最终合流验证结果以统筹记录为准。
