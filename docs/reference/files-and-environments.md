# 文件、工作区与执行环境

附件、获准工作区、临时沙箱和正式交付物分别管理。上传不授予读取或命令权限；持久成果不以沙箱中的临时路径交付。

## Agent 基础能力

启用工具的运行直接获得 Deep Agents 官方 `FilesystemMiddleware` 文件工具：`ls`、`read_file`、`glob`、`grep`、`write_file`、`edit_file`、`delete`。名称、描述和参数 Schema 从安装版本的官方定义读取，不在插件目录重复维护。员工不用创建原生连接或逐项授予基础文件操作；禁用工具的运行不附带这些能力。

没有可用沙箱时，工作区采用官方 `StateBackend` 的虚拟文件状态。沙箱配置与目标主机验收匹配时，受理固定本轮沙箱后端并增加官方 `execute`。这是本地配置就绪判断，不是远端实时健康检查；已接受的沙箱运行遇到远端故障会明确失败，不切回虚拟或宿主 Shell。

正式迁移 `0026` 停用旧 `native` 连接和相关员工许可，保留原 ID、定义及历史引用，并更新受影响员工修订。能力库只管理 Skill 和 MCP；新建原生连接或重新装配旧工作区会被拒绝。旧运行快照不按新权限自动恢复，当前使用快照版本 8。

## 工具范围与网络

基础文件读取限定 `/inputs`、`/sources`、`/skills`、`/workspace`、`/outputs`；写入和删除限定 `/workspace`、`/outputs`。输入由本次显式选择固定，资料只能来自本 Run，技能只能读取冻结清单，不能读取后端主机或其他用户的目录。

`execute` 只在沙箱后端提供。Shell 能接触的系统路径由隔离环境和运行身份控制，不能用文件工具的参数检查代替。Agent 和模型凭据留在宿主，沙箱作为工具环境使用；平台负责输入投递、预算、产物收集和资源释放。

模型指引依据本轮真实工具生成，说明环境、目录和实际返回；服务方说明只指导对应 MCP 操作，不定义员工身份或通用回答风格。搜索摘要与页面正文分开处理，不在结果层按供应商私有字段推断网页内容。

外部工具采用 `mode=provider`：管理员负责受限上游身份，平台检查批准的参数 Schema 和明确配置的参数约束（maximum/maxItems/maxLength/enum），空对象不作为授权。通用链路不按工具名修改参数，不将 `url`、`urls` 自动视为网页参数，也不施加三 URL 上限。非空 `allowed_domains` 因没有通用且可靠的参数映射，在保存与执行时明确拒绝；旧配置须改为明确的参数约束或上游受限账号，不能静默丢弃范围。MCP 服务如何解析业务 URL、DNS 和重定向由该服务的能力契约负责，不能与平台到 MCP 的传输保护混同。

MCP 管理地址支持 HTTP(S)，不维护部署域名或私网主机白名单；允许回环、内网及代理 DNS 映射，地址不能包含用户名、密码、查询参数或片段。传输固定本次解析的地址并保留原域名的 TLS 校验，拒绝链路本地（含常见云元数据地址）、多播和未指定地址；业务请求不能切换配置的协议、主机或端口；OAuth 发现、注册和续期按每个协议目标分别校验，不转发 MCP Bearer，详见 [OAuth 生命周期](mcp.md#oauth-账号生命周期)。不跟随重定向或环境代理，不支持由 schema 触发外部引用读取。响应以 identity 编码有界接收，目录另有限额。该接入方式允许访问后端可达的本机和内网服务，不提供内网访问隔离。

## 文件与交付

| 区域          | 当前含义                                                     |
| ------------- | ------------------------------------------------------------ |
| `/skills/`    | 本轮冻结的技能，只读；完整正文成功读取后才激活               |
| `/sources/`   | 本轮已保存工具结果和资料的只读投影，不推断供应商私有网页字段 |
| `/inputs/`    | 用户上传或从当前对话显式选择的文件，只读                     |
| `/workspace/` | 本 Run 的临时脚本和中间文件                                  |
| `/outputs/`   | 本轮待正式保存和发布的文件                                   |

普通文件与技能共用一套官方 `read_file`。平台适配器保留完整虚拟路径，完整技能正文成功读取才记录激活；普通读取不激活技能。文件和命令在一个 Run 内串行并原子记账，MCP 可以并行。

虚拟可写文件使用官方状态，单文件上限 128 KiB、工作区总量 512 KiB。输入同样按虚拟模式限制检查。沙箱模式从首次真实工作区操作起使用一份环境，读写文件与命令共享字节；技能和来源通过只读投影供模型阅读，并在命令执行前投递原始支持文件与来源字节。

超出根目录报 `file_path_denied`，未获准技能文件报 `skill_not_allowed`，范围内不存在的文件（包括下一轮已失效的长结果路径）按官方工具错误返回供模型处理；撤权、来源绑定不匹配和内容完整性错误仍阻断。可写路径仍不能覆盖只读输入。MCP 原始返回完整保存，中小结果完整提供模型，大结果通过官方预览及只读路径按需读取；`read_tool_result` 保留旧字符游标兼容。读取复核来源当前许可，不能访问其他运行的资料。详见[运行契约](runtime.md#外部读取证据与长结果)。

虚拟工作区发生首次写入、编辑或删除前，动作事务将本轮标记为禁止自动恢复，避免动作记录与框架文件状态分开提交造成重放或丢失。纯聊天和只读运行仍按可信存档恢复；沙箱或外部工具运行不自动重放。

上传使用有界原始字节，仍检查 Origin、登录身份和配额。选择输入时固定文件 ID、哈希、归属和路径；清单送入模型，原始大文件不塞入对话正文。首批验收 CSV、JSON、UTF-8 文本；二进制和大文件由沙箱程序处理。

文件字节先落入受控持久目录并校验，再提交元数据；输出先取回并保存，然后在发布事务内关联助手消息、正文和 Run 终态。下载必须通过当前对话权限及文件关联检查，使用 attachment/octet-stream，不返回宿主或沙箱地址。取消、失败和未发布的临时输出不能作为成功文件下载。

元数据存在但物理文件缺失时返回 `file_content_missing`，明确提示重新上传或恢复存储；不能把缺失伪装为空文件。知识分片失败保留已发布片段与索引，原件恢复后需重新提交任务。

文件上限来自 `FileConfig` 和部署配置。当前缺省为单文件 10 MiB、每 Run 保存总量 40 MiB、每用户持久文件 256 MiB；保留存储空间余量。未引用输入、失败暂存和孤立字节按保留期清理；已发布关联、活动 Run 和已记录来源保留。文件服务通过注入的引用查询决定清理资格，不反向驱动对话业务。

## 沙箱与命令

来源阅读投影会拆分超长行并限制单次读取字节；下载和沙箱程序使用原始字节，不将阅读表示当作结构化文件。

沙箱生命周期由 `environments` 维护，文件/命令框架协议装配归 `agent`，实际命令、运行身份、真实路径检查和输出字节收集归 `environments/open_sandbox.py`，最终文件归 `files`。管理操作不作为模型工具，管理密钥不进入工作负载。使用固定 digest/image ID、UID/GID 1000、只读 root 所有的输入目录及独占工作区；没有宿主 Shell 回退。

OpenSandbox 创建前先保存资源申请，成功后保存远端身份、归属与期限。创建结果未知时按请求 metadata 查询并保留资源债务，禁止盲建或恢复旧环境。命令时限最高 60 秒；日志、传输、文件、进程、CPU、内存、磁盘及网络各有独立约束。命令退出码未知不当成功；非零退出码在步骤中显示失败，模型可继续解释失败或采取另一项获准操作。

成功前停止工作负载并收集输出；所有退出路径都尝试销毁。销毁失败保留资源与失败次数，周期和启动清理继续重试，TTL 作为补偿；已可靠发布的文件不因回收失败消失。未知创建没有可确认的远端 ID 时保守占用容量，过期后可按指南人工核对。清理不依赖发起人的会话继续有效。

代码能力须配置目标 Linux 主机的当前验收依据；缺失、过期或不匹配时未就绪，其他能力仍可用。验收文件是受信部署者在主机上的观测依据，不是模型给出的证明；更改服务或隔离配置后必须重新验收。

## 官方复用与生命周期取舍

文件工具和参数复用 [Deep Agents 内置工具](https://docs.langchain.com/oss/python/deepagents/tools#built-in-harness-tools)，虚拟状态使用 [StateBackend](https://docs.langchain.com/oss/python/deepagents/backends)。真实文件操作复用官方目录列出的社区 OpenSandbox 适配器；平台只补运行身份、路径、资源限制和交付边界，社区适配器不等于 LangChain 维护的沙箱服务。

集成采用 [sandbox-as-tool](https://docs.langchain.com/oss/python/deepagents/sandboxes#sandbox-as-tool-pattern)：Agent 在宿主，工具在隔离环境执行。官方允许按线程、任务等范围管理沙箱；本平台选择每 Run 独占、延迟创建、结束销毁，以减少保活和跨轮恢复状态。它不是官方默认线程复用策略。对话继续保留正式消息、摘要与已发布文件，临时工作区不跨 Run 继承。
