# 会话 SDK 与执行过程展示验收

日期：2026-10-24。范围：现有 Run / RunStep 上的会话 SDK、首次原子交办、只读请求核对、消息与执行摘要、官方 shadcn/ui 接入。当前规则见[对话契约](../reference/conversations.md)、[运行契约](../reference/runtime.md)，模块用法见[对话模块](../../frontend/src/pages/conversations/README.md)。

## 实施结果

useConversation 局部管理消息、Run、提交与 SSE，公开四种 status 及发送、停止、重试、重连操作。未知提交保留不可变命令与幂等键；刷新只读核对，明确重试才重新提交。失败重试复用原用户消息，保留原助手消息和新尝试。停止失败不伪造已取消，重连读取不丢失仍在等待的命令确认。

新草稿在页面先分配 UUID；首次发送在同一业务事务建立 Conversation 与 Run。摘要增加真实步骤数、步骤版本、运行时间及当前实际动作，不需要业务迁移或数据库重置。SDK 不读取路由、认证或当前员工，不引入 Zustand。输入局部管理，历史消息保留引用，订阅不随文字片段重建，Markdown 和旧步骤行独立更新。

旧 AI Elements 包装层已移除。官方 Base UI registry 的 Message、Bubble、Trace、Collapsible、Input Group 与 Message Scroller 接入现有语义令牌；Streamdown 单独负责 Markdown。源码版本与许可见[第三方说明](../../frontend/THIRD_PARTY_NOTICES.md)。执行过程默认折叠，有真实记录才显示；可查看模型轮次、供应商返回的 reasoning、工具及技能加载，最终正文独立放在下方。本轮没有增加 commentary 或额外模型调用。
