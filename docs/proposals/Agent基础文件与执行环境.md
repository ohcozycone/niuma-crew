## 剩余验收

当前机器没有运行中的 Docker/OpenSandbox，也没有服务地址、密钥、镜像及主机验收依据。需要部署者准备 Linux OpenSandbox，固定工作负载镜像并按[接入指南](../guides/agent-tools.md#验收并启用代码执行)完成目标主机隔离检查。

随后验证一次真实任务：输入 CSV，模型写脚本并调用 execute，生成可下载成果，确认任务结束后远端环境销毁；再检查取消、命令超时和回收失败后的清理。未取得这些结果前，保持虚拟文件模式，不开放 execute，也不伪造主机验收文件。

沙箱跨轮保活、长期工作区和其他执行提供方不在本次实施范围。前期继续采用每 Run 独占、按需创建、结束销毁，通过正式成果衔接下一轮。
