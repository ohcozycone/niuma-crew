# 当前数字员工角色

2026-10-21，正式数字形象采用同系列十三角色彩色 SVG，替换旧黑白系列。头像选择器、员工卡片、导航、配置与对话统一使用同一注册表；主工程仅维护静态头像。母版及制作事实见 [SVG 说明](../../../../docs/reference/avatar-assets.md)。

| 岗位 ID      | 角色       | 主要识别元素                                   |
| ------------ | ---------- | ---------------------------------------------- |
| `intern`     | 实习生牛   | 青绿圆领上衣、「实习」工牌、双手轻扣；通用默认 |
| `finance`    | 财务牛     | 眼镜、计算器与硬币                             |
| `admin`      | 行政牛     | 文件与行政道具                                 |
| `designer`   | 设计师牛   | 贝雷帽、画笔、色卡                             |
| `programmer` | 程序员马   | 稀疏头发、电脑                                 |
| `backend`    | 后端马     | 方框眼镜、靛蓝卫衣、深色机械键盘               |
| `frontend`   | 前端牛     | 珊瑚外套、奶油青绿拼色键盘                     |
| `product`    | 产品经理马 | 产品需求与思考表情                             |
| `sysadmin`   | 运维马     | 网线与接头                                     |
| `knowledge`  | 知识牛     | 厚书、书签与阅读眼镜                           |
| `research`   | 研究马     | 放大镜与图表夹板                               |
| `operations` | 运营牛     | 手机与提示符                                   |
| `support`    | 客服马     | 听筒与记录本                                   |

形体、配色、比例与细节以主工程 `frontend/public/avatars/svg/` 的正式 SVG 为准；可编辑母版保存在独立归档。这里的描述不替代母版，也不声明动画活动件或绑定已经完成。旧黑白角色设定与当时的确认依据见内部历史记录。

新增四张原图与 SVG 对照均获用户认可后接入。「实习生牛」原图及无描边 SVG 均已认可，已计入十三角色并设为默认；普通日常上衣、佩戴「实习」工牌。后端马、前端牛原图与 SVG 对照均已认可，已按同哈希母版接入。
