# 对话页右侧辅助栏

设计状态：已采纳。实施状态：已实施。更新日期：2026-11-01。现行规则见[对话契约](../reference/conversations.md#前端交互)，实际验证见[验收记录](../records/conversation-sidebar.md)。

## 目标与范围

按已确认原型，将对话页组织为左侧正文与输入、右侧默认展开的辅助栏。右栏提供历史对话和员工能力两个标签，可收起与重新展开，不加入任务入口。

## 实施增量

1. 复用现有会话作用域、正文滚动及历史列表，历史使用服务端分页；切换会话不停止后台运行。
2. 能力读取真实员工技能、获准工具与当前使用者的个人知识库。挂载资源与本轮实际使用分开表达；知识库设置复用现有编辑器。
3. 宽工作区主辅并排，辅助栏独立滚动；窄工作区上下排列且限制辅助栏高度，保留输入空间。新进入对话默认展开。
4. 辅助栏读取失败局部重试，不阻塞正文；沿用既有权限与个人资料隔离，不新增执行、配置或任务协议。
5. 视觉修订保留上述布局和功能：员工身份在右栏顶部统一展示，历史采用无表格外框的轻量列表，能力按真实资源分组；右栏以留白和柔和表面区分主辅，附件操作收进输入框。

## 验收

检查默认展开、收起与焦点恢复、标签键盘操作、历史选择与分页、真实资源空态与失败恢复，以及日夜主题和桌面、390/320px 排版；执行前端静态、相关测试、构建及文档检查。
