# MCP 统一接入与标准 Skill 目录实施验收

日期：2026-10-29。范围：用户确认的统一 MCP 表单/快捷导入、连接测试，以及标准 Skill 目录、别名与同步。本记录以当前工作树、隔离数据库测试和真实浏览器检查为依据；不把官方 SDK 支持等同于本平台支持。

## 落地与职责

- MCP 页面保留同一张表单，`McpQuickImport` 弹窗接受 JSON/文件，解析后回填；多项选择、覆盖确认、密码暂存及取消清理分开处理。`McpSetupAccess` 将凭据放在同页，主按钮保存定义、账号并测试连接，部分失败保留已创建资源和重试入口。
- 继续使用现有 MCPAdapter/客户端与受控网络，不增加厂商适配器或新的网络服务。受限 `mcpServers` 支持 `type`；Registry 描述支持 Streamable HTTP 和固定 npm 版本，持久保存非秘密输入说明/必填/秘密属性。模板、额外启动参数、多 HTTP 认证头、SSE、OAuth 等明确不支持；不猜测任意 URL 的认证字段。
- `skills/library.py` 拥有标准目录读写、文件锁与暂存替换；`skills/service.py` 拥有平台定义、发布与同步。首次验收时默认数据库目录下 `.agents/skills`，随后按下方修订改为 `~/.agents/skills/`，可用 `SKILL_LIBRARY_DIR` 配置；现有不可变字节用于 Run 快照，两种目录不可相同。
- 创建/上传/正文编辑写回标准目录，目录同步新增或更新同一技能 ID，保留别名、参数、分类、启停和员工关系。标准名与目录名一致；显示别名可选，清空恢复原名，卡片有别名时保留原名。
- 外部修改阻止页面直接覆盖；同步未变不重复建记录或增加修订；源缺失保留已发布内容。旧数据首次同步导出关联；同名内容冲突报错。仅管理员扫描配置根目录，拒绝链接、特殊文件和越界/超限包，不运行脚本或安装依赖，不自动装配员工。
- 最终自查将删除时的目录关联读取移到文件锁内，避免首次物化并发留下可重新同步的孤立目录；异常回滚仍恢复文件。断电/强制终止可能留下暂存，当前未引入文件系统与数据库的跨存储事务日志，运行继续依赖已发布清单。

实现入口：[技能目录](../../backend/app/skills/library.py)、[技能服务](../../backend/app/skills/service.py)、[MCP 描述解析](../../backend/app/tools/definitions.py)、[接入页](../../frontend/src/pages/tools/ToolsPage.tsx)、[目录同步界面](../../frontend/src/pages/skills/SkillLibrarySync.tsx)。

## 浏览器与本机数据

独立临时后端/前端使用 8021/3003 和临时数据库、虚构管理员及本机 FastMCP 替身，不向正式能力库写入测试服务/技能。浏览器实际走通：目录同步新增一份含脚本的技能；Registry JSON 回填；保存访问设置、协议握手、发现两个工具及首次确认。可选 Authorization 字段实际生成可选密码框。日夜主题、390 像素表单和 320 像素弹窗已检查，320 像素下 document scrollWidth 与 viewport 同为 320。截图保存在本机临时产物中。

临时服务使用独立测试 Cookie，避免与其他 localhost 页面会话冲突；此隔离仅在验证脚本，不修改产品认证。Chrome 验证入口未响应后改用内置浏览器完成检查，没有操作用户当前页面。浏览器选择本地 JSON 文件未单独验收，粘贴解析、格式约束及回填有交互测试。

业务库升级前使用 SQLite backup 保存到 `backend/.data/backups/before-skill-library-20261029-160012.db`，完整性检查通过。升级后保留 3 位员工、0 份技能、2 条账号连接、2 个 MCP 服务，外键检查无错误；未替换个人 Key、未变更员工许可。正式后端健康检查通过。可编辑目录首次同步按需创建，不在数据库迁移阶段扫描或执行文件。

真实第三方 Key、新 MCP 的云端调用、腾讯云文件权限和实际 CLI 安装工具未新增验收；命令行安装兼容的是指定目录里的标准文件，不能声称任意安装器的默认目标都相同。当前不支持跟随外部符号链接。OAuth、跨机器同步、自动依赖安装、文件 watcher 和新沙箱框架均不在此次范围。

## 用户级默认目录修订

2026-10-29，用户要求与命令行安装目录对齐。核对 [Agent Skills 格式规范](https://agentskills.io/specification)和[官方扫描指南](https://agentskills.io/client-implementation/adding-skills-support#where-to-scan)：格式不强制根目录，指南推荐项目级和用户级 `.agents/skills/`。平台默认改为运行后端用户的 `~/.agents/skills/`，显式 `SKILL_LIBRARY_DIR` 仍优先。旧的数据库同级目录不自动合并；本机旧目录实际无技能包，无需迁移文件。未扫描、同步或修改本机用户目录中的技能。
