# 当前运行、步骤与读取

本页维护已实施的执行契约。当前用户通过对话应用提交工作；Run 负责一次工作的受理、执行和成果保存。字段由[公开读取结构](../../backend/app/conversations/schemas.py)、[内部记录](../../backend/app/execution/models.py)和迁移维护。

## 接受、快照与幂等

接受在一个短事务中保存对话、用户输入、空助手 Message、Run、冻结输入和绑定。client_request_id 的唯一范围是发起用户和操作；同键同摘要返回原记录的当前读取结果，不同内容返回冲突。重放先于当前容量和配置检查。

接受时固定岗位、规则、方法内容、装配身份、模型修订、输入上下文和预算；启动与动作前仍复核当前会话、员工启停、模型装配/修订、已激活方法和本次资源。固定内容不意味着权限也固定。

员工固定配置由 execution/snapshot 捕获，RunTask 创建真实客户端和受限资源。execution/service 提供应用事务内的受理、取消和完成；对话应用组织当前输入、已接纳执行标识及业务关联，再调用内部受理操作。执行可复用不等于直接开放客户端创建 Run，当前没有独立任务 HTTP 提交入口。RunWorker 只提交执行事实，不调用对话发布来完成 Run。

## 运行观察与结果持有

对外提交、读取、停止、重试、SSE 和成果下载统一由对话应用提供，见[对话契约](conversations.md)。执行模块不提供独立 HTTP 路由或另一套 RunRead 投影。应用通过内部受理和取消操作参与自己的事务；执行宿主通过 complete 保存成果与终态。

公开 Python 操作也接收可信 Actor 并检查 runs 能力和记录归属，不能绕过 HTTP 授权。当前后台继续沿用发起会话及资源许可复核策略；本次不擅自引入服务身份、离线委托或改变登出语义。

Run 的 result_text/result_data 是执行成果，Message 是应用接纳后的正式回复。执行输入和成果文件引用随 Run 保留，应用接纳前也不被文件清理误删；删除 SDK checkpoint 不影响成果。当前不提供 Run 自动过期或删除接口，持有随相应 Run 存在，不以 HTTP 回包送达为成功条件。

对话回复增加 acceptance（pending/accepted/failed）及 acceptance_error，表达应用处理，不是另一份执行状态机。接纳暂时失败只重试同一份成果。正常续接只选择成功且已接纳、接纳无错误的 Run；模型上下文从该执行的 SDK 存档读取。前端在 pending 时继续订阅，显示执行已完成、正在保存回复；不把接纳失败显示成 Agent 失败。

## 调度与并发计数

一次被接受的输入建立一条 Run；幂等重放、打开对话和观察连接不新增 Run。不同用户或不同对话使用同一位员工时，各自的输入、历史、资源依据和成果属于各自 Run。累计工作数量与当前同时执行数量分别计算。

全平台不再设置 Run 同时执行数量上限。[RunWorker](../../backend/app/execution/runtime/worker.py) 在服务就绪时调度已接受 queued 记录，并用在途任务表防止同一 Run 重复启动。队列容量、单用户未结束容量、同一对话只接受一份活动工作、动作预算、时限和资源许可仍分别生效；取消总量门槛不扩大任何资源权限。

原 `RuntimeConfig.concurrency / RUN_CONCURRENCY` 已移除或不再读取。当前配置入口见[运行配置](../../backend/app/execution/config.py)；已确认的文件职责与方法协作见运行管理标准。

## checkpoint、历史与恢复

页面历史只读取业务 Message，不访问 SDK。连续对话的每次输入仍创建独立 Run，但共用稳定 Thread。正常追问仅新增当前问题，从最近成功且已接纳 Run 的明确 checkpoint 接续 SDK 消息、完整配对工具消息、官方技能 pin 消息与摘要。新 Run 单独初始化文件、技能发现缓存和用量；恢复同一 Run 则不重置这些工作。失败或取消分支不作为后续起点；没有基点时只使用当前输入；选定基点却线程不符或没有存档时明确拒绝，不从 Message 回填。

同一 Run 重启恢复时，按线程和 app_run_id 查找属于本轮的最新可信 checkpoint，保留冻结输入、开始时间、已用预算、已激活动作与累计未知用量。页面历史不是执行恢复的替代品。知识内容或授权范围改变时保守重置执行记忆，正式历史仍保留。单纯增加可用技能或工具保留普通记忆；移除或修改已存在的技能/工具及关键配置时重置。

可信且待继续的普通 Agent 存档可继续；可信完成标记且 Run 仍活动时只补执行成果保存，不再调用模型。缺失、不兼容或不支持恢复的存档不自动重放，收束为 interrupted。已终止 Run 不因存档有完整文字而改写。

SDK 提交与业务提交分开：SDK 内部完成只是恢复依据，Run 成功以执行成果及终态事务为准，应用接纳另行提交。未完成模型请求可能重发并重复计费，未报告的用量保持未知。当前不提供多主机租约或通用外部副作用重放保证。

## 实际 SDK 与预算

普通 Agent 使用 LangChain、Deep Agents 文件工具与 SQLite checkpoint；原生/MCP 工具、文件与沙箱已接入，范围、预算、来源和部署条件见[基础工具契约](agent-tools.md)。仅支持快照版本 5，不适配旧 v2/v3/v4 数据；原生写入、沙箱和首版外部工具 Run 不在重启后自动重放。

模型次数、方法读取次数、上下文字节、可见正文/思考字节、输出 token、总时限和图步数各自受限。图步数不等于模型次数。模型动作开始前，在同一写事务复核许可、扣减次数并保存动作；失败时不发出外部调用。

## 官方记忆、摘要和用量

连续线程通过官方 SQLite Saver 保存。平台提供数据库路径和 Run 归属回调，不复制框架存档格式。SummarizationMiddleware 按估算消息 token 阈值生成摘要并保留近期消息；当前阈值默认 16384，保留 4096，可用 RUN_SUMMARY_TRIGGER_TOKENS、RUN_SUMMARY_KEEP_TOKENS 配置。保留预算必须小于触发预算，配置在接受时冻结。

摘要使用官方选择、保留和状态更新算法，模型调用经现有动作门执行，计入本 Run 的模型次数、总时限和实际用量。摘要调用失败或预算不足按运行失败处理，不能把内部摘要作为正式回复。摘要缩短上下文，不压缩历史 checkpoint 数据库，也不删页面消息；极大单条消息、工具定义及系统指令仍可能触发已有上下文字节限制。

实际 token 读取标准 usage_metadata，已知值用官方 add_usage 累加；中断和未报告项保留未知。官方 ModelCallLimitMiddleware 负责单次图调用的次数防线，平台动作账本负责跨重启的尝试、原子预占与资源授权，两者口径不同。未额外启用 ToolCallLimitMiddleware 叠加第二套同义预算；所有实际工具仍走现有持久动作门。当前不是用户余额/金额扣费系统，未启用通用自动重试。

## 本轮允许与实际使用

接受时捕获可用方法，显式选择可预加载，其他按需读取。装配重建即使复用相同 ID 也通过 created_at/revision 被识别。已激活方法集合从成功动作恢复；授权检查合并既往与本次申请，发布前重读持久动作。

一次模型的工具请求只是意图。工具实际开始、成功返回及方法激活分别记录；失败或未知结果不冒充已经加载。

Agent 创建时声明 AgentRuntimeContext，每次调用及恢复通过官方 context 参数传入本轮 host 与 run_id。工具中间件读取 ToolCallRequest.runtime，核对所属 Run、工具注册和调用 ID；知识工具及结果读取工具使用官方 ToolRuntime 注入。运行上下文不属于模型可填写的参数，也不进入持久消息状态或 checkpoint；恢复时由新建的本轮执行对象重新传入。

动态 MCP 保留远端参数 Schema，通过官方 request.override(tool=...) 为每次调用绑定独立执行函数，不修改共享工具实例，远端名为 runtime 的业务字段仍作为普通参数传递。调用 ID 仅用于关联；实际许可仍由平台在授权、预算和动作记录的同一事务中申请，缓存复用也先复核授权。单次许可和调用信息留在本次调用栈中，结果保存成功后才返回模型；同步知识读取取消时仍等待所属线程退出，再由 Task 收尾。

本轮重新核验的知识证据、预检索结果、输入文件清单及记忆重置说明，通过官方模型中间件临时补充，补充消息不写回 checkpoint，用户原文不变。历史知识引用的清洗只作用于临时视图中的基点消息，不改本轮新证据、用户输入或持久消息，也保留结构化内容块。最终模型权限、体积和预算检查包含补充资料。保留旧消息不扩大旧结果编号的读取范围。

## 外部读取证据与长结果

MCP 返回的原始结果持久保存。模型收到有界预览、`result_id` 和字符游标，可用派生的 `read_tool_result` 继续读取本轮结果；不必为了读取刚返回的数据另装文件工具。该入口只接受本 Run 的结果编号，保留来源工具的绑定并在每次读取前复核当前许可，不能读取另一轮、附件或任意宿主路径。读取独立记账并共享 Run 总预算，不重新执行外部业务操作。源文件路径的 `read_file` 授权仍单独检查。

对于明确“读取/提取/阅读”并带目标 URL 的输入，发布前核对成功的结构化提取来源以及模型收到的结果范围。零调用、错误目标、仅搜索摘要或长结果尚未读完时，以 `external_read_unverified` 准确失败，不发布“已经读取”的候选回答；普通 URL 格式讨论不触发此规则。此首版识别是保守的明确请求规则，不是任意任务的自然语言验收器；支持常见 `results[].raw_content` 及 Tavily Extract 的提取结构，其他格式需要补结果语义映射。超过预算的长页面应缩小范围，不能假装完整处理。

“取得提取文本”不保证网页内容完整、未被登录页替代或解释无误。`full_text` 不因非空文本而成立。页面分别展示提取文本与搜索摘要，实际调用和内容语义正确性分开验证。上述检查通过不能代替真实模型和外部服务行为评测。

## 流式回答与思考展示

SDK 片段在 execution/runtime/streaming 解析、拼接和识别工具轮；普通 ContentUpdate 跨过边界。RunTask 负责缓冲及看护保存频率，Store 只保存普通字段。

页面只观察已提交内容，不直接转发未持久化 token。完整响应覆盖暂存片段，结束后的迟到更新不能覆盖。思考按 UTF-8 字节截断并保留截断标记，恢复时仍占原预算。

助手视图 content 已由服务端选定：活动时为当前可见草稿，成功且已接纳时为 Message 的完整正文；成功但尚未接纳时可展示已保存执行成果，标记为 draft；其他终态为允许的部分正文或空串。前端不再选择模型轮，也不把工具正文当聊天回复。

## 前端与读取模型

首屏 snapshot 在真实 SQLite 读事务中组合当前摘要、员工安全摘要、连续消息页与提问摘要。接受、核对、历史、单回复与 SSE 共用助手视图。对话摘要的 version 来自 Conversation.revision，回复 version 组合 Run.revision 与对话接纳处理版本，接纳完成也会推进回复版本。

GET、停止和 SSE 的 ResponseSnapshot 同时返回当前对话摘要与回复。前端分别合并两个版本；晚到的旧回复或旧首屏不能回退活动目标。公开标识 response_id 就是助手 Message ID，没有新 Response 表。can_retry 同时考虑当前操作权限、回复状态及是否为末次尝试；前端不只按失败状态开放重试。

## 取消、故障与历史

排队停止可直接提交取消并释放占用；运行停止先记 cancelling，由看护关闭执行。显式停止精确指向回复，迟到请求不能停止下一次工作。SSE 断线只释放观察连接。

取消与完成竞争由运行公开操作在短写事务中裁定。Run 的完整正文、结构化成果和终态一起提交；对话另行保存正式回复、文件关联并释放业务占用。已经成功的 Run 不因应用拒收、接纳失败或迟到取消而改变。普通故障只保留执行器明确给出的允许片段，不能兜底取最后工具轮。撤权不增加可见正文。

执行成果或过程存储失败时停止后续动作并使宿主降级，存储恢复后按 persistence_unavailable 收束；重启补成果仅适用于仍活动且完成存档可信的 Run。对话接纳失败不降级执行宿主，不重跑模型；应用扫描持久关联恢复处理，暂时错误按指数退避重试，最长间隔 60 秒，明确权限/资源拒绝记录为接纳失败。

## CI 与后续知识能力

CI 对话诊断试验已退役，专用执行、报告/反馈及配置入口移除；本次重建不再保留旧消息、Run 或运行时兼容分支。新普通消息、通用 MCP 与 GitHub 登录继续使用各自入口，见退役说明。

独立业务 Task、Goal、多引擎和业务工作流引擎尚未实现；内部 RunTask 只执行一次 Run，不代表新增业务任务实体。不能从当前目录或 SDK 能力推断这些业务能力已开放。未来新增业务来源定义自己的输入与结果接纳，复用既有执行公开接口。

## 模块时序调度

页面 → 对话 router → ConversationService → RunService.submit → queued；消息和关联随同一事务保存。

RunWorker → RunTask → SDK Agent（请求与 AgentContext）→ RunService.complete → 唤醒 ConversationAcceptance 独立接纳。原子动作由 RunStore 保存；接纳仍有持久扫描补漏与退避。

页面 → snapshot/历史/回复/SSE → 同一查询实现读取已保存状态。实现入口见[后端架构](../architecture/backend.md)。

MCP OAuth 的正常续期只更新内部存储修订，保持本轮固定身份；重连、断开或明确授权失效推进凭证修订，旧动作依据不能继续使用。缺少授权时仍可普通聊天，实际工具请求返回连接账号提示；运行中不自动弹出授权、重新注册或重放业务调用。账号生命周期见 [MCP 契约](mcp.md#oauth-账号生命周期)。

## 执行证据

独立执行详情复用既有 Run/RunAction 与业务关联。每次真实模型请求、SDK 响应及工具申请/反馈可按私有文件引用查询；不改变提交、恢复、接纳或考核评分。详细[字段、权限、保存和故障语义](execution-evidence.md)。
