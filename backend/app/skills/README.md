# 共享技能、标准包与发布内容

技能是一套可以反复使用的方法主文和支持文件。例如「会议行动项整理」说明如何识别负责人、期限和待确认事项。管理员创建、导入或同步技能，再由员工选择并填写非秘密参数；实际读取文件或调用外部服务仍需要独立工具许可。

## 模块设计

### 一份技能怎样成为可执行内容

在线编辑、标准 ZIP 导入和旧表单记录都落到同一份 Skill。`service.py` 组织用户操作及版本检查，`packages.py` 校验主文和文件，`definitions.py` 把标准源文或旧字段解释成统一方法定义。员工和执行准备都读取这个定义，不各自拼接一套正文。

标准包主文为 `SKILL.md`，协议名用于标准目录与发现，平台展示名/别名用于界面。分类、启停和参数规范是平台字段。旧记录保留 ID、字段与员工关系，读取时编译成主文；保存标准源文后，不再允许旧指令字段单独覆盖它。

### 三种存储如何保持一致

| 位置           | 保存内容                                     | 谁读取、为何存在                                           |
| -------------- | -------------------------------------------- | ---------------------------------------------------------- |
| 可编辑来源目录 | 人或 CLI 可编辑的标准目录                    | 管理同步及导入/正文编辑使用，便于外部工具互通。            |
| 数据库         | 当前主文、展示属性、参数规范、版本和文件清单 | 管理/目录/员工读取，作为平台已发布定义。                   |
| 不可变字节存储 | 按摘要保存支持文件                           | 旧运行按接受时的文件依据读取，外部未同步修改不会改变执行。 |

发布先写并校验不可变字节，再在事务内替换主文和清单。编辑来源目录另用文件锁、完整暂存及目录替换；数据库失败时在锁内恢复旧目录。数据库与文件系统无法共同抵抗所有断电，强制结束留下的暂存须先备份并核对，不能直接称为跨存储原子提交。

来源目录由 `SKILL_LIBRARY_DIR` 配置，默认后端系统用户的 `~/.agents/skills/`；运行字节在 `SKILL_STORAGE_DIR`，默认数据库旁的 `skill-assets`。目录只在管理员显式同步后发布，启动/普通刷新不扫描。同步逐包校验：未变跳过、源缺失保留已发布内容、冲突不覆盖；旧记录可首次导出并关联，已有别名、分类、参数及员工关系保留。已关联目录的协议名不直接改名。

### 标准包验证与编辑冲突

ZIP 接受一个技能根：根 `SKILL.md` 或唯一一层与协议名相同的目录。压缩包最多 12 MiB，展开 20 MiB/128 文件，单文件 10 MiB；主文和可在线编辑文本最多 128 KiB。拒绝越界路径、大小写冲突、链接/特殊文件、加密包和异常压缩比；安全 YAML 保留扩展字段，拒绝重复键、循环引用、非有限值和超限元数据。

预览只解析，确认导入重新验证同一包，不运行脚本或安装依赖。读取只接受清单内路径，导出保留原始字节。保存携带预期修订，未变不增加版本，冲突保留客户端草稿；外部目录内容与已发布版本不同则要求先同步，防止页面覆盖外部修改。被员工使用的技能不能直接删，参数规范修改需预检启用关系。

### 从已发布定义到本轮方法

接受工作时固定完整主文、文件清单、摘要和关系参数；支持文件不塞进模型上下文或 JSON。运行层投影到 `/skills/s-<skill-id>/`，构造稳定名称和简介，并附本轮非秘密参数；模型按需加载或显式预加载方法，支持文件按固定清单与当前装配许可读取。

执行获准命令前，运行层将已激活方法投递到沙箱同一路径，支持文件原字节、目录 root 所有、文件 0444，命令以 UID 1000 运行。旧/孤立 blob 当前保留而非自动 GC，备份须包含数据库、可编辑目录与不可变存储，避免破坏旧运行依据。

## 目录与职责

```text
skills/
├── models.py                      # 保存共享技能当前主文、展示属性、参数规范、来源关联和文件清单，维持同一平台 ID
├── schemas.py                     # 定义整包保存、导入预览、支持文件读取与安全展示结构，区分可写定义和查询概要
├── service.py                     # 组织创建/编辑、预览/导入/导出和来源同步，检查身份、版本及员工引用后发布内容
├── packages.py                    # 解析与校验 ZIP/YAML/路径，编译旧主文，计算文件清单并读写按摘要保存的不可变字节
├── library.py                     # 扫描和读取配置来源目录，实施文件锁、暂存替换及外部修改核对，保持可编辑源与发布过程一致
├── definitions.py                 # 统一解释标准主文与旧记录，给员工和执行返回含内容摘要的同一种方法定义
├── parameters.py                  # 校验参数规范及每名员工的非秘密参数，不从自然语言主文推导业务字段
├── contracts.py                   # 约定执行要携带的技能及支持文件字段，使快照、加载和资源读取共享同一内容依据
└── config.py                      # 区分可编辑技能来源目录与不可变运行存储目录，供部署和服务共同使用
```

## 与其他模块协作

[employees](../employees/README.md) 保存选择关系和参数，[conversations](../conversations/README.md) 固定本轮定义，[execution/runtime](../execution/runtime/README.md) 负责发现、加载、实际激活及文件/沙箱投递。格式与内容由本模块解释，调用许可归员工及运行宿主。

技能是共享资产，生命周期不同于个人附件，不套用 files 的暂存 TTL。用户管理入口检查 Actor 和管理能力；已授权运行读取 blob 不要求使用者拥有技能编辑权。标准 `allowed-tools` 只是源包字段，不授予平台权限。
