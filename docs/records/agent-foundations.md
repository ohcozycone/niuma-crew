# Agent 基础能力实施与验证

日期：2026-10-27。适用：本地本轮实现，迁移 `0006`，快照版本 3；保留 v2 普通聊天兼容。本记录区分代码实现、离线验证和真实服务条件，不把文档或替身当作部署成功。

## 复审后的调整

1. 保留对话、执行宿主和 Agent 循环，新增 tools/files/sandboxes 三个资源模块。员工许可仍归 agents，文件可见性/消息引用归 conversations；SDK 与 ORM 不进入彼此不应依赖的边界。
2. 网络目录复查纳入记账后的工具尝试；撤权在真正调用前再复核。原始输入/输出 schema 和 SDK 元数据共同参与摘要，变化产生待审核候选。
3. 文件路由保留完整虚拟路径，避免 CompositeBackend 前缀剥离破坏已有技能键；显式声明 Deep Agents 官方文件状态，因为 SDK 不会自动识别自定义路由内的 StateBackend。
4. 同一 Run 的原生文件/命令串行，防止并行工具批次竞争同一工作副本。快照保存沙箱执行配置；原生写入、沙箱和首版外部工具 Run 不在重启后自动重放。
5. OpenSandbox SDK 与拟部署服务统一选 `1.1.1`，保留第三方 Deep Agents 适配包 `0.1.2` 并补 UID、日志/传输限制、输出与生命周期接线；声明兼容和实际目标主机验收分开。

## 验证与证据

后端完整离线回归 489 项通过，包含旧进程恢复和迁移测试。新增专项覆盖真实 LangChain/Deep Agents 循环、实际 FastMCP HTTP 协议适配、真实 SQLite、文件闭环、预算回滚、目录等待期间撤权、DNS 固定/TLS 名称、未知创建晚到回收、沙箱命令到文件收集/销毁顺序，以及已发布文件保留。沙箱上游在这些检查中为明确替身，不运行宿主命令冒充隔离执行。

完整 `make check` 通过。前端 325 项测试通过，覆盖连接发现与批准分离、加载失败禁止空授权、上传后只传文件引用、超限上传前拒绝。开发启动器另有 28 项通过。Ruff、Python 格式与类型、ESLint、TypeScript、Prettier、文档本地引用及生产构建均通过；LangChain MCP beta 提示和构建的大块提示仍存在。

使用独立临时数据库和管理员在真实浏览器验收：创建原生文件工作区、显示七项原生工具、保存员工 read_file 许可并刷新验证、日间/夜间可读性与工具指南入口。启动核验发现生产路由白名单遗漏 `/tools`，已修复并增加直接访问及员工参数路由测试。本轮浏览器视觉核验限桌面尺寸。

当前开发库在确认没有活动 Run 后，先通过 SQLite backup API 保存到 `~/.niuma-crew/data/backups/before-agent-tools-20261027T091939Z-b9c4ad6c.db`，再由正式迁移升级到 `0006`；外键检查零错误，`alembic check` 无新增升级操作。现有开发服务 `/health` 返回 200，OpenAPI 已加载工具连接、文件及沙箱状态接口。临时验收实例不使用当前开发账号、真实模型或搜索凭证，核验后已停止。

实际网络尝试访问 Tavily 的未认证 MCP 入口，没有提交密钥或发起搜索。本机 DNS 返回非公网地址，受控传输按规则拒绝；这不能作为真实服务已联通的证据。默认 HTTPS 端口与 SNI 路由另由确定性传输测试验证。
