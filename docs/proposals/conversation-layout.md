# 对话布局与历史读取增量

设计状态：已采纳。实施状态：布局、问题目录、双向定位、可见问答组高亮及正文/导航边界收拢已实现。生效规则见[对话契约](../reference/conversations.md#前端交互)，实际验证见[验收记录](../records/conversation-layout.md)。更新日期：2026-10-31。

范围是对话空间、员工入口和历史浏览，不涉及模型协议。基于已完成的 [会话状态重构](conversation-state-management.md)，增加只读目录、目标窗口和双向游标；不增加工作面板。

## 目标与职责

1. 去掉独立会话顶部栏，姓名、标题、历史切换和新对话合入共享顶部导航。角色在每条助手回复的名称旁展示，移除输入框角色及留白。默认输入收为两行，随内容增长到上限后内部滚动；仅输入组显示焦点边界。回到最新使用输入框上方居中的下箭头。
2. 员工卡片进入该员工最近更新的可见对话；没有记录时打开新对话。显式“新对话”始终打开空白草稿。读取失败明确重试，不将错误当作无历史。
3. 当前员工历史在按需打开的对话框中切换，全局历史页保留；共用列表呈现，按最近更新时间倒序、服务端分页，不把所有历史常驻页面。
4. 消息先显示最新一页并定位底部。滚到顶部时自动读取更早页，保留按钮与失败重试；以消息 ID 去重，向前插入不改变当前可见消息。流式回答仅在跟随最新位置时推动滚动，离开底部后提供“回到最新”。

滚动复用 shadcn 的 `@shadcn/react/message-scroller`，由 UI 适配层维护主题；页面负责分页触发、游标、请求锁、取消和错误。官方能力说明：[Message Scroller](https://ui.shadcn.com/docs/components/base/message-scroller)、[无样式接口](https://ui.shadcn.com/docs/react/message-scroller)。自动请求历史不是该组件的数据能力。

## 问题目录与跨页定位增量

目录从原始 Run 的不可变输入读取 ID、顺序、摘要和时间，重试不增加问题；服务端分页，支持搜索，沿用 conversations:read 和资源范围。正文查询先在业务消息引用上定位并截取有界窗口，再读取该窗口的公开 checkpoint，不遍历中间所有正文，不新增消息表或调用模型。

消息接口增加互斥的 after_sequence、around_message_id，与原 before_sequence 共存；响应同时给出前后游标。目标窗口包含目标提问及其附近回答。前端保留最新窗口和正在阅读的连续历史窗口；跳转成功后切换，不能将不连续窗口拼接。历史阅读不受新回复拉动，回到最新或发送后恢复最新窗口。双向加载去重并保持锚点；连续跳转最后一次意图生效，失败保留原窗口，离页和发送中止历史读取。

消息右侧只保留刻度条；最初的悬停问题列表已由下方“刻度直接定位与问答预览”增量取代。刻度只渲染当前位置附近的有界窗口，用平移过渡和边缘渐隐表达前后移动，减少动态效果时取消过渡。问题数量超过元信息首屏时，通过轻量 anchor_message_id 查询准确轮次，不读取中间正文。导航依赖稳定问题 ID，目标未挂载时先加载，渲染后再滚动并高亮。

## 失败与验收

### 刻度直接定位与问答预览

设计已采纳（2026-10-25），已实现：移除悬停后再选择问题列表的步骤。每根可见刻度对应一个真实问题，悬停或键盘聚焦显示问题与回答摘要，点击／Enter 直接定位；触屏点击直接定位。共享一张预览卡片，在刻度间平滑换位，摘要轻微上滑进入，不移动正文阅读位置。

刻度步长从 16px 收为 10px，线厚从 2px 收为 1px，最长刻度从 20px 收为 16px。继续只渲染当前位置附近及少量缓冲，正文滚动时用稳定轮次 key 滑动；长历史的轻量锚点与邻域摘要预取保留。未知问题 ID 的刻度在元信息到达前不可定位，不推测 ID。

初版问答预览通过 around 消息接口读取小窗口并保存有界短文本缓存，现已由下方“导航数据边界与显示数量”的专用预览接口取代。预览始终不提交任务、不替换阅读窗口；离开／切换目标取消读取，迟到数据不得覆盖新预览；失败显示预览暂不可用，点击仍可走正常定位。没有新增收藏等写入能力。

验证直接点击、悬停只预览、键盘、切换／迟到／失败、长历史有界渲染与动画；点击后的刻度换位不会在静止指针下重新打开预览，实际视觉与检查结果见[布局记录](../records/conversation-layout.md#刻度直接定位与问答预览)。

### 刻度独立滚动

设计已采纳（2026-10-25），已实现：刻度允许滚轮／触控板、触屏拖动及方向键／PageUp／PageDown／Home／End 独立翻阅，滚动不改变正文，边界处不将滚动传给正文。点击问题后恢复跟随正文；正文主动滚动至另一问题时也恢复跟随。保持当前细线、局部渲染、稳定 key 与平移过渡。

问题接口增加可选 start_number，从全局问题轮次定位元信息页，与 after_sequence 互斥，权限与总数语义保持原契约；不能用消息序号估算问题轮次，因为重试会插入额外输出。独立窗口按需预取附近摘要、缓存有界，快速滚动取消旧读取并忽略迟到响应；不全量加载目录或正文。跨元信息页、首尾、正文隔离、触屏拖动不误点击、键盘及失败重试的实际结果见[独立滚动验收](../records/conversation-layout.md#刻度独立滚动)。

### 导航数据边界与显示数量

设计已采纳（2026-10-25），已实现：不足三次用户提问隐藏导航，计数使用问题接口的全局 total，助手回复、重试输出和本地已加载条数不参与计数；第三次提问接受后刷新目录并显示。

导航的数据读取、取消、分页缓存与显示规则归私有业务 Hook，刻度和预览卡片只负责展示与交互；会话接入组件只连接滚动锚点、数据源接口和定位回调。数据源可注入，不将页面 DOM、具体 HTTP 或 Provider 写入展示组件。

新增按 question_id 读取预览的只读接口，返回该问题最新一次 Run 的公开回答短文本及 run_id、输出消息 ID、revision、status。不再通过附近八条消息的相邻关系猜配问答，也不下载执行步骤。每次打开预览重新读取最新执行，不维护跨悬停的回答副本；取消旧请求并拒绝迟到响应。问题摘要仍按稳定 ID 有界缓存，切换会话释放状态。实际分层见[导航数据流](../../frontend/src/pages/conversations/README.md#导航数据流)，验证见[验收记录](../records/conversation-layout.md#导航数量与数据边界)。

分页失败保留当前消息和游标，显式重试；切换对话取消迟到请求。验证首屏最新位置、前插锚点、加载锁、失败恢复、显式新建与默认接续、移动端与日夜主题，以及输入焦点和发送按钮不重叠。实际结果进入 records，生效规则合入 [对话契约](../reference/conversations.md)。

## 可见问答组与点击锚点

设计已采纳（2026-10-31），已实现：将唯一当前问题改为可见问答组集合，解决同屏多轮只能选一项、末轮未抵达顶部无法进入高亮的问题；主动点击仍以提问为定位锚点。可见性、重试归组与交互规则已合入[对话契约](../reference/conversations.md#前端交互)，实现协作见[模块入口](../../frontend/src/pages/conversations/README.md#问题导航与消息窗口)。

保留刻度局部窗口、独立翻阅与既有读取接口，消息滚动器的自动跟随和顶部留白保持原行为。组件测试覆盖可见交集、重试、历史窗口与点击目标；浏览器验证同屏多轮、长回复、末轮和历史跳转，实际范围与限制见[验收记录](../records/conversation-layout.md#可见问答组与点击锚点)。

## 正文阅读与导航接入边界

设计已采纳（2026-10-31），已实现：新增正文组件作为页面的消息区域入口，集中节点、可见范围和定位职责；导航改为消费问题 ID 与定位控制。移除独立可见性扫描文件和菜单自身的定位失败副本，保留现有读取接口、滚动器、分页与交互行为。

明确的登记与四类导航输入使正文结构调整留在正文适配层，目录与预览继续独立管理读取。生效规则见[对话契约](../reference/conversations.md#前端交互)，最小接入与生命周期见[模块入口](../../frontend/src/pages/conversations/README.md#问题导航与消息窗口)，节点替换、历史前插、错误隔离及浏览器结果见[边界验收](../records/conversation-layout.md#正文与导航接入边界)。

## 用户消息气泡与定位反馈微调

设计已采纳（2026-10-25），已实现：用户消息气泡采用不对称轮廓：右上角收尖，左侧保持圆润，右下角采用更舒展的圆弧。问题目录定位继续按稳定消息 ID 滚动和聚焦；取消消息整行灰底，仅让目标气泡的原有底色轻微加深后恢复，不增加外圈、光晕或其他装饰。重复选择同一问题重新播放，消息行和布局不变；系统减少动态效果时不播放动画。生效规则见[对话契约](../reference/conversations.md#前端交互)，实际验证与未覆盖项见[布局记录](../records/conversation-layout.md#气泡尖角与底色反馈修正)。

## 收藏员工快捷导航增量

设计已采纳（2026-10-24），本节增量已实现。生效规则见[员工头像导航](../../frontend/src/design-system/components.md#员工头像导航)，实际结果见[收藏导航验收](../records/conversation-layout.md#收藏员工对话与编辑入口验收)。收藏入口的主操作从编辑改为接续对话，右侧复用员工卡片的 `Settings2` 编辑图标。游客继续进入公开详情。

- 提取正式侧栏与设计样板共用的收藏行，主链接接收对话地址，编辑链接接收正式配置地址；保留来源及已有未保存保护。对话继续使用 `resume=1`，加载失败、无历史和不可发送状态由已有对话页处理。
- 主链接与编辑链接是兄弟节点，外层不处理点击、不嵌套可交互元素。右侧操作区始终预留，主链接不覆盖编辑区；细分隔线和无跳转留白明确边界。
- hover 或键盘焦点进入该行时立即显示编辑入口，不改变布局或点击范围，不使用淡入造成透明可点击状态。编辑按钮使用 36px 点击区、16px 图标和独立焦点轮廓；按钮悬停保持透明，显示「编辑员工配置」提示。触屏入口常驻并使用 40px 点击区。
- 验证两种导航、边界点击、跨区域按下／松开、快速移入点击、键盘顺序和提示，以及触屏、日夜主题、长姓名、低高度侧栏和游客入口。实际结果进入既有对话布局记录。

## 对话页面包屑与侧栏归属

设计已采纳（2026-10-25），本节增量已实现。生效规则见[页面层级](../../frontend/src/design-system/components.md#页面层级与列表摘要)，实际结果见[面包屑验收](../records/conversation-layout.md#对话页面包屑与侧栏归属)。进入对话详情或新对话时，侧栏选中「数字员工」；独立对话记录列表继续选中「对话记录」，不按来源改变选中态。

共享顶部栏按「数字员工 › 员工名　问题图标 + 会话问题」呈现，复用现有员工名与会话标题数据，不新增请求。父级链接返回员工目录，来源为员工目录时保留筛选和分页；来自历史等其他页面时返回员工目录根页。历史切换、新对话、全局搜索和主题操作继续可用。

抽取共享面包屑展示供外壳和对话标题插槽复用。长员工名与问题各自省略并提供完整文字；窄于 640px 时操作区换到第二行，面包屑与问题保持相邻。验证直接打开、员工入口、历史入口、刷新及前进后退、空白草稿、长文本、日夜主题、触屏和键盘，不改变会话创建、发送或订阅流程。

## 切页亮度与收藏背景修正

设计已采纳（2026-10-25），本节增量已实现，验证见[切页闪动核对](../records/conversation-layout.md#切页闪动与收藏焦点背景核对)。移除共享正文在每次路径切换时从 0.65 透明度、3px 位移开始的入场动画；保留当前按路径隔离页面状态的行为，不混入数据读取与表单生命周期重构。

收藏员工仅在 hover 时显示行背景，不由鼠标或键盘焦点保留灰底；键盘焦点轮廓、编辑入口与提示仍可用，不增加员工选中状态。

用受控只读请求对比修正前后的渲染帧、外壳节点和文档请求，验证无主动淡入、收藏移出后无灰底且键盘可达。目标页加载占位、接续对话的中间跳转与顶栏加载期间的替换仍是独立问题，未在本节中声称解决；导航元数据和数据加载边界的结构调整另行评估。
