# 日间、夜间与跟随系统

本文维护当前行为或操作，历史结果按记录索引查阅；未执行的目标能力不属于本页已实现范围。

## 主题契约

登录、工作台、帮助、设计展示与 body 浮层共享主题。用户偏好为 `light`、`dark`、`system`，实际主题为 `light` 或 `dark`；未设置或无效偏好跟随系统，媒体查询不可用时回退日间。浏览器 `localStorage` 的 `niuma:theme` 保存偏好，与身份无关，不随登录退出清除，不承诺跨设备同步。

[`theme.css`](../../frontend/src/design-system/theme.css) 是视觉数值来源，采用基础值 → 语义用途 → 必要组件映射，完整颜色接口在设计系统维护。日间为暖白资源卡片与浅暖灰工作区，夜间为暖炭灰与米白，搭配陶橙强调和灰绿状态；表单也沿用同源灰阶。布局、字号、间距、圆角与动画尺度两主题共享；普通组件使用同一语义类，由根主题切换其值。头像固有颜色保留，品牌文字、背板、表面、阴影与浮层使用各自语义映射。对比度与状态配对见[颜色规范](../../frontend/src/design-system/colors.md)，初轮覆盖与恢复方法见暖色主题验收，后续 Tab、菜单和圆角修正见视觉细节验收，最新日间表面见暖白卡片验收。

## 首屏与运行期

| 入口                                                                         | 职责                                                           |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------- |
| [`themeController.ts`](../../frontend/src/state/theme/themeController.ts)    | 偏好解析、根属性更新、持久化、系统／跨标签／历史缓存恢复与订阅 |
| [`useTheme.ts`](../../frontend/src/state/theme/useTheme.ts)                  | 通过 `useSyncExternalStore` 订阅同一控制器                     |
| [`build-theme.mjs`](../../frontend/scripts/build-theme.mjs)                  | Vite 在 HTML head 内联同源令牌 CSS 与控制器，早于 React 执行   |
| [`ThemeSwitcher.tsx`](../../frontend/src/components/theme/ThemeSwitcher.tsx) | 主题切换入口，菜单使用本地 Base UI 适配器                      |

控制器是页面级单例，首屏脚本与应用模块调用同一安装函数，重复安装不重复监听。根元素同步 `data-theme`、`data-theme-preference`、`.dark` 与 `color-scheme`；脚本不读取凭证、不发请求。首屏 CSS 包含两主题根声明，在应用样式和业务请求之前确定背景与文字颜色。

显式偏好优先于系统；只有 `system` 响应 `prefers-color-scheme`。同源其他标签页通过 `storage` 同步，清除偏好恢复系统；历史缓存恢复时重新读取存储。存储失败时本页继续切换，后续刷新按系统解析。主题订阅与业务数据加载互不依赖。

## 切换控件与品牌

工作台顶栏最右侧、登录顶栏、帮助与展示页复用主题控件。日月主体无外框、底色、投影或装饰横线；点击主体切换至相反主题并进入手动模式。小箭头沿日月水平中心线排列，展开日间、夜间、跟随系统三项单选菜单；系统模式在日月右下角显示 A，同时提供完整可访问名称和状态反馈。

菜单通过 Base UI Portal、定位与键盘机制实现，挂载到 body，继承根令牌；Escape、点击外部、选项选择与焦点恢复由库负责。触屏扩大点击区，图形位置保持一致。太阳／月亮交替升落遵循减少动态效果设置，不给全站颜色添加统一过渡。

登录场景以布局视口计算缩放与运行时 CSS 变量，主题控件保持与品牌场景相同几何比例。品牌图形、字形和眨眼时序保持一致，仅文字墨色随主题映射。品牌与头像素材颜色不参与普通 UI 色彩替换。

## 验收

1. 核对日夜语义键、引用完整性、无循环、对比度及已登记例外；颜色与共享尺度由唯一来源生成。
2. 覆盖保存偏好冷启动、系统变化、显式选择优先、跨标签、无效／不可用存储、重复安装与历史缓存恢复。
3. 检查登录、工作台、帮助、展示、body 浮层，以及日夜切换、键盘、焦点、触屏、减少动态效果。
4. 检查 320／390px、桌面与短屏，确认无横向溢出，菜单及登录操作可到达。
5. 执行对应控制器、首屏集成与令牌测试，并记录实际浏览器环境和未覆盖范围。当前工程验收证据统一见实施与验收；此前主题视觉证据保留于主题和控件归档。
