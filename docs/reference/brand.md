# 产品品牌与工程标识

本文维护当前产品身份与正式品牌入口；候选和迁移过程见历史记录。

## 范围与命名

产品展示名为 `NiumaCrew`，副标题为「数字员工平台」，最外层目录为 `niuma-crew/`。内部目录与组件按功能和通用工程规范命名，不随品牌增加前缀。仓库名称仅用于最外层目录与产品展示。后端 Python 包使用 `app`，前后端工程包名分别使用 `backend`、`frontend`；数据库、认证、事件和存储标识按功能命名，不绑定仓库名称。

前端展示名、副标题、说明和图标地址集中在 `frontend/src/lib/brand.ts`；共享标志组件位于 `frontend/src/components/brand/`。页面、登录、帮助、调试及设计展示入口引用同一配置，文档中的产品说明同步更新。品牌配置仅承载展示信息，不控制会话和业务逻辑。

## 标志方案

当前共享品牌组件使用登录页认可的马头像与 Niuma / CREW 矢量字标，已替换早期几何 N。字形保持登录页定格状态，系统标志仅眼皮低频眨动；减少动态效果时静止。`frontend/scripts/build-brand.mjs` 从正式登录页 `logo.ts` 派生 `public/brand/wordmark.svg`，构建与开发启动自动生成，`make build-brand` 可单独更新。组件不加载登录页动效模块、字体、SDK 或 React 动画库；副标题保留在可访问名称中，不再额外拼接一套系统字体字标。

浏览器图标使用独立的[马头 SVG 源稿](../../frontend/src/components/brand/mark.svg)，保留现有角色的造型与配色，以 144×144 正方形画板居中并留白，静态展示。品牌构建将源稿复制为 `public/brand/mark.svg`；不再裁切完整字标，避免将相邻 N 的竖笔带入图标。32px、192px 与 Apple Touch PNG 从该源稿导出后随仓库维护，修改源稿时同步刷新。应用入口为 SVG 图标增加版本参数，使浏览器重新获取修正后的素材。

历史图标检查见品牌验收，不替代当前资源核对。

夜间主题由同一矢量源派生 `wordmark-dark.svg`，只替换字母墨色；角色、字形、尺寸和眨眼保持同源。共享组件按解析后的主题选择字标，登录页的内联字标继承主题前景；不会对角色整体做颜色反转。行为与首屏规则见[主题模式](theme.md)。
