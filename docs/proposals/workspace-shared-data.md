# 工作台共享数据 Provider

设计状态：已采纳。实施状态：已实现。更新日期：2026-10-30。现行接入标准见[共享数据模块](../../frontend/src/state/README.md)，实际检查见[验收记录](../records/workspace-shared-data.md)。

## 范围与技术选择

采用 React Context、useSyncExternalStore 和普通 TypeScript 状态对象。WorkspaceDataProvider 在当前身份的工作台内提供固定实例，员工、技能、能力目录和导航使用同一套订阅与请求管理。仅共享当前浏览器页面内的数据，不增加数据库、localStorage 数据副本或跨客户端推送。输入、URL 条件、编辑中的表单和编辑保护仍归原有页面及专门状态。

## 与当前实现的差异

替换 ConfigurationInvalidationProvider 及两个失效版本：员工摘要按 ID 共用；员工列表存 ID 顺序和匹配总数；收藏侧栏复用收藏第一页及其 total；统计独立按需读取。共享读取只在订阅时发起，同条件并发请求合并，刷新保留内容，最后一个订阅离开后取消旧读取，缓存有界。Context 不传递不断替换的大对象。

收藏与启停通过员工共享状态统一提交，同员工串行、不同员工可并发。收藏只提前更新星标，确认后更新共享记录、筛选成员和可确定的数量，再核对有界收藏与分页；普通目录不为收藏重复请求。版本较旧的员工响应不得覆盖已确认的新数据。读取跨越写入时取消或忽略；保存期间需要的读取延后到保存结束，防止数量重复加减。明确失败撤销临时值；409、断网及服务端错误先读取该员工核对，不自动重发 PATCH；核对失败保留待确认状态和明确的核对入口，不能把重试保存当作重试读取。

员工编辑保存、删除向同一状态更新摘要及受影响列表；详情与摘要继续分开。技能读取、保存、删除、导入和安装接入相同的共享读取基础，成功后只更新受影响的技能、能力目录、员工摘要与计数；能力库和搜索复用共享请求管理。原局部编辑保存锁保留，防止中途离页，不把收藏登记为全局保存。

## 生命周期与维护标准

共享状态按身份和权限创建，切换身份或卸载工作台后取消读取并忽略旧写入的页面更新；页面内部导航保留当前身份的已确认数据。资源持有稳定的读取结果、loading、error 和订阅函数；组件只订阅需要的员工或查询。相同条件返回同一资源；领域保存方法统一处理数据同步，不允许页面同时修改共享记录并额外广播全局刷新。纯展示组件继续接收属性，目录中的员工卡片通过按 ID 订阅读取，设计样板不依赖工作台。

## 验收

覆盖共享订阅与定向渲染、同条件去重、订阅释放、React StrictMode、切换身份与卸载后的迟到响应、请求失败保留内容、收藏与启停并发、未知保存结果核对、分页补位与末页回退、目录与侧栏共用收藏页、技能写入后的跨页面同步。运行前端静态检查、相关与全量测试、构建、文档检查及可用浏览器验证。新规则合入当前工程手册与架构，旧的局部收藏同步方案标记被替代，实际结果进入 records。
