公开详情与员工使用摘要直接读取白名单，公开 Skill 使用已配置的实例；JSON 补齐响应模型，文件、SSE 和 OAuth 保留协议处理。API README 重写为实际中文目录、核心边界、错误转换与开发入口；现行架构、工程手册和移动路径引用同步更新。

## 验收发现与处理

- 冷启动并发最小复现：30 组、60 次启动中出现 8 次 checkpoint_unavailable，底层为 SQLite database is locked。首次 WAL/建表初始化改为读写共享入口，在工作线程内协调；新增 30 组双 writer 回归验证正常并发仍可同时进入。全部 15 项 checkpoint 初始化与进程恢复定向测试通过，随后完整回归通过。
- 文档检查原先把 .impeccable 工具生成评审缓存当成项目正文，报告了 21 个历史截图/行号链接。检查器明确排除此工具缓存，原报告保留；新增回归保证正式 docs/records 的坏链接仍会失败。
- API README 正文字符从 4037 减为 1440，新增 37 行带中文注释的实际目录树；去掉逐项协议复制和历史过程，核心错误边界保留并链接源码和业务契约。

本轮为同进程模块化单体的职责重构；验证使用隔离数据库、迁移和离线替身。未访问开发业务库，未以替身结果证明真实模型、MCP 或沙箱上游可用。
