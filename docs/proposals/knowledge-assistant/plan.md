## 目标与范围

交付真实可用的全文知识助手：管理员建库与导入资料 → 预览 → 构建发布 → 为员工绑定 → 提问并阅读原文依据 → 保存反馈；随后以同一问答用例执行已有 12 道开发题，人工评分并形成失败分析。

本迭代覆盖[主设计开发顺序](README.md#开发顺序与阶段验收)的阶段 1—3，另增加轻量 JSONL 评测。多库、归属、版本与历史引用沿用主设计，不能退化成固定知识数组。全文 A 在模型预算内使用全部获准发布资料；超限明确失败，不悄悄截断或改成检索。

混合 B、Embedding、重排、外部来源同步、PDF/Office、通用 Skill/MCP、自动方法改进和多 Agent 后置。正式题集管理、评测批次表和双栏页面属于后续，轻量入口不代表这些已完成。

## 开发任务

### K00：追踪链路，准备可重置的验证环境

- **学什么**：应用生命周期、模型客户端、后台执行、事务、SSE 与取消。
- **做什么**：按[架构阅读顺序](../../learning/reading-code.md)追踪普通聊天，标明配置捕获、模型输入、步骤和终态归属；准备隔离数据库与文件目录，记录启动、账号与清理方式。
- **怎么验证**：观察一次正常结束和一次取消；刷新只恢复观察，不新建执行；解释重启中断。真实调用明确问题与预算，离线结果不能冒充真实调用。
- **完成产物**：链路说明与环境记录；现有问题如实列出，无关重构不作为前置。

K00 进度（2026-10-23）：[Notion 源码导读与行动清单](https://app.notion.com/p/402eab92f60081cca40be1a8add06472)已建立；后端相关 42 项、前端 2 项离线测试通过。测试使用隔离数据和受控模型，未调用真实上游；本人操作与复述待完成，不能据此将 K00 勾为完成。

### K01：审核资料与题目，固定评分依据

- **学什么**：知识版本与生效时间、答案要点、禁止结论、答案泄漏、开发题与保留题。
- **做什么**：核对 manifest 的 5 个文件、哈希、13 条教学规则与 12 题的 ID/引文/答案；按已有审核稿人工检查，记录分歧、修订、审核人和时间。仅 documents 进入资料清单，题目与答案分别读取。
- **怎么验证**：自动检查文件、题号、参考答案和原文引文对应；人工核对条件、金额、日期、无答案与越界要求。哈希一致不等于人工审核通过；未审项保持 pending，不写虚构签名或成绩。
- **完成产物**：资料版本、审核记录与开发评分依据。沿用题号，12 题全部作开发/回归题；未修改的数据不机械重写。

### K02：闭合全文阶段最小契约

- **学什么**：稳定身份与不可变版本、发布指针、API/DTO、幂等、预期修订、私有访问与 token 预算。
- **做什么**：在原设计和字典列明本迭代实际需要的资产、作业、发布、回答、反馈及 run 上下文；明确导入/替换、发布、绑定、来源/反馈，以及轻量入口的共用问答调用。固定 A 的解析、计数、模型能力、输出预留与超限行为；B 相关结构不因存在于目标图就全部实施。
- **怎么验证**：用重复请求、过期修订、跨库/跨 owner、超限和重启走查契约。确认网络/解析不占写事务，作业共享有界容量；私有消息、SSE、步骤、来源、缓存与导出不被 resources:all 绕过。
- **完成产物**：可实现的契约、迁移子集与接口验收清单；未定点在对应任务开始前闭合。前端动工同时读取 frontend/AGENTS.md 与工程规范。

### K03：建立资产、作业与原文件存储

- **学什么**：关系建模、外键、不可变内容、文件与数据库一致性、迁移与恢复。
- **做什么**：按 K02 实施 A 所需模型与下一份正式迁移，保留库/分组/来源/文档身份和版本，建立统一知识作业与逐项结果。文件按服务端 ID 落盘，沿用 APP_DATA_DIR；作业共享生命周期和准入。
- **怎么验证**：隔离库从现有版本升级，核对旧员工、消息、run 和 CI 数据、约束及模型一致性。注入文件保存/事务失败，确认半成品不变成可用资料，无引用文件可清理；恢复同时覆盖数据库和原文件。
- **完成产物**：迁移、存储与约束/故障测试；写清回退或恢复的条件和损失，不在真实开发数据上试错。

### K04：实现导入、解析和来源定位

- **学什么**：输入校验、规范化、来源区间、内容哈希、幂等批处理和部分失败。
- **做什么**：实现 UTF-8 Markdown/文本上传、粘贴和登记的教学包导入，统一生成文档版本与来源块；保留标题、表格、代码、日期和否定条件。正文位置与未来检索切片分开；实现显式替换、逐项错误、取消及仅重试失败项。
- **怎么验证**：五篇资料可导入；同键同内容复用，换内容冲突，同名不自动替换。非法编码/超限文件产生部分失败，成功项不丢不重复。恶意文件名不越目录，资料中的命令/URL 不触发执行/抓取，样例导入不包含 evaluation。
- **完成产物**：导入服务、来源块、作业查询和边界测试；中断后保留事实且不自动发布。

### K05：接入真实知识管理页面

- **学什么**：DTO 与页面状态、URL 恢复、服务端真值、表单草稿、作业观察与错误恢复。
- **做什么**：管理员入口接真实多库列表/详情，完成一级分组、添加资料、批次状态、失败重试和原文预览；保留规章制度 Tab，沿用设计系统与未保存提示。
- **怎么验证**：两个库独立导入相同示例；移组/删组不删除原文。刷新恢复库、文档和作业，不重复导入；失败保留输入，游客/member 无原文/管理权限。管理列表搜索不称为检索。
- **完成产物**：真实页面、必要组件/API 测试与浏览器记录。

### K06：构建并发布全文版本

- **学什么**：编辑态与发布态、固定选材、候选产物、乐观并发和原子发布。
- **做什么**：构建固定文档/解析版本、来源块与规则，展示候选和选材，再以预期修订切活动指针；构建发布共用已有作业/容量。A 不依赖 Embedding，超限有明确原因。
- **怎么验证**：未发布不可问答；失败/取消不换线上版。改草稿、移组或换默认规则不改旧发布；竞争发布只有一个有效结果；替换正文后旧发布仍可定位，重启不自动上线候选。
- **完成产物**：全文发布服务、页面/状态与版本一致性测试。

### K07：绑定员工并收紧私有运行范围

- **学什么**：引用与所有权、快照与即时撤权、共享员工与私有资料的区别。
- **做什么**：员工保存单库与 A 策略；提交捕获可访问发布、规则和模型依据，建立知识上下文。私有对话收紧到发起者，覆盖消息、run、SSE、步骤、来源、缓存和导出；绑定不授予他人资料权限。
- **怎么验证**：两个测试 owner 直接请求对方库、来源、运行与 SSE 被拒绝，覆盖全局管理权限。无发布/归属错误不能保存成可用绑定；排队后换发布不改旧快照，撤权/停用阻止后续动作。旧聊天与 CI 回归通过。
- **完成产物**：绑定接口/表单、快照、全链访问检查与集成测试。

### K08：共用全文问答与引用校验

- **学什么**：上下文拼装、模型限制、结构化答复、事实与假设、结束原因、定位与语义支持。
- **做什么**：实现对话和轻量评测共用的 answer_question 用例。加载全部获准发布正文，计入岗位、规则、历史、工具契约与输出预留；保存实际上下文、用量和步骤，校验引用后原子提交可见答复与结果。
- **怎么验证**：受控模型覆盖越界来源/位置、空答复、截断、超限、取消、持久化失败与未知用量；真实调用检查正常、跨文档、冲突与无答案，人工另查支持性。资料指令不能扩大权限；不把字节上限冒充模型预算，不截部分全文后仍标 A。
- **完成产物**：共用用例、确定性测试与少量真实集成记录；测试替身不作为回答质量证据。

### K09：来源、反馈和历史恢复

- **学什么**：可解释交付、证据快照、反馈归属、技术成功与用户判断。
- **做什么**：对话展示知识依据、可定位原文及版本/状态，提供主设计的有用/有问题反馈。历史读取当时资料，反馈不自动改技能或知识。
- **怎么验证**：回答、原文和反馈刷新恢复，不重提；发布新正文后旧回答仍指旧证据。非法引用不展示为已核实；无引用、澄清、技术失败和权限错误可区分。
- **完成产物**：完整网页闭环与历史/错误恢复记录。

### K10：轻量评测与一次受控改进

- **学什么**：批量实验、控制变量、人工评分、分母/N/A、错误归因与开发成绩局限。
- **做什么**：增加待命名的受限脚本，固定操作者、发布、题集、模型配置/凭证修订、提示与参数、并发和重复次数。调用 K08 同一上下文/回答链路，共享准入、取消和用量；逐题保存 ID、输出、引用、状态/错误、耗时与配置依据。输出固定后关联参考答案并人工评分。
- **怎么验证**：12 题均有结果或明确失败，生成请求没有参考答案。脚本不复制提示词/拼装逻辑，不伪造生产聊天；沿用 owner 和资源检查。按主设计手算评分并核对报告；未评分不算正确，未知费用不记零，A 的召回排名指标为 N/A。
- **完成产物**：12 题开发评分报告与错误列表；选一个失败，只改回答方法中的一个因素，同发布/问题复跑，保留前后结果、实际用量和人工复核时间。不保证必然提升，不将开发题改进称为独立泛化成绩。

轻量数据适配保留原题号、doc_id、source_path 和原文引文，将审核依据映射到 K04/K06 生成的固定发布、来源块与原文区间，不要求重写参考答案，也不把参考正文交给回答模型。

脚本的参数、调用与产物契约由 K02 补到主设计，K10 实施后才加入运行说明；本轮没有创建新命令。复用已有审核/评分结构，实验元信息和结果不覆盖空白评分模板。产物按数据目录与归档规范保存，私有原文/凭证不提交仓库；正式 evaluations 作业与页面后置。

### K11：故障、恢复与本人学习验收

- **学什么**：系统排错、事务/取消竞态、数据恢复、回归范围和结论边界。
- **做什么**：执行下方清单并修复问题，核对文档、接口、迁移和界面。本人解释链路、预测改动影响，并定位一个没有预先给出答案的故障。
- **怎么验证**：先受影响模块测试，再执行项目静态检查、离线测试、构建和隔离迁移检查；真实模型、浏览器及成本另记。不用历史记录代替本次结果，失败与未知项保留。
- **完成产物**：验证与恢复记录、限制和学习复盘；仅通过项标完成。
