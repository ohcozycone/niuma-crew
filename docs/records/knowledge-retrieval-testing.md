# 知识库检索测试与模型入口验收

日期：2026-10-31。范围见[增量方案](../proposals/knowledge-assistant/retrieval-testing.md)，当前规则见[知识库契约](../reference/knowledge.md)。

## 实现

- 大脑页仅管理 chat 连接，知识库“检索设置”弹窗单独管理 embedding 连接；复用配置、凭证与修订服务，已有向量连接保留。
- 页面优先展示检索方式、问题和结果；未就绪时禁用向量与混合方式，保留 BM25。
- 产品混合检索复用同库 BM25、向量候选，以 RRF 合并；鉴权、版本检查、原子索引发布与失败保留沿用向量链路。

## 实际检查

- 后端定向：`test_knowledge_vectors.py`、`test_knowledge_library.py`、`test_model_connections.py` 共 47 项通过；覆盖 RRF 排名/同分稳定顺序/去重、同库来源、索引失效和现有边界。入库回滚断言同步当前统一错误边界，核对返回安全 500 并且资料和索引均未部分保存。
- Ruff 定向检查通过，知识模块三份受改 Python 源文件 mypy 通过。
- 前端流程与模型配置测试共 20 项通过，包含构建中禁止关闭弹窗、未配置混合深链接保留问题并可切回 BM25、Key 保存和用途筛选。受改文件 ESLint、前端 typecheck、生产构建通过；Impeccable detector 无命中，文档检查 0 错误。生产构建仍提示已有大体积代码块。
- 全前端测试首次运行：485 通过、2 失败；失败位于工具页错误恢复按钮与 HTTP 客户端离线文案断言，与本次受改入口无关，未在本任务改动这两处。

## 界面核验边界

使用临时数据库、测试账号和模拟 1024 维向量运行隔离服务。实际点击知识库内添加模型、保存测试 Key、测试连接、返回索引设置、建立索引和混合查询，确认命中与来源链接；核对 1280×720 日间布局，检索方式/问题并列且首条结果在首屏，编辑关闭后焦点回到设置弹窗；未访问真实用户 Key，未向硅基流动发送资料。模拟结果只证明接线和交互，不证明真实 API 权限、额度或语义召回质量。
