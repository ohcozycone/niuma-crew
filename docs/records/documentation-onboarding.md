## 实际核对方法

1. 从路由、页面及共享数据实现核对当前用户入口与状态作用域；从 bootstrap 核对服务装配与同进程边界。
2. 沿对话接受、准备、执行协调、发布及文件下载代码核对输入到结果的链路；区分已接受、候选结果和正式交付。
3. 对照身份角色映射、员工资源捕获、工具清单/账号及模型工厂核对权限和资源归属；技术选型版本仍以清单与锁文件为准，未虚构历史选型动机。
4. 对照静态资料页面与独立知识实验入口，保持正式产品、实验和未来方案分开。
5. 核对有 README 的模块目录与文件职责表，覆盖生产文件；相关文件可合并解释，测试和包标记不展开成逐函数清单。
6. 将两幅 SVG 导出为 2 倍 PNG，逐幅查看中文、文字边界、连线及图例；图示为职责协作和正常成功路径，正文补充失败与恢复边界。
