# CI 诊断数据退役

当前 CI 专用数据不再是业务能力。正式升级见[0012 退役迁移](../../../backend/migrations/versions/0012_retire_ci_diagnosis.py)及[迁移目录](../../../backend/migrations/versions/)，不改写历史迁移来伪装成从未存在。

## 专业记录

退役迁移删除 ci_diagnoses 与 agents.ci_repository，精确清理固定试验技能及其装配，不按名称批量删除用户技能、员工或通用 MCP 连接。

## 过程、来源与报告

专用过程、报告和反馈表移除；已交付消息文本、共享 Run 及动作保留只读。活跃试验在新 Runner 启动前安全中断或取消，关闭未完成动作、释放对话占用；旧输入仍可辨认并拒绝重试，不保留执行器或报告查询。

## 迁移与后续范围

停止旧后端及同步等全部写入入口，成套备份业务库、checkpoint、主密钥与相关技能资产后升级。固定技能若有可编辑来源目录，还需按现有锁和一致性机制归档，防止同步重新导入。校验外键、混合历史和普通运行，并验证备份恢复。

历史 0004/0005 的升级与验证继续保留；退役后的专业 JSON 无法靠空壳 downgrade 无损恢复，回退使用备份。操作见[迁移与恢复](../data-model.md#迁移与恢复)和[后端指南](../../guides/backend-operations.md#数据库迁移)。后续业务按真实需要独立设计，不为旧试验预建替代模块。
