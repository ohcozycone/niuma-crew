## 隔离验收阶段的部署限制

截至源码与隔离验收阶段，没有读取或修改开发/部署数据库、真实凭据及用户技能目录。部署者须按[退役操作指南](../guides/backend-operations.md)停止全部写入、成套备份、盘点归档来源，再执行 0012 并启动新版本。该阶段通过不等于环境已升级；后续本机落地结果见下节。

该阶段未使用真实账户重新验收模型、GitHub OAuth、外部 MCP 与 OpenSandbox；离线替身不能证明上游可用。当前仍为同进程、同库、单持锁 Runner，不宣称支持独立 worker 或多主机恢复。
