# 表单控件统一验收

日期：2026-10-31。范围：当前工作区的共享控件与主题，未提交远端或部署。增量见[方案](../proposals/unified-form-controls.md)，生效规则见[设计系统组件规范](../../frontend/src/design-system/components.md#输入选择与反馈)。

## 首轮实施（焦点配色已由下方修订替换）

`Field` 提供统一的标签、说明和错误样式，`FormField` 消费同一组合并保留已有 ID、外部说明、表单值与动态错误关联。Input、Textarea、Select、SearchInput 和 InputGroup 统一橙色焦点，移除输入控件上的全局硬轮廓叠加；登录保留原有底线布局，由容器承接同一外圈。主题焦点引用品牌色，未新增颜色字面量。示例页与第三方适配说明同步更新。

- `make build`：生产构建通过；仍提示部分既有依赖产物超过 500 kB，未调整分包。
- `UV_CACHE_DIR=/tmp/niuma-uv-cache make check-docs`：文档链接检查通过。默认 uv 缓存目录不可写，改用临时缓存完成检查。
- Impeccable 机械检测：变更目标未检出问题。
- 浏览器：使用真实组件的临时验证入口检查 Input、Textarea、SelectField、SearchInput、禁用与错误、两种输入组和原生提交；Select 方向键加 Enter 成功切换，标签点击聚焦成功。普通字段为橙色边框和 3px/20% 外圈，无额外 outline；错误保持红色；输入组内部外圈宽度为 0，只有外层显示 3px 外圈。临时入口已删除。

## 恢复 shadcn 默认焦点与普通圆角

根据当前有效要求，取消橙色焦点，新增 `field-focus` 接入 shadcn 中性灰；全局键盘焦点兜底恢复原有中性色。参考站实际输入在日夜均为 8px 普通圆角，聚焦外圈为 3px、50% 透明度；工程原有 8px 超椭圆使角部更方，现已改用 `rounded-field` 普通圆角，并登记到 className 合并规则，保证输入组的直角覆盖仍有效。错误态沿用红色，输入组仍只在外层显示焦点。

实测来源为 [用户提供的 Field 页面](https://www.shadcn-ui.cn/docs/components/field)：日间 ring 为 oklch 明度约 0.708，夜间约 0.556，角形为 round。工程以对应中性灰 #a1a1a1/#737373 接入。生效规范与样板、索引已同步，不再将橙色作为当前要求。

本次修订验证：

- 浏览器日夜主题下的实际 Input/Textarea 均为 8px、round（计算值 `superellipse(1)`），无额外 outline；日间边框 #a1a1a1、夜间 #737373，3px 外圈透明度为 50%。390px 下仍为 16px 输入字号且无横向溢出，验证后恢复显示设置。
- `make test-frontend` 最终为 76 文件、529 项通过。此前一次运行的问题导航 tooltip 测试等待超时，单文件 16 项复跑通过，随后完整套件通过；未改动该测试或导航逻辑。
- `make lint-frontend`、`make build` 与临时 uv 缓存下的 `make check-docs` 通过。生产构建仍有既有分包体积提示。

## 默认边框补齐

上一轮恢复了聚焦色，默认边框仍引用项目旧的深灰，未与参考站对齐。本次将共享 `input` 语义改为参考站默认值：日间 #e5e5e5，夜间白色 15% 透明度。Input、Textarea、Select、搜索与输入组直接消费同一令牌；既有聚焦色、外圈和错误态保持各自语义。默认边框改按上游视觉规范验收，不再对它执行旧的 3:1 边界要求；全局键盘焦点对比度检查保留。

浏览器实测：日间 Input、Textarea、Select 默认边框均为 rgb(229, 229, 229)，聚焦后为 rgb(161, 161, 161)；夜间默认边框为 rgba(255, 255, 255, 0.15)，与参考站日夜实际 CSS 值对应。验证后恢复主题。
