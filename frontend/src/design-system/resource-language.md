# 对象、动作与确认

同一业务对象在导航、列表、详情、装配、选择与执行中保持相同名称和图形。图形使用现有 Lucide 描边体系，颜色沿用主题语义，不以颜色单独区分类型。唯一映射与渲染入口为 [ResourceIcon](../components/common/ResourceIcon.tsx)，正式交互样板位于 `/design-system#resource-language`。

## 对象身份

| 对象         | 主名称       | 图形           | 边界                                    |
| ------------ | ------------ | -------------- | --------------------------------------- |
| 岗位         | 员工         | 当前角色头像   | UsersRound 表示员工集合，个人仍用原角色 |
| 方法包       | 技能         | Puzzle         | `SKILL.md`、协议和 API 标识保留原名     |
| MCP 服务     | MCP          | Plug           | HTTP/stdio 作为传输属性，不改变类型标识 |
| 平台操作     | 内置工具     | Wrench         | 不用终端图形泛指所有工具                |
| 能力集合     | 能力库       | Plug           | 同时包含工具与技能                      |
| 服务账号     | 账号连接     | KeyRound       | 凭据状态另行说明                        |
| 对话模型连接 | 大脑         | Brain          | 与向量模型区分                          |
| 检索模型连接 | 向量模型     | Network        | 不混入员工大脑选择                      |
| 资料集合     | 知识库       | LibraryBig     | 大卡片沿用已认可的文件夹资产            |
| 文件         | 文档         | FileText       | 上传、下载、移除另用动作表达            |
| 员工指令     | 工作指令     | ListChecks     | 清晰的编辑器标题可省略重复图标          |
| 全员规则     | 公司规章制度 | ShieldCheck    | 只读继承，不提供解除绑定                |
| 持续交流     | 对话         | MessagesSquare | 执行阶段与成功失败另行表达              |

已知来源的工具按 MCP/内置工具显示；历史运行未记录来源时使用通用“工具”，不推断来源。不支持的类型回退“未知类型”。集合、对象、动作、状态分工稳定：技能已启用不等于已装配，已装配不等于本轮已加载，加载也不代表执行成功。

类型已由图标与相邻文字表达时，摘要不再重复类型。图标按钮必须有可访问名称；普通动作旁的图标是辅助，不能替代按钮文字。

## 动作与生效时机

添加用 Plus，配置用 Settings2，面板完成用 Check，主保存用 Save，移除装配/绑定关系用 Unlink，永久删除用 Trash。勾选表示加入选择，Switch 表示启停；不再用启停开关表达工具操作或本轮技能的选择。

员工页分为基础配置、指令与知识、能力装配，URL 键保持 `identity`、`instructions`、`capabilities`。工具和技能在同一装配列表中筛选、搜索和分页；配置面板完成更新同一员工草稿，主保存才提交。取消、Escape 和关闭丢弃本次未完成的面板修改。知识库绑定作为独立增量；当前知识辅区进入真实资料管理，不能宣称已接入员工对话。

## 危险操作确认

影响装配关系、支持文件、个人账号或共享可用性的操作先确认，明确对象、影响范围、能否恢复和生效时机。复用 [ConfirmActionDialog](../components/common/ConfirmActionDialog.tsx)，初始焦点落在取消；取消或 Escape 不改草稿、不发写请求，提交期间禁用重复操作和关闭。失败由拥有请求的页面保留在弹窗中，确认组件本身不持有业务状态。

| 操作                        | 确认内容                             | 生效时机       |
| --------------------------- | ------------------------------------ | -------------- |
| 移除员工能力                | 只解除装配，不删除共享能力或账号     | 保存员工配置后 |
| 移除技能支持文件            | 指定路径，主文和其他文件保留         | 保存技能后     |
| 切换/解除本人账号           | 只改本人绑定，说明默认账号回退       | 确认请求成功后 |
| 暂停员工                    | 暂停接单，配置和历史保留，可恢复接单 | 确认请求成功后 |
| 停用 MCP 服务/连接          | 说明受影响的员工、连接和后续调用     | 确认请求成功后 |
| 应用移除/修改工具定义的目录 | 展示变更数量，提示重新核对授权       | 确认请求成功后 |
| 移除知识文档/向量索引       | 文档及索引的实际删除范围             | 确认请求成功后 |

已有员工永久删除的输入确认、模型与 MCP 删除确认及后端引用保护继续生效。一般输入、筛选、首次添加和可撤回的选择沿用直接操作。

外部规范提供一致识别、非颜色表达、导航与标签原则，不指定 Skill/MCP 的唯一图标；图形选择属于站内约定，依据见设计方案。
