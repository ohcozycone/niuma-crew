# 后端文件职责第一轮整理验收

2026-10-26，适用于本次调整后的本地工作区。依据[已采纳范围](../proposals/backend-architecture/README.md#文件职责第一轮整理)，完成文件归位、命名和引用整理，保持现有对外行为与事务边界。当前分工见[后端架构](../architecture/backend.md)及相应模块说明。

## 实际调整

| 范围         | 调整及所有者                                                                                                                                             |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 对话读取     | conversations/queries.py 合并原 service 的查询、归属查找、执行投影及上下文选择；ConversationQueries 不接受写命令                                         |
| 对话写入     | conversations/writes.py 集中创建对话、保存输入、分配顺序、绑定执行及发布助手消息；函数使用调用方 Session，不自行提交                                     |
| 命令与发布   | use_cases/conversation_commands.py 的 ConversationCommands 负责创建、提交、重试、取消；PublishRun 调用对话写入规则发布结果，继续持有原有事务             |
| 员工执行配置 | agents/execution.py 集中配置组合、技能捕获、当前装配许可复核和系统提示词组合；skills 继续拥有共享方法定义及参数校验，organization_rules 继续拥有规则读写 |
| 执行错误     | 执行错误码与公开提示从 execution/schemas.py 移入 errors.py，统一使用 ERROR_MESSAGES；schemas.py 保留读取 DTO                                             |
| 文件命名     | API 共享请求限流归 api/rate_limit.py；技能参数校验改名 parameters.py；SDK 技能资源加载改名 skill_loading.py                                              |
| 保存入口     | 结构化阶段资料使用 save_progress_payload；正式完成使用 complete(Completion)，文字进度继续使用 update_progress，移除混合用途的 persist 入口               |

旧文件和旧符号不保留转发别名，生产代码、测试、实验及相关文档引用一并更新。查询、写入和用例纳入现有增量 mypy 范围，未将未检查的其他模块标为已全面通过类型检查。

## 保持的事务及行为

独立创建空对话仍在同一个写事务内校验员工、创建对话和读取响应。发送仍先取得写入资格，再检查归属、幂等、容量和当前配置；用户消息、Run、冻结输入与对话关联原子保存。重试仍复用原输入；取消与结果发布继续使用原有串行保护。

发布对话的函数改为由 conversations 提供，仍在 PublishRun 的事务中执行：稳定结果、正式助手消息、终态和活动关联一起提交，失败一起回滚。模型调用与工具等待仍在事务外，授权复核时机没有因文件移动改变。

对照本轮开始前的文件副本，核对了 12 个关键函数。去除类型标注、无运行时作用的 cast，并统一同工作区另一项应用错误类型调整后，归属查找、投影、上下文选择、输入准备、执行绑定、助手消息发布、技能捕获及授权、提示词和配置组合的语法树一致。错误提示字典完全一致，对话路由装饰器的路径、响应模型及状态码一致；原有 ORM 文件、对话 DTO、执行快照契约和 uv.lock 内容未变。本轮不涉及数据库迁移。

测试使用临时数据及假模型，未访问开发数据库或真实模型上游。本工作区同时有应用错误类型与数据库错误识别整理，455 项是当前整个工作区的回归结果；本记录不将这些独立调整计入本轮文件归位。SDK 消息转换、授权策略复用、CI 循环统一及 checkpoint 测试辅助清理仍属后续增量。
