# NiumaCrew

NiumaCrew（建设中） 是一个用于交流学习的数字员工平台。你可以为一个岗位设置岗位描述和边界、语言模型和可复用技能，再通过对话交给它具体工作；需要读取文件或访问外部服务时，员工只能使用事先获准的工具。平台保存输入、回复、执行过程和已交付文件，方便后续继续交流和核对结果。

## 平台有哪些功能

| 功能           | 帮助你完成什么                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------- |
| 数字员工       | 保存岗位职责、工作指令和资源选择，让同一岗位可被反复使用；员工是配置，不是登录账号。               |
| 大脑配置       | 管理员工调用语言模型所需的连接与密钥；多位员工可以共用同一连接。                                   |
| 能力库与技能   | 浏览可用方法和工具服务；技能保存可复用的工作指引及支持文件，选入员工后供运行时读取。               |
| 工具与账号     | 连接外部服务，确认它提供的操作，再为员工授予具体许可；使用者可以绑定自己的相容账号。               |
| 对话与执行记录 | 发消息、观察真实动作、停止处理、重试符合条件的失败回复，并继续已有对话。                           |
| 文件与沙箱     | 传入附件、保存交付物；代码执行另需配置并验收隔离环境。                                             |
| 知识资料       | 建立本人知识库、上传文本、核对原件和片段，并在库内进行 BM25 关键词检索；员工绑定及模型问答待接入。 |

## 当前状态

- 已实现员工与技能配置、共享模型连接（大脑）、全局规章制度，以及带历史、停止、重试和执行步骤的真实对话。
- 已接入标准技能包的导入、编辑、导出与目录同步，支持按需加载方法及支持文件；HTTP/可信 stdio MCP、附件与输出文件、OpenSandbox 命令执行按员工许可使用。
- 管理员维护配置；GitHub 普通成员可发起本人对话、管理本人 MCP 账号，游客只读浏览。GitHub 登录需部署者配置；模型、MCP 和沙箱的真实可用性还取决于部署凭据、网络与目标主机验证。
- 当前后端同进程、同业务库运行。知识页当前代码已接入本人库、文本入库、来源阅读和关键词检索；向量/带引用问答、员工知识绑定、SOP 和能力评测仍未接入，普通用户业务 CLI、机器身份和独立 worker 尚未接入。

## 本地运行

需要 Python 3.12+、uv、Node.js 22.12+、pnpm 11 和 make。以下命令均在项目根目录执行。

1. 安装依赖并升级数据库：

   ```bash
   make setup
   make db-upgrade
   ```

2. 首次管理配置前初始化管理员；已有管理员可跳过。按终端提示输入密码：

   ```bash
   make admin-create
   ```

3. 启动完整开发环境：

   ```bash
   make dev
   ```

4. 打开[应用](http://127.0.0.1:3000)，使用管理员登录或选择游客浏览。前端固定 3000；后端从 8000 自动避让，实际地址见终端输出，接口文档位于该地址的 `/docs`。Ctrl+C 统一结束本次前后端进程；3000 已占用时直接报错。

按环境变量示例配置后，本地 SQLite 数据库位于 `~/data/app.db`，与源码目录分开保存，不会自动导入示例员工。已有 `.env` 不会被上述命令覆盖，文件路径和备份要求见[后端配置说明](docs/guides/backend-operations.md#数据库与本地文件配置)。启动和管理员初始化无需模型密钥；真实对话前，需由管理员在“大脑”中配置模型连接，并将其绑定到启用的员工。

## 核心流程

1. 创建数字员工：设置职位、岗位边界、服务风格。
2. 配置员工能力：创建知识库、通用技能、SOP 与工具（建设中）。
3. 发起会话：从数字员工列表进入并发送消息。
4. 执行并观测：在执行记录中查看流式意图、检索、技能、工具、校验和回答事件。
5. 持续运营：记忆、反馈、对话日志和定时任务长期优化员工能力（建设中）。
