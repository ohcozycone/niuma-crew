# 知识库资料建设闭环验收

日期：2026-10-31。范围是[资料建设增量](../proposals/knowledge-assistant/document-processing.md)，现行行为见[知识库契约](../reference/knowledge.md)。用户已授权实施本阶段，完整增量向量与员工知识挂载未包含在内。

## 实施结果

上传只保存经校验的MD/TXT原件；库内手动提交持久处理批次。默认800字符、120字符重叠，允许库级覆盖，合并校验并冻结实际规则。后台逐文件解析并原子发布正文/Chunk/FTS；处理失败保留原件及有效旧产物，重试只针对所选文件。取消、删除和重启中断通过任务许可与原件摘要校验阻止迟到发布。

上传队列在账号作用域持有，SPA切页及浮层收起不中断传输。刷新/关闭浏览器不承诺续传，退出账号清理本地队列；服务端已经入队的处理任务继续执行。库设置支持名称、用途、规则维护及修订冲突保护。

向量摘要按实际Chunk覆盖判断，允许部分覆盖；新增暂存原件、删除其他文件不使有效向量整体过期。重处理只清除该文件的旧向量。既有向量构建仍为显式同步整库构建，尚非后台增量任务。

## 页面实测

使用本机8769端口、隔离临时数据库及合成文本，实际启动知识处理器，不连接聊天模型或Embedding API。

1. 选择并上传文件，上传开始后立即切到库列表，全局浮层仍显示原件保存成功；收起后返回库，显示新增待处理文件。
2. 对失败文件点击重试并提交后台处理，离开后返回，原有可用文件与新成功文件共同显示关键词可用，其他待处理原件仍不可检索。
3. 设置切分100字符但保留默认重叠120时阻止保存，改为10后保存成功；处理弹窗采用100/10，而已有关键词文件数量不变。
4. 验证320、390及1280像素视口：窄屏无横向溢出，规则输入和弹窗可用；恢复视口并关闭验收页。

验收截图保存在本机本次会话可视化目录，展示文档就绪状态、处理弹窗及跨页上传浮层。未用界面实测模拟进程崩溃和删除竞态，这些由后端测试验证；没有真实语义召回质量结论。
