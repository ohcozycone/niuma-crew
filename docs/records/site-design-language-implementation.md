# 全站设计语言与员工配置实施验收

日期：2026-10-31。用户已认可设计并直接授权实施，补充要求为移除等危险操作增加确认。范围依据[总体计划](../proposals/site-design-language.md)和[具体设计](../proposals/site-design-language-design.md)；现行规则归入[对象、动作与确认](../../frontend/src/design-system/resource-language.md)，不将原型通过结果当作正式界面验证。

## 正式实现

1. 新建和编辑员工共用基础配置、指令与知识、能力装配三个 tab，保留原 URL 键。名称与大脑同页、标准字段样式、72px 角色头像及原头像选择器；宽屏显示正式卡片预览，窄屏按需打开。指令主区、继承规则折叠和知识辅区组合，保留同一员工草稿、事务保存、修订冲突和离页保护。
2. 工具与技能共用 AgentCapabilityAssembly 的混合列表、类型筛选、搜索、六项分页和添加入口。添加候选列表独立滚动，工具与技能的筛选和搜索留在上方；技能候选保留服务端批次分页。原工具许可、账号模式、范围约束和技能声明参数面板由原所有者继续管理；面板完成只更新草稿。
3. ResourceIcon 集中对象名称与图形。导航、能力卡、技能卡、装配/候选、全局搜索、对话技能选择、运行过程、模型用途、知识/文件/规则及设计样板接入一致表达。类型与状态分开，工具操作选择和本轮技能选择使用 checkbox，启停保留 Switch。未知来源运行使用通用工具身份。
4. ConfirmActionDialog 统一取消初始焦点、明确对象和影响的确认。覆盖装配移除、技能支持文件移除、员工暂停、MCP 服务/连接停用、包含移除或定义变化的目录更新、本人账号切换/解除、知识文档与向量索引移除。草稿操作说明主保存后生效，即时写入说明影响范围；已有员工/模型/MCP 永久删除确认和后端引用保护保留。
5. 正式设计目录新增 `/design-system#resource-language`，展示正式标识、动作和确认组件；帮助页、模块说明、设计系统与方案状态同步。临时生成的 `frontend/output/` 已被 Git 忽略，本次将其加入 Prettier 忽略，避免检查/改写研究产物。

## 自动检查

最终执行 `make lint-frontend`、`make test-frontend`、`make build` 均通过：74 个测试文件、512 项测试。覆盖的行为回归包括：工具较多时直接筛选技能、分页与搜索、统一添加入口完成前不写草稿、取消参数修改、完成后切换筛选保留参数、移除取消不写草稿、确认后只解除关系、技能支持文件取消/确认及完整包保存、员工暂停取消不请求、服务/连接停用确认、目录删除变更确认、本人解绑取消与失败保留、文档删除失败保留和向量索引嵌套确认。

`UV_CACHE_DIR=/private/tmp/niuma-crew-uv-cache make check-docs` 检查 280 个文件，发现同期知识库增量的两处未完成引用：`docs/reference/knowledge.md` 引用尚不存在的 `docs/records/knowledge-document-processing.md`；`docs/proposals/knowledge-assistant/document-processing.md` 尚未从主索引可达。本次新增规范与实施记录没有报告链接错误，未为其他进行中的功能编造验收记录。

原有员工编辑、共享同步、保存失败/冲突、草稿恢复、权限、工具范围校验、技能包二进制保留及对话回归继续运行。未修改后端接口、数据库模型或迁移，不以这些前端结果声明后端新能力通过。

## 边界

员工知识库绑定与正式聊天检索仍属于独立功能增量。当前知识辅区只进入真实个人知识库管理，并明确资料不会自动进入员工对话；没有提交假绑定或新增持久化字段。

本次未做真实账号解绑、永久删除、远端 MCP/模型执行、所有浏览器/角色/异常状态的视觉全覆盖或读屏器实测。现有后端权限与引用保护由既有契约和测试维护。构建保留已有大分包提示，不改变依赖与拆包策略。
