# 共享样式组件完整封装

设计状态：已采纳。实施状态：共享组件及用户确认后的知识卡片均已实现，当前规则见[共享表面](../../frontend/src/design-system/surfaces.md)，验证见[本轮记录](../records/component-encapsulation.md)。更新：2026-10-31。用户授权梳理后直接改正式组件，知识卡片经单独确认后，复用员工同源 Card、CardContent、CardFooter，叠加统一通用知识图标和少量细节；前序写实书本和彩色文件夹探索已撤回。

## 盘点与边界

对 frontend/src 中非测试、非生成的 TS/TSX/CSS 建立 AST 使用清单，排除头像 SVG 原画及图示；检查共享组件、页面私有组件、样式文件及原生控件。引用次数是模块族 JSX 直接导入计数，不等于运行覆盖或独立组件数；路由、barrel 与动态图例另核对，不凭零引用删除文件。原始 CSV 当时位于 `.impeccable/review/component-encapsulation/usage.csv`，当前工作区未保留；可读结论见[本轮记录](../records/component-encapsulation.md)。

组件负责默认字体、表面、尺寸、间距和交互状态；页面负责内容、事件、数据、放置位置和外部空间。className 本身不算问题，宽度/外部间距与重写内部样式要分开判断。登录、头像、品牌和对话编辑器保留自身任务造型，不强行并成普通表单。

## 本轮明确改造

| 组合          | 完整入口与迁移                                                                                                    |
| ------------- | ----------------------------------------------------------------------------------------------------------------- |
| 页面/面板 Tab | 增加完整 PageTabs，统一列表、标签、数量、基线、指示线与响应；迁移全部页面线型 Tab，保留底层分段 Tabs 用于内嵌选择 |
| 普通字段      | FormField 维护标签/控件的统一布局；迁移重复普通字段，不把开关行和特殊员工身份控件硬套进去                         |
| 弹窗          | 中央弹窗默认内部纵向滚动；侧边面板使用自己的主体滚动；移除页面重复 overflow-y-auto                                |
| 菜单项        | 危险语义、分组标题和单选项视觉由共享组件提供，不由账户页重写                                                      |
| 空态          | 用普通/紧凑密度表示用途，移除消费者各写 padding 的差异                                                            |
| 页头主操作    | 复用既有 PageHeading.actions，把知识库新建/添加及能力目录添加移回页头；搜索刷新保持集合工具栏                     |

Button、Input、Select、主题/头像等已有完整接口不重做；Card补齐内嵌plain/none用途，业务 Card 内部排版和原生品牌场景不会被“一律禁止 className”替代。规章、技能和业务错误的状态协议保持原行为。
