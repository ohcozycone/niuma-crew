## 适用范围与阅读入口

本文维护后续阶段的运行、接口及读取目标。当前 P1 语义由[现行契约](../../reference/runtime.md)维护。P1 仅含纯指引技能、模型调用和现有 CI 专用业务；下文通用工具与知识规则属于 P2/P3/P4。表归属和取舍见目标模型，字段只在数据字典维护，当前功能以现有接口和迁移为准。标准包、动态 MCP 目录与独立员工工具许可按[技能/MCP 新设计](../skills-and-mcp/README.md)推进；以下目标语义尚未实现。关联不等于执行，方法声明不等于授权。

运行职责整理与流式回答、技能/工具步骤和思考展示的已实施增量，见 [runtime 重构方案](../runtime-refactoring.md)；该方案不代替本页的工具授权与知识接入设计。

## 模块职责

| 模块                             | 拥有的数据与操作                           | 协作边界                                                             |
| -------------------------------- | ------------------------------------------ | -------------------------------------------------------------------- |
| agents                           | 员工、技能关系参数及实际工具授权的聚合保存 | 同事务校验引用与预期修订；不解密或调用外部服务                       |
| skills                           | 当前共享方法、参数规范和工具需求槽位       | 正文与需求同事务，变更递增技能修订；不选生产账号                     |
| tools                            | 内置契约、MCP 动态目录、连接与范围解释     | 秘密独立解析，操作前强制检查，地址经部署策略批准，不接受任意代码实现 |
| model_connections / llm          | 连接/秘密与模型协议适配                    | 保留分工；工具连接不依赖模型业务服务，可复用窄加密基础能力           |
| knowledge                        | 资料、版本、来源块、发布与知识作业         | 提供固定发布、检索和来源读取，不拥有员工或对话队列                   |
| conversations / auth.permissions | 准入、幂等、内容范围和固定本轮依据         | 输入、输出占位、上下文和 run 原子保存                                |
| runs / runtime                   | 持久化状态与步骤；调度及模型/工具协调      | 一个运行生命周期，SDK 事件经映射，不取代数据库事实                   |
| 前端                             | 配置、显式选择、当前页查询与真实步骤展示   | 不授予资源权限，不把候选/配置数量显示成执行成功                      |

员工聚合保存需要将发起身份或资源范围传入用例；当前无 Actor 的 CRUD 接口不能仅靠入口能力检查代替工具使用、资料拥有者和绑定修改检查。这些引用校验与保存处在同一事务，不为跨模块协作拆散提交。

继续使用模块化单体和短事务。知识作业有自己的表，共用容量与生命周期能力，不造聊天消息，也不复制整套 Runner。评测复用问答用例但有独立执行结果与评分。

## 配置、发布与可用状态

员工—技能仍以 (agent_id, skill_id) 唯一，包含启停、非秘密参数和可选工具依赖映射。员工工具许可独立维护，明确连接、工具摘要与资源范围；不要求先造一个 Skill。参数、映射与许可在员工聚合保存时原子校验，更新相应配置和员工修订。

当前正文由 schema 1 快照固定。标准包切换后，skills 指向不可变内容制品；编辑产生新制品并切当前指针，旧运行仍可取回旧资源。平台参数规范和附加检查配置也捕获进快照。内容更新不改写本轮方法，禁用、解绑、许可/连接变化仍阻止后续动作。

MCP 工具来自获准连接的目录快照，内置工具来自受信代码。工具名、描述、schema 和相关元数据摘要固定在目录与员工许可中；新增操作不自动授权，已获准工具相关契约变化则暂停该工具待复核。连接身份、配置或凭证变化后，旧运行不得透明切到新账号。

知识文档/处理规则不可变，发布固定选材和产物；full_context 与 hybrid 使用捕获发布，缺索引不降级。知识生命周期继续按专项契约，不机械复制技能制品结构。

“已导入”“已关联”“配置完整”“宿主支持”“当前获准”和“真实调用成功”分别表达。就绪由后端按当前内容、依赖和许可解析，不持久化永久可信的 executable=true。技能数按启用关系；工具按获准 (connection_id, tool_name) 去重，两个连接的同名工具计为两个不同操作入口；连接数与调用次数另算。数量不证明执行或收益。

## 普通聊天的统一运行流程

以下是新目标，当前 P1 的实际限制见现行契约。

1. **准入**：检查身份、员工启用、内容范围、幂等和容量。selected_skill_ids 必须属于当前员工；缺少或空数组表示自动判断。没有 Skill 也可使用独立获准工具。
2. **固定依据**：在短事务捕获员工/规则/模型、启用技能制品与配置、员工工具许可、获准目录和连接修订，保存输入、助手占位与 queued Run。标准包/MCP 切换使用新快照 schema，具体编号在实施时分配；不冒充现行 schema 已能处理新字段。
3. **知识准入**：需要时固定 ready 发布及策略；同事务建立 run_knowledge_contexts 并收紧 owner 可见性。网络、文件获取和索引建设不占此写事务。
4. **发现与激活**：先给模型方法摘要和受预算限制的获准工具。模型按需读取固定 SKILL.md 与资源；显式选择先加载，缺少必需依赖明确失败。不开放快照外资源或未支持执行环境。
5. **工具往返**：统一 Agent 循环处理 MCP 与内置工具，不按技能 ID/业务 kind 另选循环。短别名映射到 (connection_id, upstream_tool_name, descriptor_hash)，需要时关联所用技能以便解释；归属不能靠模型自报。
6. **授权与调用**：首次连接及每次工具调用前，事务外重新检查当前远端目录；失配暂停受影响工具待审核。逐次检查会话、许可、连接与目录摘要、参数、资源范围及预算，校验通过后解析秘密并实际调用。标准 Skill 不决定授权，强制任务约束由宿主在接受时合并并固定，冲突拒绝；同名工具、账号和输出互相隔离，不用全局环境变量切身份。
7. **按需知识**：full_context 在预算内读取固定发布，hybrid 使用匹配索引；实际送模区间在读取时记录。检索故障与资料不足分开，不补造引用。
8. **校验与交付**：真实步骤落库；通用完成检查及已声明的受信领域检查通过后，将正文、业务结果、用量和终态原子提交。CI 引用/attempt 检查属于领域组件，不能用模型声称完成替代；普通技能不要求逐个开发检查器。

自动技能选择仍需真实任务评测；资源附件、脚本、stdio 和 MCP 非 tools 能力分别按支持矩阵验收。已发出的外部请求不承诺撤回，写入结果未知时不自动重放。

### 当前 P1 基线

现行 SDK、预算来源、允许目录与真实动作见[当前运行契约](../../reference/runtime.md#实际-sdk-与预算)。本方案以下定义后续增量，不重复维护当前实现细则。

### CI 与其他能力

P1 CI 仍使用现有专用授权，并从通用候选中明确标记为暂不可激活，保留专用入口，避免把它误当普通指引而声称已取证；目标迁移后读取标准制品、关系参数和独立员工工具许可。旧结构化 work 入口仅转换为同一示例 Skill 和任务输入，不成为统一执行器的永久分支；CI 的 attempt、来源覆盖、证据区间和报告校验继续由受信领域组件保证。

CI 的有界 ci_result、ci_feedback 暂留 runs，分别保存领域报告和原一次反馈。统一步骤不替代业务报告，普通能力不能把进度写入 CI 字段。当前 retry 使用现行协议与配置；标准包/MCP 升级后重试使用当时现行 schema 与配置，不自动重放旧授权。

### 取消、故障与预算

保留 queued/running/cancelling、终态、断线继续、显式重试及重启标 interrupted，未完成步骤也标中断。不自动重放外部请求。已发出的上游调用只能尽力取消，不能承诺撤回；取消和撤权必须阻止后续调用及迟到成功覆盖。

宿主限制总时限、模型轮数、工具次数、上下文、快照、输出和结果体积；模型调用用量累计。配置规模、上下文超限、缺组件、连接变化、权限失效、技术故障、澄清和资料不足分别记录，不包装成同一种成功回复。持久化失败停止后续操作。

## 权限与敏感数据

当前员工、技能、大脑和工具连接仍是平台管理资源。工具权限是发起身份、上游身份、实际授权与宿主固定本轮范围的交集。对关系、许可、连接或获准工具摘要的实时检查不能由快照替代。密钥只在调用前解析，不进入 DTO、技能、参数、快照、步骤或日志。

知识绑定省略时保持；只有当前资料拥有者可清空或变更自己的绑定，新目标也须有权。其他管理员可改员工的其他字段，但详情不回显私有库 ID，保存时不能把不可见值当 null 清掉。

知识按创建者归属。接受私有上下文要求 actor=库拥有者=对话拥有者，并在同事务切 visibility=owner。owner 范围优先于 resources:all；消息、历史、run、步骤、SSE、答案、反馈、引用、导出和缓存统一检查。解绑不把旧历史改回 platform，资料失效也要保护既有内容。

未授权资料不进入目录或快照，不返回内部库标识；共享员工仍可用于不涉及该资料的聊天，显式访问资料则返回不可见。游客和 当前的 member 沿用当前公开展示权限，不自动获得配置写入、对话、工具或知识问答能力。external_identities 只绑定登录用户，不构成工具授权或凭证来源。

### 保存与选择语义

- PATCH 省略 skill_assignments/tool_grants 分别保持原集合；提供数组表示对应完整目标集合，[] 分别解除技能或撤销工具许可，null 无效。
- skill_assignments 每项包含 skill_id、enabled、parameters 和可选 tool_bindings；parameters={} 清空参数，tool_bindings={} 清空映射。映射只能引用同员工 tool_grants 中真实获准连接和工具，不能自行授权。
- tool_grants 每项包含 connection_id、明确工具名/获准摘要和可执行 scope_policy。不存在的工具、通配符全开、摘要失配或不可强制的范围拒绝保存。新建许可的 ID、修订、授权人和 grant_origin 由服务器生成。
- 同一事务同时解除技能不自动撤销独立工具许可，UI 明示仍可调用的工具；撤销工具后允许保留待补配置的技能，但就绪检查失败，不进入可执行目录。
- P1 当前仍拒绝这些新增工具字段；只有正式升级后才能提交，不保留两套长期写入真源。
- selected_skill_ids 省略或 [] 自动判断；null、重复或超当前 16 项选择上限返回 422。选择进入幂等摘要，同键换选择返回 409；客户端不能提交正文、许可快照或秘密改变权限。
- 连接秘密 PATCH 省略表示保留；空字符串/null 不隐式清除，显式 clear_credentials 才清除并更新凭证修订。无认证连接不得附秘密。

新增权限须注册授权映射并给管理员显式授予；用户、member 和游客边界不自动变化。工具请求不得提交 Python 导入路径、provider 实现或任意受信校验代码。知识 API 继续按专项设计；不新增同技能多实例或技能发布审核 API。

## 前端与读取模型

员工列表保留身份、编号、名称、分类、头像、职责摘要、启停、平台共享收藏、大脑是否配置及资源数量。岗位指令、示例、交付说明、完整配置与授权进入有权详情；密钥明密文始终不回显。资源名称若参与展示或筛选，由服务端增加对应查询，不规定固定联表数。

进入资源页按当前条件请求当前页，编辑按 ID 读取详情。搜索与筛选覆盖完整服务端结果；侧栏、收藏、使用统计用各自聚合，不依赖客户端拉完全部员工/技能。缓存按身份和条件隔离，保存后更新或失效，返回重新校验，并支持手动刷新。

员工配置 UI 分别显示技能与独立工具许可，必要参数生成业务表单；技能依赖提供补齐向导，缺配置明确说明。技能库和工具连接分 Tab，添加给员工无需返回列表重找技能。暂不提供多实例或发布版本选择。聊天支持可选显式技能、真实步骤、澄清与失败恢复；知识 UI 区分候选资料、构建作业、当前发布和历史来源。保留草稿、保存锁和导航保护，修订冲突保留草稿；刷新后旧修订草稿等待显式恢复，不自动套用。可查看服务器最新配置并显式采用新修订保留当前输入，之后仍需点击保存。
