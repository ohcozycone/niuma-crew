# 应用资源与历史素材维护

当前主工程只保留运行、构建与测试实际需要的代码、正式资源和示例数据。历史截图、验证原始日志、制作母版及候选材料存于同级 niuma-crew-archive；应用不从归档导入模块、读取资源或建立运行符号链接。

## 正式资源

头像使用十三角色静态 SVG 与 React 渲染实现，目录、回退和母版关系见[头像参考](../reference/avatar-assets.md)及[组件说明](../../frontend/src/components/avatars/README.md)。品牌源、生成资源及主题变体见[品牌参考](../reference/brand.md)。生成器和正式元数据是维护入口，修改来源后按[前端构建说明](../../frontend/scripts/README.md)重新生成。

教学文档、题目与参考答案属于[数据集](../../backend/datasets/travel-expense/README.md)，不当作工程规范，也不默认加载进模型。参考答案与评测记录不能混入回答知识。

错误插画使用独立方形透明 PNG，正式资产在`frontend/public/failures/`；[生成元数据](../../frontend/failure-assets.json)维护提示词与最终来源，不进入公开资源目录。组件按[统一接入标准](../reference/failures.md)选择展示族，错误码与文案保持HTML。

知识库通用图标使用 `frontend/public/knowledge/library-folder-clean.png`，[生成元数据](../../frontend/knowledge-assets.json)保存来源及提示词。用户已认可文件夹设计，采用去掉拟人眼睛的透明版本；候选图、编辑提示词、旧图和预览代码已迁至同级归档，主工程只发布现用图片。

## 临时与长期证据

临时检查产物写系统临时目录。需要长期保留的截图、原始日志和制作材料在同级归档保存；主工程 records 保留日期、范围、结论、限制和证据入口。没有归档目录的检出仍能阅读正式规则、构建和运行；历史外部材料不可用时如实标明。

迁移材料前记录清单及必要哈希，核对目标冲突，迁移后确认应用无依赖、入口和链接完整。已有母版和历史资料不因清理删除；同名不同内容保留可恢复版本。素材与实际数据、主密钥的备份是不同操作，运行数据遵循[后端指南](backend-operations.md)。
