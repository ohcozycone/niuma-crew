## 实现核对

| 内容         | 核对入口和结论                                                                                                                                        |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 岗位与装配   | agents/service、tool_grants、tool_account_bindings：岗位资料、共享资源关系、工具许可和每人账号选择分别保存，主保存共同提交。                          |
| 接受与交付   | conversations/service、preparation、publication：输入/空回复/Run 接受在前，候选经授权及文件校验后正式发布。                                           |
| 运行与 SDK   | execution/coordinator、control、store 和 agent_runtime/langchain、middleware：动作先记录再实际请求，已保存 SDK 状态的完成标记及最终消息用于确定候选。 |
| 文件与环境   | files、sandboxes 与 bootstrap：字节保存、业务引用/保留、临时环境清理分开，知识原件保留由装配合并。                                                    |
| 前端状态     | WorkspaceData、业务 Store、会话 Provider/控制器：身份作用域、定向订阅、完整表单及观察分别管理。                                                       |
| 问答可见范围 | useVisibleQuestions 与 Outline：服务器定义问题身份/编号，DOM 交集只判断当前屏幕可见组。                                                               |
| 知识         | 当前 service、models、schemas、API 路由和库/文档/检索页面：本人文本入库与 BM25 已装配；模型问答及员工绑定尚未接入。                                   |
