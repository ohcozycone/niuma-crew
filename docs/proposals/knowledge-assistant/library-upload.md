# 知识库列表与文档入库增量

状态：2026-10-31 用户授权范围已实施；现行行为见[知识库契约](../../reference/knowledge.md)，实际证据见[实施记录](../../records/knowledge-library.md)。范围为多知识库页面、原始文件持久化、文本切片与 BM25、内置资料迁移；不扩展员工绑定或正式聊天。整体后续设计见 [Notion 导航](implementation.md)。

## 本轮闭环

1. 已登录用户创建自己的知识库，进入库内上传 UTF-8 Markdown/TXT；用户明确允许制作演示文档并替换旧静态差旅页面。
2. 原文件复用 files 的受控磁盘、摘要与配额；库、文档、切片和 FTS5 存业务 SQLite。库内文档引用加入保留集合，避免被附件清理器误删。
3. 小文本在请求工作线程内完成加载、切分与分词，解析不持有写事务；每文件最多 128 KiB，单库最多 200 文档/5000 切片。原文、切片、索引在同一短事务生效，失败不影响原有资料；暂不引入后台作业与人工发布步骤。
4. 上传以客户端 UUID 幂等；同库相同原始字节不重复入库。同名不同内容作为独立文档，不猜测覆盖关系。提供文档移除、固定原文/切片读取、原件下载和库内 BM25 测试。
5. 生成技术文档演示包；现有差旅包保持教学内容与来源，连同技术包通过显式样例导入接口、复用普通上传的入库服务导入。迁移操作可重跑，页面不导入静态正文，不在启动时给所有用户注入样例。

## 页面与边界

沿用现有设计系统和规章制度 Tab。资料 Tab 展示库列表，新建后进入文档列表；库内有上传和检索测试入口。来源通过库、文档和片段 ID 定位，刷新与返回保留 URL；游客显示登录引导，不读取私人库。没有 Embedding 时明确显示 BM25，不使用测试向量冒充真实检索。

本轮只开放有界纯文本，不将 POC PDF/DOCX 解析器开放给不可信上传。资料不会自动成为系统指令或进入员工上下文。当前立即原子入库与整体方案的候选构建/人工发布是不同阶段，后者仍未实施。

## 验收

- 新库上传真实字节，能读取原件和切片，BM25 只返回该用户该库证据；重开数据库后仍可使用。
- 重传幂等、错误编码/超限/无权限/错误库拒绝；失败不污染已有文档。原件清理后仍保留被知识引用的文件。
- 空库、失败、检索无结果、文档阅读、下载、删除和日夜窄屏可操作；规章草稿保护保持有效。
- 正式 Alembic 升级保留现有业务数据；演示导入记录实际接口结果与存储位置，不将测试替身当部署结果。
