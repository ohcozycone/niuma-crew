# 功能范围与使用前提

管理员维护共享员工、模型、技能、工具连接和知识库；成员通过员工使用这些配置，管理自己的对话和考核。游客可只读浏览，不能发起工作或修改配置。

## 当前能力

| 要完成的事                   | 使用入口                 | 使用前提                                             |
| ---------------------------- | ------------------------ | ---------------------------------------------------- |
| 整理文字、分析材料、继续追问 | 员工主页的对话记录       | 已登录的管理员或成员，以及可接单、模型可用的员工     |
| 固定岗位职责与输出要求       | 员工配置                 | 管理员权限，在“指令与知识”填写工作指令并保存         |
| 复用方法与模板               | 能力库、员工能力装配     | 创建或导入技能，再为员工选用                         |
| 访问外部服务                 | 接入 MCP、员工能力装配   | 有效的组织工作连接、已确认的工具列表和员工操作许可   |
| 查阅组织资料并引用来源       | 知识库、员工参考知识     | 管理员完成分片索引，为员工选库并设置检索时机         |
| 处理文本附件、交付文本文件   | 对话发送区与回复文件入口 | 平台直接提供受控文件工作区；上传与工作区各有容量限制 |
| 处理二进制文件、运行程序     | 同一对话入口             | 部署者已配置并验收沙箱，代码执行显示就绪             |
| 检查函数调用提议             | 员工主页的员工考核       | 可用员工及固定 BFCL 题库；会调用真实模型             |

配置保存、连接检查、实际任务完成需要分别确认。模型目录检查通过后，再做一次文字对话；工具清单确认后，再核对实际调用；文件成果以下载后能打开、内容正确为准。

知识资料须先处理，再用于检索。附件上传与知识入库独立；向量索引需另行构建，没有向量的资料仍可使用关键词检索。

## 建设中的能力

员工主页的“任务记录”“定时任务”“长期记忆”目前显示建设中，不提供持续委托、定时或事件触发、跨对话记忆等操作。人工确认后可靠续办、经验复盘与组织资产正式发布也仍在设计。

普通对话支持已受理后的后台执行，以及符合条件的恢复和重试。关闭页面只停止观察；退出登录或会话失效会影响执行授权，不能据此安排长期代办。
