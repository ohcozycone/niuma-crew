规范版本：2.2。更新日期：2026-10-31。适用范围：日间／夜间界面与 `/signin`；数值以 [`theme.css`](theme.css) 为准，页面规则数据维护在 [`spec.ts`](spec.ts)，实际样板在 `/design-system`。

## 页面层级与列表摘要

本次调整设计已采纳，实现与本地验证已完成，视觉待用户审阅。

- 工作台没有独立首页，根路径进入数字员工。最小 48px 顶栏的一级页只显示当前模块名，不生成重复的父子层级；员工、技能二级页显示「所属模块 › 当前页面」，当前页文字不作为链接。外壳与对话页共用 [`PageBreadcrumb`](../components/common/PageBreadcrumb.tsx)。
- 对话详情及新对话属于「数字员工」工作入口，侧栏选中「数字员工」；独立 `/conversations` 记录列表仍选中「对话记录」。对话顶部按「数字员工 › 员工名」呈现，后面紧接 14px 问题图标与会话标题，未提问草稿显示「新对话」。员工名与问题分别截断，完整文字保留在提示属性中；不因窗口变窄隐藏问题。小于 640px 时操作区换至第二行，避免搜索、主题、历史和新对话挤压主信息。
- 二级页通过顶栏父级链接返回所属列表。来源为同一模块列表时保留搜索、筛选和分页；跨模块来源不改变面包屑层级，编辑页的「取消」仍按原有来源返回。未保存修改和保存中的离页保护统一由共享外壳处理。
- 员工编辑和游客详情不在正文标题上方另加返回行，列表和二级页的标题从相同的内容顶部位置开始；保留编辑页的取消、保存和删除操作。
- 管理员员工列表将数量放在状态标签右侧，全部员工标签显示独立读取的全局数量，右侧显示「共 N 位员工 · 本页 M 位可对话」。N 是服务端当前条件的匹配总数，M 限定为本页，可对话条件沿用员工卡片规则。后台刷新保留卡片和数量，追加简短更新状态；收藏、失败与分页同步见[员工模块](../pages/agents/README.md#目录读取与收藏同步)。
- 窄屏数量在标签下方换行并右对齐，不隐藏，不与标签挤占宽度；数量属于列表筛选摘要，随结果更新。移除管理员列表底部重复数量和常驻的持久化说明。

验证：隔离 SQLite、关闭模型执行的生产浏览器检查 12 组通过，覆盖一级层级去重、员工／技能／对话二级页、同模块筛选与分页返回、跨模块取消、未保存和保存中保护、长列表滚动恢复及游客详情。日夜主题在 320、390、600、601、1000、1440px 均无横向溢出，列表与员工创建页标题顶部位置一致；相关单元测试 29 项、TypeScript、lint、修改文件格式及生产构建通过。未实测 Safari／Firefox。浏览器记录与复现脚本。

## 颜色与层级

| 对象               | 使用令牌                                      | 规则                                                                              |
| ------------------ | --------------------------------------------- | --------------------------------------------------------------------------------- |
| 工作底与框架       | `canvas`                                      | 顶栏、侧栏与内容底连续；日间近白，夜间微暖深灰                                    |
| 卡片、输入、浮层   | `surface` / `card-border` / `border`          | 用边界和阴影建立层次，不给各区块另配大底色                                        |
| 正文与说明         | `text` / `text-muted`                         | 正文使用当前主题前景，说明清晰可读；不借用状态色或橙色降级文字                    |
| 主操作             | `action` / `action-hover` / `action-text`     | 日间暖墨反白、夜间浅色深字                                                        |
| 普通控件选中       | `selected`                                    | 当前主题中性阶，不与导航当前态混用                                                |
| 当前菜单           | `nav-active` / `nav-active-text`              | 中性背景，文字、图标和数量统一使用 text 前景                                      |
| 品牌文案与局部装饰 | `brand-text` / `brand` / `title-accent`       | slogan 使用陶土橙，收藏与小点使用铜橙，品牌辅助衬色保留浅橙，功能页标题不再加衬块 |
| 反馈               | `success*` / `warning*` / `danger*` / `info*` | 当前主题前景与反馈底成对，同时提供文字或图标                                      |

当前导航与已选 Tab 在悬停时保持选中的背景及前景；悬停颜色只作用于未选项，键盘焦点继续可见。展示页将导航、按钮、输入、Tabs 和浮层的说明放在对应示例旁，不再用页尾折叠表格重复归纳。

`theme.css` 的根声明和夜间覆盖提供同名语义映射；主题行为与首屏契约见[日间、夜间与跟随系统](../../../docs/reference/theme.md)。字号、布局与几何共享。`--gray-*`／`--night-*` 等基础变量构成色卡，不在业务组件直接选色阶。组件直接使用 `--os-*` 语义变量及其同名 Tailwind 类；颜色、圆角、字号和阴影由控件自身声明，全局规则负责正文、焦点与减少动态效果，无须 body 主题外壳。已批准角色原画的固有色是装饰例外。所有颜色分组与中文用途由 `spec.ts` 驱动展示，新增颜色须同步其用途及验证。

## 文字与排版

`--os-text-*`、`--os-weight-*`、`--os-leading-*`、`--os-tracking-*` 提供基础尺度；`--os-type-<角色>-*` 与 `type-<角色>` 工具类组合字号、字重、行高、字距与语义色。新增或调整共享文字优先使用完整角色，避免只选字号、其余属性各自决定。

| 角色          | 字号来源            | 字重                  | 行高                   | 字距                   | 颜色与用途                             |
| ------------- | ------------------- | --------------------- | ---------------------- | ---------------------- | -------------------------------------- |
| `page`        | `--os-text-page`    | `--os-weight-heading` | `--os-leading-heading` | `--os-tracking-normal` | `text`，功能页主标题                   |
| `section`     | `--os-text-section` | `--os-weight-heading` | `--os-leading-heading` | `--os-tracking-normal` | `text`，区块标题及窄屏页标题           |
| `title`       | `--os-text-title`   | `--os-weight-heading` | `--os-leading-heading` | `--os-tracking-normal` | `text`，卡片与内容单元名称             |
| `label`       | `--os-text-caption` | `--os-weight-regular` | `--os-leading-compact` | `--os-tracking-label`  | `text-muted`，品牌或资料分类的辅助标识 |
| `description` | `--os-text-body`    | `--os-weight-regular` | `--os-leading-body`    | `--os-tracking-normal` | `text-muted`，标题后的用途说明         |
| `body`        | `--os-text-body`    | `--os-weight-regular` | `--os-leading-body`    | `--os-tracking-normal` | `text`，正文及基础继承                 |
| `caption`     | `--os-text-caption` | `--os-weight-regular` | `--os-leading-compact` | `--os-tracking-normal` | `text-muted`，数量与附注               |

CSS 变量为 `--os-type-<角色>-size/weight/leading/tracking/color`，角色为 `page`、`section`、`title`、`label`、`description`、`body`、`caption`。字号输出 px，行高无单位，字距输出 em；基础变量继续兼容现有组件。`spec.ts` 提供角色用途和同源样板。新角色必须说明语义差异，不能仅为单个页面增加相近字号。

字体族沿用 `theme.css` 中的 `--font-sans`。中文标题保持正常字距；辅助标识用于品牌或资料分类，功能页主标题使用中文标题和下方说明。辅助层级通过字号、位置和字重建立，颜色继续使用已有可读的 `text-muted`。标题允许完整换行，说明不截断；`headingLevel` 只决定文档语义，不改变视觉大小。

## 导航与图标

导航常态直接复用文字和背景语义，未选项与轻量按钮共享中性悬停／按下色，当前态保留必要组件映射，由 `theme.css` 引用基础色卡；页面不直接取色阶或添加颜色常量。品牌橙继续用于品牌和收藏等局部识别，当前菜单改用中性背景。登录文案、收藏小点和状态反馈保留各自语义。

| 状态       | 外观与行为                                                                                                                         |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 常态       | `text` 深色标签，`text-muted` 灰色图标；数量使用 `text-muted` / `nav-count-bg`                                                     |
| 悬停       | `hover` 浅暖灰背景，尺寸、位置与字重稳定                                                                                           |
| 当前       | `nav-active` 中性底，`nav-active-text` 引用正文前景并同时用于文字、图标和数量；文字、数量统一 500 字重，数量去底框；不增加侧边色条 |
| 当前项悬停 | 保持当前态的底色、前景和字重，不退回普通悬停态                                                                                     |
| 键盘焦点   | 保留统一的可见焦点轮廓，不依赖悬停识别                                                                                             |

`--os-nav-weight`（400）与 `--os-nav-active-weight`（500）定义导航字重；数量继承整行字重与当前前景。`--os-nav-icon-size` 为 17px，`--os-nav-icon-stroke` 为常态 1.75、`--os-nav-icon-active-stroke` 为当前 1.75；描边为无单位数值，尺寸带 px。

导航日夜选中前景均引用 `text`，日间使用比悬停更深一级的微暖灰底，夜间使用 `selected`；原橙白配对的局部对比度限制已移除。管理员、游客、桌面侧栏、移动抽屉与规范样板共用同一套令牌。装饰图标设置 `aria-hidden`，链接含义由标签提供；导航尺寸、间距与焦点行为继续保留。

### 侧栏分区与账户入口

侧栏按顶部品牌／功能菜单、中间收藏列表、底部账户入口组织，不再显示「功能导航」标题。侧栏与移动抽屉中的 Logo 使用共享默认尺寸的 85%（约 134×34px），保持人物和字标等比缩放，品牌行与菜单行左边缘对齐，Logo 左对齐、帮助入口靠品牌行右端，两者为独立链接。品牌行高至少 40px、与菜单相隔 16px，侧栏顶部留白为 20px；尺寸由侧栏作用域控制。帮助使用 28px 的柔和浅底问号气泡，单侧小圆角承接角色与字标的圆润形态，保留 32px 点击区；颜色由已有品牌色、中性表面和文字语义变量派生。悬停和键盘聚焦时稍加强底色与字色，并通过共享 Tooltip 显示「使用指南」；焦点轮廓独立可见。帮助入口保留当前功能对应的指南地址并在新标签页打开；移动端放在导航抽屉同一位置。全局搜索入口位于右侧顶栏、主题控件左侧，保留搜索弹窗与 ⌘／Ctrl K 快捷键，打开时聚焦输入、关闭时焦点返回打开前的控件；1100px 及以下收为带可访问名称的搜索图标，给面包屑留出空间。正常高度下仅收藏列表占用剩余空间并独立滚动，收藏标题和账户入口保持可见；保留已有功能行和 40px 员工头像尺度。

收藏标题右侧显示加载完成后的收藏数量。列表使用透明轨道，静止时隐藏滑块；实际滚动时显示细圆角中性滑块，最后一次滚动后 700ms 隐藏，单纯悬停或聚焦不显示。始终预留滚动条空间，避免宽度跳动。窗口高度不超过 600px 时切换为整个侧栏滚动，收藏列表恢复自然高度；该滚动面沿用相同显示规则，避免嵌套滚动和底部入口不可达。

账户入口使用 28px 圆形首字头像、用户名／角色双行文字、右侧展开箭头，统一为至少 48px 的整行按钮；压缩上下内边距、双行间距及分隔线周围留白。管理员点击后向上展开菜单，退出项使用图标与文字，悬停／聚焦时使用危险色；保留键盘导航、Escape 关闭与焦点返回。退出期间防止重复请求，失败在菜单内反馈并允许重试；未保存配置继续使用现有离开保护。游客保留头像与身份说明，右侧直接提供「登录」，沿用退出游客会话后进入登录页的流程。

账户按钮的身份、头像、箭头和全部状态样式由 [`AccountMenuButton`](../components/auth/AccountMenuButton.tsx) 负责，正式账户与规范样板共用；分区由 [`Layout.tsx`](../Layout.tsx) 组织，退出流程仍由 [`AccountMenu`](../components/auth/AccountMenu.tsx) 负责；浮层通过 `components/ui` 的 Base UI 适配器提供，不新增认证接口或权限。

### 员工头像导航

收藏列表以角色本身作为识别元素：透明底、无外框、无额外内边距，保留完整 SVG 及其标志道具。通过 `AvatarBadge size="navigation"` 统一使用导航尺寸，不沿用普通小徽章的边框与裁剪。

尺寸与组合间距统一维护在 `theme.css`，使用 `--os-avatar-size`、`--os-favorite-gap/px/py/stack`。头像为 40px，名称间距为 12px，主链接内边距横向 8px、纵向 4px，行间距为 4px；高度由头像和内边距自然撑开。窄屏与长名称优先截断文字，头像不收缩；完整名称通过链接的 `title` 保留。

点击收藏行主区域进入员工主页。管理员可通过右侧 `MessagesSquare` 图标打开该员工的新对话页，使用 `/conversations/new?agent={id}`，不恢复最近对话；具体读取、失败与发送条件沿用[对话契约](../../../docs/reference/conversations.md#前端交互)。两个链接均保留来源与已有离页保护；游客不展示新建对话操作。

主链接与新建对话链接是兄弟节点，外层不响应点击。右侧对话入口始终预留，不被主链接覆盖，hover 不挤动姓名或改变点击范围；分隔线与留白区分入口，分隔处点击不跳转。常态对话图标和竖线隐藏；鼠标进入整行时同时显示，移出后立即隐藏，即使主链接仍保留点击焦点也不显示。键盘Tab直接进入新建对话链接时，仅该链接通过focus-visible显示自身和焦点轮廓；不使用淡入，不让透明图标接受鼠标点击。对话图标为 16px，描边沿用 `--os-nav-icon-stroke`，桌面点击区为 36px；对话按钮悬停时保持透明，通过共享 Tooltip 显示「新建对话」，可访问名称标明与哪位员工新建对话。无hover能力的触屏设备常驻显示，点击区为44px；有鼠标的混合设备不因存在粗指针而常驻展开。整行仅悬停时使用 `hover` 背景，移出后不因焦点保留灰底；Tab 依次进入主链接与新建对话链接，各自有可见焦点轮廓，不保留点击选中态。

正式侧栏与 `/design-system#agent-navigation` 共用 [`FavoriteAgentLink`](../components/navigation/FavoriteAgentLink.tsx)，头像保持装饰性，不重复朗读。六角色与长名称样板的主链接及对话入口进入正式员工列表选择员工，不把演示身份用作数据库 ID。实际验证见新建对话入口验收。

## Tabs 与滑动指示线

页面及侧面板的线型导航使用完整的 [`PageTabs`](../components/common/PageTabs.tsx)：传入 `label`、`items`、选中值和事件；组件负责整行基线、列表、标签、数量徽标、活动线和窄屏换行。`placement="page"` 为页内导航，`placement="panel"` 为面板导航；右侧数量/状态使用 `trailing`，不进入 tablist。调用方不重配内部 Header/List/Trigger 的样式，URL 和内容仍由页面管理。

底层 [`Tabs`](../components/ui/Tabs.tsx) 保留 Base UI 的受控／非受控选中、键盘和焦点语义，用于组件内部和分段选择。`TabsList variant="line"` 自动装配单个 `TabsIndicator`，页面不测量位置、不再使用每个 Trigger 的伪元素下划线；默认块状 Tabs 保持原有表现。

- 横向线型 Tab 默认按内容宽度排列，间距为 `space.6`（24px）；列表无内边距，Trigger 无左右内边距与边框，指示线贴合文字及数量徽标。页面/面板高度与内边距由 PageTabs 的 placement 统一决定，沿用共享指示线。
- 指示线由 Base UI `Tabs.Indicator` 提供，通过 `--active-tab-left/top/width/height` 对齐当前标签，项目只声明视觉与过渡；不另写测量、Observer 或动画状态控制器。
- 横向位置与宽度、纵向位置与高度直接消费库变量，绝对定位，不影响列表布局。快速切换、尺寸变化、隐藏后显示及焦点语义由库能力配合组件样式处理。
- 减少动态效果时关闭指示线过渡。受控值、URL 标签与内容显示仍由页面负责。

验收覆盖非首项默认值、受控和非受控、不同宽度、快速连续切换、尺寸变化、隐藏后显示、横纵方向、键盘与减少动态效果。浏览器逐帧采样和性能轨迹应确认首帧无过渡、最终几何对齐及动画空闲阶段无逐帧布局计算。实际结果见TabsIndicator 验证。

## 按钮与操作

页面级主操作放入 `PageHeading.actions`：标题与说明在左，创建、添加、保存等当前页面主操作在右，窄屏允许换行。搜索、筛选、刷新和批量选择贴近内容集合；上传区提交、失败重试、确认和取消仍在对应上下文，不把所有按钮集中搬到页头。用途说明不能占用 actions 槽。

**层级判断。** 先确定操作区域，再确定该区域要完成的主要动作。同类资源目录的页级创建入口统一为主操作：数字员工“创建员工”、能力库“添加”、大脑配置“新建大脑”和知识库“新建知识库”均使用 default。空列表、已有数据、搜索和筛选结果变化不改变这个层级。添加有多个类型时使用一个主按钮打开菜单，菜单选项沿用普通菜单样式。页级保存／提交是编辑流程的主操作，返回／取消是次操作；卡片、行内配置和查看按局部层级使用 outline／secondary，刷新和更多使用 ghost。禁用与加载表达可用状态，保留原来的主次身份。

| 类型                | 场景                                 | 视觉与状态                                                                                                 |
| ------------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| `default`           | 创建、提交、保存、登录               | 日间暖墨反白，夜间米白深字；一个操作区域突出一个主操作                                                     |
| `secondary`         | 列表中反复出现的继续入口，如“去对话” | 陶色浅底与同色系文字，使用 `action-soft*`                                                                  |
| `outline`           | 配置、返回、取消、资源卡片操作       | 内容表面与轻描边，无默认投影；悬停和按下逐级加深                                                           |
| `ghost`             | 日志、刷新、更多等辅助动作           | 无底、辅助文字；悬停 `hover` 浅暖灰底与 `hover-text` 略深前景，按下 `pressed`，`aria-pressed` 为陶色选中态 |
| `link`              | 行内跳转                             | 品牌文字，悬停下划线                                                                                       |
| `destructive-ghost` | 打开删除确认、移除装配               | 危险前景，悬停危险浅底，不变回普通文字色                                                                   |
| `destructive`       | 最终删除或放弃修改                   | 深砖红实心与浅色文字；普通取消使用 outline                                                                 |

**尺度与形态。** 普通按钮统一 8px 控件圆角，不为每项功能新造胶囊、圆形或独立色彩。标准高度 36px／文字 14px；行内 sm 为 32px／13px；重要入口 lg 为 40px；xs 为 24px／12px，仅用于引用等紧凑控件。图标通常 16px、xs 为 12px，放在动作名称前，外部跳转箭头放在名称后。纯图标按钮使用对应 icon 尺寸并提供可访问名称；粗指针下最小目标 44px。

**日夜配对。** 日间主操作为暖墨色，悬停和按下仅轻微压深；浅陶色按钮逐级加深、避免突然出现重色块。夜间主操作使用柔和米色，悬停略提亮、按下略压暗；危险确认使用深砖红，正文危险反馈仍用浅红前景。危险按钮通过 `danger-action*` 成组取色，不借用反馈文字色铺大面积背景。陶色按钮常态、悬停、按下保持陶色。一个组只出现一个实心操作；主提交与危险确认不并列，继续入口与选中使用浅陶色。

**状态。** Button 统一悬停、按下、键盘焦点、选中与禁用。传入 `loading` 后显示转动图标、保留动作文字、设置 `aria-busy` 并禁用，保留原动作配色，减少动态效果时不旋转；业务方继续负责请求锁与保存生命周期。普通禁用使用独立 disabled-bg／disabled-text：底色贴近内容表面，无描边；文字降为 400 字重，图标共用弱化前景，ghost／link 保持透明，不依赖整体透明度。可用 outline 保留边界与正文前景，不能与禁用态共用同一组表面／边界。fieldset 禁用和链接组合遵循同一规则。没有改动的保存按钮常驻禁用，请求中的状态不伪装为普通不可用。员工编辑的未修改状态在按钮内显示勾选图标与“已保存”，修改后切换保存图标与“保存配置”，请求中显示“保存中…”。其他不可用原因说明保持正常辅助文字的可读性。危险、成功等语义不互相借色。

**页面操作范围。** 资源目录的创建／添加是标题右侧的主操作，低频重新加载和维护统一放在同侧 PageActionsMenu。CollectionToolbar 只组织搜索、筛选和结果摘要：搜索桌面为 320px，窄屏铺满并换行，数量靠后；不把来源同步或全局管理混入筛选行。当前 Tab 专属操作属于 Tab 内容区域，不跨不相关页面职责；知识库与全员规范分别为独立页面。背景介绍合入页头描述，说明框只用于当前需要处理的提示。

**中性反馈。** `hover`／`hover-text`／`pressed` 为按钮、未选导航、账户入口和菜单共用的交互色，不借用导航选中或危险底色。无底按钮有柔和底色反馈；真正的行内链接保留下划线反馈。收藏员工行悬停使用同一浅暖灰底，右侧对话图标略微加深；已选导航持续保留自己的底色。主题日月插画按其品牌规范保持透明悬停。

**组合。** ButtonGroup 负责 8px 间距、对齐和按内容换行，保留调用方给定的动作顺序。编辑页辅助／返回在前、主保存在末尾，危险入口独立分组。员工编辑页将保存状态融入按钮，不在下方重复展示；按钮文字区域保留四个汉字的宽度，避免状态切换推动相邻操作。删除与返回／保存之间留 24px，窄容器收为 12px。DialogFooter 复用同一组合，取消在确认前；列表刷新与新建在集合工具栏，行内日志为 ghost、继续入口为 secondary。业务 className 只表达位置、宽度与必要内容布局，不另调按钮底色、投影、圆角、字重或字号。员工头像、主题插画、导航项和整行选择仍使用各自语义组件。

登录的提交、GitHub 和游客入口通过同一 Button，保留场景排版。正式示例见 `/design-system#buttons`，包含真实组件、尺寸、禁用／加载与编辑操作组合。

主题入口使用共享 `ThemeSwitcher`，位于工作台顶栏最右侧及登录顶栏；只保留日月图形与居中箭头，去掉底框、投影、色块和横线，悬停保持透明。A 由主体按钮定位在日月右下角，独立于箭头与触屏点击区尺寸。键盘焦点轮廓保留，模式菜单沿用共享浮层与选中语义。日月插画固有色由 `theme.css` 的 `--art-*` 登记，经 `--os-sun-*`／`--os-moon-*` 引用。三态操作与共享状态见[主题模式](../../../docs/reference/theme.md#切换控件与品牌)。

## 输入、选择与反馈

搜索使用共享 [`SearchInput`](../components/common/SearchInput.tsx)。会自动请求服务器的关键词输入显式设置 `debounceMs={300}`：文字即时回显，停止输入后才提交查询；清空或非输入法确认的 Enter 立即生效，Enter 不提交外层配置表单。中文等输入法组词期间暂停查询，确认后重新计时。外部查询值变化、禁用及卸载取消待提交输入；URL 保存已提交查询，分页由原页面在提交时归零。已发出的请求仍由原数据层取消或隔离结果，不在输入框中另建请求状态。

本地筛选使用默认即时模式（`debounceMs` 为 0）；普通表单字段、点击检索、保存、解析或预览后才请求的输入不加防抖。统一适用于员工目录、能力库、员工技能候选及全局搜索；未来新增远程搜索沿用同一入口。

下拉选框统一通过 [`SelectField`](../components/ui/SelectField.tsx) 使用：`options` 只维护一份 `{ value, label, disabled? }`，`label` 保留纯文字以支持已选显示与键盘文字定位；`icon` 放触发器左侧，装饰图标不进入可访问名称，箭头由组件统一提供。需要加载提示或简短已选名称时配置 `displayValue`，弹层定位通过 `contentProps` 配置。支持表单 `name/required`、触发器 ref、尺寸/宽度、禁用及 ARIA 属性。页面与共享业务组件不再拼装 SelectTrigger/SelectContent/SelectItem，不使用 option 子节点；底层 [`Select`](../components/ui/Select.tsx) 仅供 UI 内部适配。ESLint 检查底层依赖与原生 select/option，避免新增分散实现。操作菜单与主题单选菜单继续使用菜单语义。

选择弹层默认从触发器下方展开、起始边缘对齐，间距由共享 SelectContent 维护；不将已选项叠在触发器上，展开后仍能看清图标、当前值和箭头。弹层至少与触发器同宽，长选项按视口宽度换行，空间不足时由 Base UI 翻转或限高滚动。

普通字段使用 [`FormField`](../components/common/FormField.tsx)，通过 `label`、`description`、`error` 组织字段；组件为首个受支持控件建立标签/ID及辅助文字关联，保留既有 aria-describedby。现行 Input、Textarea、SelectField 和原生文本控件均支持；一项 FormField 对应一个字段。自定义复合控件需要先提供专用完整入口，不能假定任意自定义组件都能被自动识别。`FormField` 复用基础 `Field`、`FieldLabel`、`FieldDescription`、`FieldError`，沿用 [shadcn Field](https://ui.shadcn.com/docs/components/base/field) 的字段组合规范；Base UI 管理交互语义，业务页继续通过现有 `FormField` 接入，复杂字段按需组合。`Form` 提供 Base UI 表单语义，不另引入表单状态库。

- 标签常驻，占位符仅作示例；辅助说明放在同一功能组内。
- 常态使用主表面与 `input` 暖灰边界，两主题都从同源灰阶映射。Input、Textarea、SelectTrigger 聚焦时使用至少 3:1 的 `field-focus` 实色边框与 3px、50% 透明度同色外圈，鼠标和键盘均可见；与其他交互的键盘焦点兜底 `focus` 分开。Select 展开时保持外圈；无效字段聚焦时保留 `danger` 边框及 20% 透明度外圈。颜色来源见[颜色规范](colors.md)。
- Input、Textarea、Select 的输入边界使用 `rounded-field`（8px 普通圆角），不套全站的超椭圆形状。InputGroup 保留组合输入容器的现有半径，角形同样使用普通圆角。
- 搜索复用 Input；InputGroup 只在外层显示焦点，内部控件不重复描边。全局键盘轮廓仅为其他交互兜底，不能叠加到这些基础控件。页面不覆盖基础控件的焦点色、宽度和透明度；登录保留底线布局，由字段容器承接同一外圈。
- 无效输入设置 `aria-invalid`，错误文字通过 `aria-describedby` 关联字段；颜色不能单独承载错误。
- 移动端通用输入保留 16px，避免聚焦缩放；多行内容由 Textarea 承载。
- Select、Switch、Tooltip、Dialog 等交互统一走 `components/ui` 的 Base UI 适配，不在业务组件直接引入 Base UI。
- 加载、空态、失败与成功分别表述；错误提供重试并保留已有筛选或草稿。展示样板的反馈必须标明是示例。

线型 Tabs 的活动指示条统一使用 brand 陶橙，厚度 3px、顶端 tiny 圆角；常态标签使用 text-muted，不再用文字透明度减淡。PageTabs 及页面内 Tabs 共用实现。

## 卡片、标题与弹层

### 焦点与裁切边界

`overflow-y: auto` 也会形成横向裁切；不能只排查 `overflow-hidden`。表单、搜索结果、能力候选、文件目录和面板正文等可交互滚动区使用 `focus-gutter`，预留统一焦点空间并抵消外边距以保持内容对齐，同时设置滚动安全区。该空间覆盖输入 3px 外圈与全局键盘 outline；不要给贴边控件再套一层无留白的裁切容器。

Tab、贴边菜单项、收藏导航和密集问题刻度使用 `focus-inset`，将 ring 与兜底 outline 画到内部。键盘轮廓的偏移通过 `--os-focus-outline-offset` 同时作用于聚焦前后，避免过渡动画先把轮廓画到容器外。问题刻度在内部有焦点时取消首尾淡出蒙版。

只省略文字的裁切应放在文字节点；头像、插画、消息滚动和折叠高度动画保留必要裁切。富文本容器不为换行额外添加 `overflow-hidden`；代码/表格由自身滚动区处理，动画内容为内部交互留出边距。检查首项、末项、首尾 Tab、窄屏横向滚动和弹窗纵向滚动；仅检查控件本身的 CSS 不能证明焦点可见。

资源卡片、配置分区与占位表面的唯一底座及圆角接入范围，见[共享表面与圆角](surfaces.md)。员工、知识库、技能详情、能力目录和大脑卡片保留各自内容与业务回调，不再分别维护外框和阴影。员工与知识卡片共用 CardContent 的标准内容留白和 CardFooter 的分隔结构；内容布局及员工既有窄屏覆盖仍由业务组件负责。

| 组件              | 当前规则                                                                                                                                             |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PageHeading`     | 中文标题与说明纵向排列；使用 `page`、`description`，不增加标题衬块。右侧操作或数量，窄屏标题使用 `section`                                           |
| 员工卡片          | 通过共享 Card 使用 `radius.card`、`raised`、`card-border` 和 `shadow.card`；日夜外框均为 1px 实色边界，悬停使用 `shadow.hover`；人物圆拱只作局部装饰 |
| 知识库卡片        | KnowledgeCard 复用员工同源 raised/card 表面、交互阴影与内容/底栏；统一通用知识图标，标题和用途各两行，底栏显示文档数与更新时间，整卡链接保留完整名称 |
| 技能卡片          | 复用同一表面与阴影体系，查看态与能力装配态共用结构                                                                                                   |
| Dialog / 浮动菜单 | 继承根主题的表面、文字、边界和状态色，使用 `shadow.popover`；保留键盘关闭与焦点返回                                                                  |

间距使用 `space` 或引用它的组合 token，新文字优先使用完整文字角色，圆角使用 `radius`。不在页面覆盖共享卡片内部结构。员工背板统一使用 `--os-avatar-bg`，不按员工 ID 分配深浅；同一主题下颜色、圆拱比例和落位保持一致。

### 员工永久删除确认

员工永久删除使用站内 `Dialog`，明确显示删除对象、不可撤销的影响及保留范围；完整输入「确认删除」后才启用危险操作按钮。请求期间阻止关闭和重复提交，失败在弹窗内反馈，取消后重开需重新输入。业务流程与验收见[员工删除确认](../pages/agents/README.md#员工永久删除确认)。

### 员工卡片头像背板

设计已采纳，视觉待用户审阅。列表、编辑预览、游客展示与规范样板共用背板规则。

- 背板只承托人物，不延伸到姓名区域；通过 `--os-avatar-bg` 引用日间浅暖灰或夜间暖炭灰，同一主题内保持统一。具体映射以 `theme.css` 为准。
- 卡片头像容器常态为 104×112px，卡片容器小于320px时为 88×96px，人物与道具完整等比适配；仅调整卡片内展示尺度，导航与头像选择器使用各自尺寸。
- 圆拱宽高比约 1.45∶1；常态约 80×55px，紧凑约 68×47px，均在人物区域水平居中，并随人物缩小。上方为连续圆弧，下角为 8px 小圆角，不加描边、阴影。

- 员工 ID、岗位和状态不参与背板配色；人物、服装和道具承载角色差异。

### 员工卡片对话入口

卡片主操作统一显示「开始对话」，点击接续该员工最近更新的可见对话；没有历史时打开空白草稿。对话工具栏的「新对话」始终打开空白草稿，首条发送才创建服务端记录。可用状态、列表筛选和数量统计统一使用「可对话」，表示员工已启用且配置模型；不代表已验证凭证、额度或网络。暂停与未配置模型分别显示「已暂停接单」「待配置模型」，目录暂停筛选显示「已暂停」。

卡片底部操作使用共享 outline 按钮，两主题均为内容表面与轻描边、无默认阴影，图标采用 MessageSquare；目录创建是页级主操作，空目录与已有数据时保持一致。可编辑且未配置模型时，卡片按钮显示「配置模型」并进入正式配置页。编辑预览中的操作禁用；暂停与未保存配置时，无障碍提示说明开始对话的条件。只读且具有使用权的成员显示「开始对话」，游客仍显示「体验暂未开放」，不改变对话权限。

收藏与「更多操作」入口常显，不依赖 hover；编辑配置、暂停／恢复接单复用 DropdownMenu。暂停先确认，说明配置与历史保留；恢复直接操作。收藏请求期间仍可打开菜单和编辑配置，暂停／恢复项禁用，沿用原按员工串行的状态写入。键盘关闭或取消后焦点返回入口，触屏命中区沿用基础控件。

对话工作区使用紧凑姓名／标题工具栏，历史与新对话在右侧；角色展示在助手消息头部，不重复使用功能页大标题。输入默认两行，工作方式与发送位于下方操作行；输入组承担焦点边界。历史浮层复用独立记录页的列表，当前对话标记与分页均保留。交互契约见[对话与历史](../../../docs/reference/conversations.md#前端交互)，当前验收见布局记录。

用户消息气泡右上角使用 small 圆角形成小尖角，左侧使用 card 圆角，右下角采用更舒展的圆弧。问题锚点定位时仅改变气泡原有底色，不增加整行背景、外圈或光晕；底色使用 selected 与 text 语义色轻微混合后恢复，不改变布局，减少动态效果时关闭动画。完整交互见[对话契约](../../../docs/reference/conversations.md#前端交互)。

问题导航从三次用户提问起显示，使用紧凑细刻度；消息区可见的问答组对应刻度统一加长、颜色加深，允许同时高亮多项。支持独立滚动浏览，点击定位到提问，悬停／聚焦显示问答预览卡片。卡片复用 surface、border、text、text-muted、card 圆角与 popover 阴影；共用浮层平滑换位，内容轻微上滑进入，减少动态效果时关闭动画。可见性与定位边界见同一对话契约，实际视觉见布局记录。

### 员工卡片资源摘要

卡片底部按「技能、工具操作、知识库」顺序只显示非零资源数量，不合成能力总数；三类均为零时显示「未装配扩展能力」，并保留进入技能装配的入口。零数量不表示无法对话，简介缺省统一为「暂无职责简介」。数字使用等宽数字特性，标签与数字保持一组；对话入口保留，窄卡片允许底部换行。

列表、编辑预览、游客展示和规范样板共用 AgentCard。技能入口保留已有配置跳转，工具、智库为文字统计。编辑预览随草稿更新技能数及启用工具许可的操作数；计数不作为可编辑字段保存，智库仍为只读摘要。接口、数据来源与实体扩展条件见[资源摘要设计](../../../docs/reference/agent-resource-summary.md)。

### 员工卡片图文间距

员工列表、员工编辑页右侧预览和设计系统样板直接复用 [`AgentCard`](../pages/agents/AgentCard.tsx)，不在页面覆盖其内部结构。编辑预览不传 `onAction`，所以收藏、配置、启停及对话等操作禁用；外观布局仍由同一个组件负责。

人物与右侧姓名、岗位说明、状态之间预留独立空隙。`--os-card-gap` 为 12px，卡片容器小于320px时使用 `--os-card-gap-sm` 的 8px，均引用基础间距尺度。文字区域的起点由实际人物宽度加此间距计算，姓名和岗位允许省略，状态保持可读。完整人物轮廓和道具、现有上下排布保持一致。

纵向保留舒展的分组节奏：简介保留两行等高占位，维持不同内容卡片的底栏对齐；简介上下外边距、分隔线到操作区的内边距均使用 `space.3`，操作区到卡片底边使用 `space.4`。四周标准内边距使用 `--os-card-padding`（16px），卡片人物与背板使用上述展示尺寸；桌面和窄屏共用这一纵向节奏，底栏仍允许换行。具体数值由共享样式与基础间距令牌维护，规范样板直接复用。

本项设计已采纳，共享样式及三处使用场景验证已完成；视觉待用户审阅。

### 功能页统一标题

标题直接渲染完整文字，下方显示中文描述，不再使用橙色衬块或伪元素装饰。页面、区块、卡片标题分别使用22/18/16px，正文保持14px；窄容器页标题使用section角色。数值统一由theme.css提供。

组件不提供英文副标题。描述沿用 `description` 角色及 `description-gap`；`headingLevel` 只控制文档语义，`className` 用于聊天页等场景的外部布局。

页面通过同一组件获得字号、字重和窄屏行为。登录品牌排版、空态与权限错误等反馈标题维持各自语义；正文的区块标题不作为页面主标题处理。实际样板与正式页面同源。

### 页头组合间距

`--os-heading-*` 引用 `--os-space-*`；页面通过共享组件获得相同节奏，不覆盖其内部样式。

| token             | 基础来源  | 使用位置                 |
| ----------------- | --------- | ------------------------ |
| `description-gap` | `space.2` | 标题与用途说明之间       |
| `column-gap`      | `space.6` | 文字组与右侧操作之间     |
| `actions-gap`     | `space.2` | 操作按钮、数量之间       |
| `stack-gap`       | `space.4` | 窄屏文字组与下方操作之间 |
| `content-gap`     | `space.6` | 页头与后续筛选或内容之间 |

组件自身不设置外围内边距，由页面容器负责。600px 及以下操作移到文字组下方并左对齐；只有数量时仍保留右上角的位置，说明在文字组内自然换行。标题直接从中文起排。操作靠内容组顶部，不按整块页头的几何中心浮动。

本轮先将完整文字角色接入主题正文、共享页头与规范样板；其他既有组件继续使用基础 token，后续实质调整时迁移。品牌登录、富文本回答及独立插画展示的专用排版不在本次统一范围内。

## 品牌、登录与动态效果

对话执行过程的阶段图标使用 `--os-motion-swap`（280ms），保持 20px 槽位和 16px 细线图标，旧图标快速淡出，新图标短暂错峰后从右侧轻移进入。完成图标为 MessageCircleCheck，不放大或添加成功底色；初次历史展示及减少动态效果时静态呈现。状态、并行工具与防抖规则见[对话契约](../../../docs/reference/conversations.md#前端交互)。

帮助页 `/help`、`/help/:topic` 顶栏的品牌沿用侧栏尺度（共享默认尺寸的 85%，约 134×34px）；右侧「design」链接在当前标签页进入 `/design-system`，沿用该页身份校验。

共享 Logo 由同一矢量稿生成，系统字母静止、仅眼皮低频活动，减少动态时静止。登录使用原生轻量页面与独立布局令牌，沿用底线输入和固定反馈槽；错误不推挤主按钮，表单不等待动画。slogan 的橙色属于固定品牌强调，不直接推广成普通小号正文色。页面缩小或调整字号时需重新核对可读性。

登录右侧的紧凑表单与第三方图标分组由[登录页设计](../../../docs/reference/signin.md)维护；圆形 GitHub 图标引用现有文字、边框与焦点语义，不新增品牌专用配色。

## 能力库与员工装配

能力库的“添加”菜单位于 PageHeading.actions；搜索、类型筛选、查询结果数量与刷新放在内容工具栏。窄屏搜索独占首行，其他控件允许换行；刷新只读平台目录，不连接远端。添加菜单按能力命名为“添加 MCP 服务”“新建技能”“导入技能包”，有权限才显示可用操作。对象标识、选择与启停、移除与删除的含义统一遵循[对象、动作与确认](resource-language.md)。

管理员的“同步目录技能”是独立次要操作，与刷新列表区分；弹窗展示实际后端目录、同步动作与逐包结果。MCP 新建只保留一张表单，“快捷导入”位于服务信息标题右侧，用现有 Dialog 承接 JSON/文件；多项配置先选一项，覆盖已有草稿需明确勾选。错误留在弹窗，解析不启动程序；密钥在同页访问设置中以秘密输入显示。标题右侧主操作为“保存并测试”，保存和连接失败分别说明，首次工具确认保留在结果列表中。窄屏弹窗限制视口高度并内部滚动，操作不溢出。

正式能力库与规范样板复用 `components/skills/CapabilityCard`：名称、两行等高摘要、底栏；底栏左侧是类型图标、文字与定义启停，右侧是“查看配置”轻量操作。定义启用不代表员工已装配或使用者账号就绪。内置工具作为次要管理入口。

员工能力装配共用混合列表、全部/工具/技能筛选、搜索与分页，每页最多六项；MCP 按实际账号连接显示操作数量。添加能力使用同一候选面板，候选列表独立滚动，筛选和搜索保持可达；技能候选按服务端批次分页，工具按可管理连接显示。配置时才展开具体工具或参数。面板完成更新员工草稿，页面主保存才提交；取消、Escape 或关闭丢弃尚未完成的面板修改。移除装配先明确确认，只解除草稿中的关系。候选目录发现和中文别名编辑留在能力库。

共享 `DialogContent layout="side"` 沿用 Base UI 的焦点约束、键盘关闭与焦点返回，桌面右对齐，窄屏占满宽度；标题、滚动主体和底部操作分开。普通 Dialog 默认居中，并由 DialogContent 自带最大高度和纵向滚动，调用方无需再补 overflow-y-auto。`/design-system#patterns` 展示正式能力卡片、轻量下划线导航与侧边面板，使用独立样例数据，不写业务配置。

员工基础配置在同页完成名称和大脑选择，沿用标准 Input/Select，不另设姓名下划线输入或两行大选择器。头像用 72px 现有角色、弱化背板，点击更换打开原选择器；分类和简介使用同一字段体系。宽容器显示右侧正式员工卡片预览，小容器收为预览按钮。大脑说明通过 aria-describedby 关联控件，刷新不清空已有选择；管理在新标签页打开，刷新反馈加载和结果。指令与知识页以指令编辑为主区、知识资料为辅区，继承规则紧凑折叠；知识绑定尚未接入时清楚说明当前作用。三个 tab 共享一份草稿与主保存，保存异常定位到相关 tab。

## 列表分页

[Pagination](../components/ui/Pagination.tsx) 沿用 shadcn/ui 的 nav/list/item 组合，页码使用项目 Button 适配层的 ghost/outline 变体，当前页设置 aria-current="page"。前后页仅显示 Lucide 左右箭头，中文可访问名称为「上一页」「下一页」；边界与加载使用原生禁用状态。省略号不可交互且不参与辅助技术朗读。日夜、焦点、紧凑与触屏目标尺寸沿用 Button。

员工目录查询使用「筛选员工」，搜索名称、职责或技能，作用于服务端全部匹配结果；与顶栏跨员工和技能目录的「全局搜索」区分。分页放在搜索/岗位筛选工具栏右侧，少于两页时隐藏；空间不足时换行，页面容器小于 400px 时保留当前页与两个箭头。总页数和页码在同一组，查询总数继续由 Tabs 摘要表达。接口/URL 状态由页面负责，基础组件不持有业务查询。正式组件交互样板位于 `/design-system#pagination`。

## 对话历史表格与员工编辑

历史全量列表使用 Table 原生组合和 ConversationTable 业务列；工具栏复用 SearchInput、SelectField 与 Button，集合使用 raised／border／panel，无每行大图标及额外卡片嵌套。主题占剩余空间，状态、双日期和两项文字操作对齐；按实际容器宽度在 800／600px 变化，侧栏用紧凑历史行。状态用语义前景加图标／文字，不能将非运行状态全部当成功。

主题下方显示可选取的 Conversation ID 和最近 Run ID；搜索支持主题及完整 ID，命中旧 Run 时显示「命中 Run」。执行日志使用 Dialog workspace 容器，首屏显示执行结果、用量、调用概况与错误定位，再提供路径和步骤证据。右侧按实际证据决定栏目，仅多项内容使用 PageTabs；单项直接展示，思考文本默认折叠。结构化对象通过 JsonInspector 提供只读折叠与复制，主题使用现有语义颜色。完整边界见[执行日志契约](../../../docs/reference/execution-evidence.md)。

错误定位区用紧凑数值对照呈现请求上限、实际输出、思考占比和步骤消耗，计算口径收于折叠说明。阶段消耗使用共享 Table，失败行使用 danger-bg，窄屏允许表格局部横向滚动。知识工具返回使用按序可折叠的命中列表，首项展开，展示来源位置、正文及来源标识；正文复用安全 Markdown，原始 JSON 保留在折叠区。

workspace 弹窗不继承普通 Dialog 的外层 padding，由各自标题栏和滚动正文负责内容留白。执行日志的标题栏仅保留标题、关闭按钮和全宽下分隔线；正文滚动轨道距容器边缘 8px，内容与轨道之间另有内边距，使用稳定槽位。对话／执行／提问编号用中性浅底、中文标签及可选取的等宽数值分组，员工、模型与配置版本另行排列。

员工工作指令使用暖白主编辑区，个人知识摘要和自动继承制度为辅助区；独立保存边界明确。装配行与添加侧栏共用能力图标、基础控件和当前日夜主题，技能可连续添加，工具先配置许可；保存配置常驻，未修改时禁用。交互和数据契约见[员工模块](../pages/agents/README.md)。
