# 布局与响应式

按可用空间和阅读任务布局。外壳、页面、区块、组件分别拥有自己的空间，避免多层重复设置宽度、边距和滚动。

## 空间归属

| 层级 | 负责什么                               |
| ---- | -------------------------------------- |
| 外壳 | 导航、工作区、身份入口与全局反馈       |
| 页面 | 内容上限、页头、主要滚动和页面模式     |
| 区块 | 表单分栏、列表排列、主辅区域及局部滚动 |
| 组件 | 内部间距、文字截断、控件和焦点空间     |

尺寸引用[主题尺度](../../frontend/src/design-system/theme.css)，页面不逐层叠加同一种边距。普通页面保持一致起点，专用编辑器和阅读场景根据内容确定宽度。

## 响应可用空间

先根据内容确定最小可用宽度，再改变列数或分栏。卡片、表单和文件工作区按实际容器响应，不能仅以设备名称判断。窄屏优先改为单列、调整辅助区位置、减少次要信息；表格可以在自己的区域横向滚动。

筛选、分页和批量操作保持可见且顺序稳定。长名称、长错误、空结果和多条选择需要使用真实内容检查，不能只以短文本确定布局。

## 阅读与编辑

对话保持正文和辅助信息的主次关系，窄空间将辅助区移到正文后，不建立第二份交互作用域。编辑器让字段和主要操作可达，固定页头、页脚及浮层不能遮住聚焦对象。

页面与局部区域分别明确滚动所有者，避免无意义的多层滚动；切换与历史定位遵循原页面交互规则。

## 查阅与验证

文档站示例复用[正式展示入口](../../frontend/src/pages/design-system/DesignSystemPage.tsx)及其组件。修改布局验证宽窄容器、滚动、浮层裁切与键盘路径，确认信息顺序和操作资格保持清楚。
