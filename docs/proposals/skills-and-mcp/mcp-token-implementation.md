# MCP Token 接入实施增量

设计状态：已采纳。实施状态：已实现 Token 范围；验收见当前记录。更新：2026-10-28。

本轮依据用户最后确认的范围：共享员工定义、创建后可使用、不复制员工；使用者绑定个人连接或使用明确共享的连接。仅支持远程 Streamable HTTP、无认证、Bearer Token、自定义认证头。OAuth、标准 Skill 包安装、本地 stdio 和独立沙箱服务不在本轮实施。旧方案的私人员工、员工广场、发布与复制不是本轮前置。

## 模块与边界

- tools 拥有 MCP 服务定义、账号连接、加密 Token、候选/确认目录、展示别名、配置导入与远程请求。服务不保存 Token；目录归具体账号连接。
- agents 拥有共享员工、作者、操作许可、账号使用方式；个人绑定只关联使用者与该员工的许可，不复制员工、Skill 或工作流。
- conversations 在准备 Run 时依据实际使用者解析连接；execution/agent_runtime 继续承担记账、授权复核及调用，不取得 Token。没有个人连接时保留工具说明，真正调用时返回连接提示，不阻止普通对话，不自动换用作者账号。
- 前端能力库统一展示 Skill/MCP，MCP 详情负责新增、导入、账号与目录更新。员工配置只选择已确认操作和账号方式；个人连接页只改使用者绑定。

## 关键流程

1. 创建服务定义，手填或导入 mcpServers JSON；只接受平台支持的 HTTP 配置。导入不执行代码、不访问远端，不保留原始含密钥文本。
2. 创建连接，Token 加密保存，默认个人连接。共享必须明确选择且由服务管理者创建。旧 MCP 连接迁为个人，旧员工许可改为个人模式，避免历史凭证被默认共享；原生工作区维持共享基础能力。
3. 读取候选目录，编辑展示名，确认目录。原始工具名、schema、定义摘要不可编辑；展示名不改变调用身份。相同目录确认不增加目录版本。
4. 员工作者配置工具开关、范围、预算和账号方式。提交具体定义摘要，拒绝陈旧表单静默授权新定义。新增工具默认关闭；删除、改名或定义变化不迁移旧许可。
5. 使用者个人模式只选择本人且属于相同 MCP 服务的连接；目录中的同名工具必须与员工批准的定义一致。连接变化/解绑在执行前复核。缺少连接时提示去连接页；Token 无法自动刷新，远端拒绝后提示更换，不自动重放业务调用。
6. 用户对话、附件、成果及沙箱继续按使用者/Run 隔离。普通成员可运行与管理本人 Token；只能作者编辑员工和服务，共享服务不代表共享秘密或其他用户的私有目录。

## 数据与兼容

新增 MCP 服务定义、个人工具绑定；连接增加服务归属、账号范围和展示标注；员工增加作者、许可增加账号方式。正式迁移保留原有连接、密文和历史快照；历史无作者员工只允许管理员维护。旧 Run 的既有 MCP 快照不能绕过新增的个人身份检查。

保持模块化单体和当前 SQLite；不引入微服务、OAuth 依赖或第三方存储。服务与连接、目录及员工装配分别保存；员工正文/技能/工具在员工编辑器内同事务保存。所有列表 GET 不访问远端。

## 验收

覆盖新旧库迁移、个人隔离、共享显式授权、员工作者保护、缺凭证聊天和调用、目录摘要冲突、连接变更撤权、别名不改调用、配置导入拒绝不支持项及秘密不回显；前端覆盖添加/导入、目录管理、员工装配和本人连接；静态检查、受影响测试、构建及文档检查。真实外部账号与服务可用性单独记录，离线替身不冒充真实联调。
