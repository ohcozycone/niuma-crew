# 身份与访问控制模块合并验收

日期：2026-10-26。适用快照：当前工作区。范围为 authorization 合入 auth、身份与权限文件分工、调用引用、文档和现有测试调整；没有改变数据库结构、HTTP 契约或角色权限。

## 实际改动

- Actor 搬入 [auth/actor.py](../../backend/app/auth/actor.py)，保留与 HTTP、数据库会话无关的不可变身份结构。
- 固定角色映射、操作权限与资源归属检查搬入 [auth/permissions.py](../../backend/app/auth/permissions.py)，仍为接收 Actor 和资源事实的纯策略。
- 账号、密码、OAuth 和登录会话继续由 auth 的原有文件负责；auth 包入口只声明模块用途，不聚合导出。
- 更新应用装配、HTTP、对话、执行、CI 和测试中的导入，移除旧 authorization 包及其 README，没有兼容转发入口。
- 合并模块说明，更新现行架构、工程手册、访问契约、学习入口、相关方案、历史记录的有效代码链接及两张架构图。
