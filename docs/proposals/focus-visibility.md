# 焦点轮廓与滚动裁切

设计状态：已采纳。实施状态：已实现。日期：2026-10-31。

修复输入焦点、键盘 Tab 导航和列表选中反馈在 overflow 容器边缘被裁切的问题；保持既有中性灰外圈、普通圆角、选中语义与业务行为。

1. 表单与可交互列表的滚动区通过共享 `focus-gutter` 留出 8px 焦点空间（复用现有间距令牌），抵消外边距以保持内容对齐；保留滚动、最大高度和弹窗头尾布局。
2. Tabs、密集目录项等贴边交互通过 `focus-inset` 把 ring 和键盘 outline 画到内部，避免为每个控件添加单独补丁。问题导航的淡出蒙版在键盘交互期间关闭，避免吞掉首尾焦点。
3. 只裁切文本的省略、头像和插画、对话滚动、代码及动画高度裁切按用途保留。执行过程面板保留动画裁切，内部为交互预留足够边距。
4. 核对共享控件、弹窗表单、搜索/能力列表、技能文件目录、收藏导航及带交互的长内容；以真实组件的滚动边界几何、键盘路径、日夜主题及窄屏检查验收。记录实际覆盖，未覆盖业务状态不声称完成。

现行规则已合入[组件规范](../../frontend/src/design-system/components.md)，实际结果见[验收记录](../records/focus-visibility.md)。
