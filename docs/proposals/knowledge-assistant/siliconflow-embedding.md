# 硅基流动向量检索接入

状态：已实施，2026-10-31。现行规则见[知识库契约](../../reference/knowledge.md#硅基流动向量接入)，验证见[实施记录](../../records/siliconflow-embedding.md)。用户已授权接入，目标是在页面保存 Key 后即可测试并建立本人知识库的向量索引。

## 本次增量

1. 复用加密模型连接，新增固定地址 `https://api.siliconflow.cn/v1`、固定模型 `BAAI/bge-m3` 的 embedding 预设；不能装配为员工聊天模型。连接测试发送固定的非业务短文本，验证实际向量响应。
2. 知识库检索页列出管理员启用的向量连接。用户显式选择连接并建立索引，此操作会把当前库的片段发送给该服务；成员只能操作本人库，不取得 Key 或管理模型的权限。
3. 向量存储在现有 SQLite 的独立派生表中，按余弦相似度精确检索，沿用每库 5000 片段上限。首版不新增 Chroma 服务、后台作业、员工挂载或模型问答。
4. 构建在写事务之外执行，有请求时限、批量上限、并发限制及响应校验；发布时复核资料、索引版本和模型/凭证修订，完整索引原子替换，失败保留旧索引。上传、移除或模型配置变化使旧索引过期；Key 轮换不改变向量空间。
5. BM25 与向量为用户可选模式；向量未建立、过期或服务失败均明确报错，不静默切换。构建为同步有限请求，断线后通过重新读取状态确认结果，进程退出不恢复未完成构建。

## 验收

覆盖模型凭据加密与不回显、聊天/向量能力隔离、所有者权限、旧库升级、向量响应损坏/超时/限流、部分失败、构建中的资料或模型变化、并发构建、维度及来源一致性、前端保存/建索引/检索及失败恢复。没有用户凭据时不宣称真实硅基流动调用通过。
