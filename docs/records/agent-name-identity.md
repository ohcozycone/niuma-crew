## 同日：名称校验反馈位置

用户要求名称错误紧贴字段，避免页面顶部提示占位。员工表单将 `agent_name_conflict` 映射至名称字段，与空名称校验共用输入框下方的条件提示；无错误时不渲染提示元素，修改姓名立即清除旧错误。其他标签提交时切回基本信息，在标签内容挂载后聚焦姓名输入框；错误通过 `aria-invalid` 与 `aria-describedby` 关联。

Chrome 夜间桌面实测创建重名和改名重名：页面仅有一个错误提示，位于名称输入框同一字段内且紧接其下；输入框聚焦、无效标记及描述关联正确。修改名称后提示节点消失、无效标记清除；从工作指令标签保存也能返回并聚焦名称。仅提交被后端拒绝的重名请求，没有新增员工或保存改名，测试草稿已还原。

`make lint-frontend`、类型、格式与文档检查通过。首轮前端 267 项测试和生产构建通过；复跑时工作区已有 271 项测试，其中 270 项通过，`ConversationOutline.test.tsx` 中查找“1 问题 1”按钮的用例失败，本次未修改该模块。构建保留既有大包体积提示。本次未单独覆盖日间、窄屏或其他浏览器。
