# 颜色与主题

颜色数值与日夜映射只在[主题样式](../../frontend/src/design-system/theme.css)维护，用途由[规范定义](../../frontend/src/design-system/spec.ts)登记。文档站的真实示例展示计算值，本文不重复维护色值表。

## 按用途选色

| 层级     | 作用                                             |
| -------- | ------------------------------------------------ |
| 基础色   | 登记具体颜色，只由主题定义与色板直接使用         |
| 语义色   | 表达背景、文字、操作、边界和反馈，页面按用途选择 |
| 组件映射 | 表达必要的组件差异，复用已有基础或语义色         |

日间使用暖白与浅暖灰，夜间使用暖炭灰与米白，陶橙承担品牌强调。相同语义跨主题保留，头像与品牌插画的固有颜色不整体反转。语义相同才合并变量，不能因为某个主题恰好同色就合并用途。

## 状态与可访问性

正文及辅助文字对比度至少 4.5:1，焦点与必要控件边界至少 3:1。成功、警告、危险与信息使用各自前景背景配对，并同时提供文字或图标。主操作、键盘焦点与输入焦点分别复用现有语义，不在业务页覆写一套颜色。

## 页面与第三方组件

页面使用语义工具类或变量，不硬编码具体灰阶。文字与图标继承前景，浮层继承根主题；第三方渲染器通过主题映射接入，不复制颜色定义。新增映射需要说明实际用途并覆盖两种主题。

主题偏好、系统跟随和首屏由[主题控制器](../../frontend/src/state/theme/themeController.ts)统一处理，组件通过[主题订阅](../../frontend/src/state/theme/useTheme.ts)读取；主题偏好与身份数据分开，退出登录不清除浏览器主题。
