## 实现与迁移

移除 ORM、提交服务和执行输入中的重复起点字段。RunStore 从 Conversation 读取成功引用，按已固定消息 ID 加载上下文；执行协调和结果发布优先使用当前 Run 的执行存档，没有进度才使用会话引用。Run 的执行进度与公开输出字段保持分离。

新增正式迁移 [0002](../../backend/migrations/versions/0002_remove_run_base_checkpoint.py)，只删除该列，不改写 0001 或 SDK 自管结构。降级恢复列并回填活跃 Run；已结束 Run 的历史起点不再保留，不能自动还原。运行串行及成功提交规则保证活跃 Run 的会话起点不变。
