# 共享工程约定

供开发者与 AI 在跨端任务中使用。端内实现规则见[前端手册](frontend.md)、[后端手册](backend.md)，文档归属和代码、注释的分工见[文档规范](../documentation.md)。

## 任务与职责

从[任务索引](../README.md)读取当前契约、工程手册和受影响模块。先确认数据、规则和生命周期的所有者，再决定文件归属；只在出现实际复用或独立变化原因时提取公共能力。新增能力不预建空模块，不为所有 CRUD 套统一框架。

业务行为、权限和接口以现行契约为实施依据，源码与测试用于核对实际行为。发现差异时明确需求、实现和未知项，再修正文档或代码。方案是增量依据，历史记录是限定时点的证据，不自动覆盖现行规则。

## 运行与依赖

公共命令统一在仓库根执行 `make`，完整参数见[本地开发](../guides/local-development.md)及[后端操作](../guides/backend-operations.md)。跨端运行脚本放根 scripts，前端构建与资源脚本放 frontend/scripts。依赖分别由 uv、pnpm 与提交的锁文件管理；修改清单须同步锁文件。

生成文件的事实来源是生成器、元数据及正式源资源。修改来源后重新生成；已有生成文件豁免与源码检查范围以工具配置为准，不因排除产物而排除生成器。教学数据、设计展示 fixtures、验证替身与正式业务数据保持明确来源。

## 变更与验证选择

| 改动                     | 优先核对与检查                                                                      |
| ------------------------ | ----------------------------------------------------------------------------------- |
| 文档、移动段落、调整导航 | `make check-docs`、Markdown 格式、语义和状态核对                                    |
| 前端逻辑或 UI            | `make lint-frontend`、受影响测试；交付影响执行 `make build`，视觉覆盖相关主题和尺寸 |
| 后端参数、业务和权限     | `make lint-backend`、相关隔离测试，覆盖拒绝与回滚                                   |
| 表结构与迁移             | 新旧库迁移、数据保留、外键及模型差异检查，不能仅用 create_all 验证                  |
| 后台或外部调用           | 假适配器覆盖超时、取消、撤权、持久化失败和重启；真实上游结果单独记录                |
| 开发启动或静态交付       | `make test-dev` 或后端静态交付定向测试，按需使用隔离进程核对真实入口                |

完整离线检查由 `make check` 顺序执行文档、静态检查、测试和构建。选择与风险匹配的验证，不以机械重复全量测试替代缺失的边界场景。没有运行的检查不能写为通过，离线替身不证明外部服务可用。

## 注释与交付

局部竞态、兼容顺序和资源释放在代码附近解释原因，行为用测试证明；跨端契约及通用工程要求在 docs 维护。可稳定自动判定的规则由工具执行，手册说明实际覆盖范围。没有独立维护价值的实现细节不另写说明页。

交付说明实际变化、验证结果和未覆盖项；实施结果合入现行契约，实际验收进入 records。维护索引、模块入口与引用，不在 AGENTS 重复工程细则。
