更新日期：2026-11-01。基础配置、指令与知识布局及操作规则均已实施，按钮保持原页头右侧位置，见[验收记录](../records/agent-editor-layout.md)。

## 本次实施

- 保留现有品牌、主题、头像与组件视觉。员工配置采用居中限宽外框；指令编辑为主区，继承规则与知识入口集中在右侧辅助区，窄屏在编辑器之后排列。
- 三个员工配置页签在页头右侧提供操作。已有员工未修改时显示删除员工、返回；草稿与基准不同时增加保存配置，恢复原值后隐藏保存。新建员工没有删除入口，保留保存与返回以支持必填校验。
- 返回走已有路由与离页保护，保存与删除沿用原有提交、版本冲突、删除确认及引用保护。保存中禁用操作。
- 基础配置保留右侧完整员工卡片预览；左侧采用112px圆形头像，整张头像作为更换入口，右下角以14px、1.5px线宽相机图标提示操作。相机使用24px半透明圆底：日间灰底白图标，夜间偏白底深色图标，沿用action/action-text的明暗反转，圆底65%不透明度、悬停80%，不另加描边或阴影；取消黑色文字遮罩及重复的标签/按钮，保留“更换头像”的可访问名称。大脑选择放在头像右侧，以“大脑”标签、当前连接名称及下拉箭头表达入口，去掉重复名称和单独的厚重选框；模型标识与凭证状态常驻。选择结果只更新当前员工草稿，由页头统一保存。
- 基础配置保留左侧表单、右侧卡片的主辅结构，增加两栏间距及字段组留白；不再另设大脑区重复展示选择。窄屏按内容预算重排，当前连接的读取失败、未装配及凭证问题仍需显示。

## 验收
