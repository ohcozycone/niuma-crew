# MCP 与普通 Agent 上下文档案

本档案汇总独立单函数记录，仅说明当前调用与不变量；发现评级与修复建议见[主报告](../../mcp-agent-integration-review-2026-10-30.md)。

## 分析范围

- [capture_tools](functions/capture-tools.md)：账号目录、员工许可、发起者身份与 Run 快照。
- [execute_agent](functions/execute-agent.md)：提示、历史、工具准备、模型循环、checkpoint 和完成检查。
- [create_chat_model](functions/create-chat-model.md)：工厂、实际请求、工具绑定与 SDK 解析。
- [输出与历史](functions/output-visibility-and-history.md)：草稿、失败后投影、后续上下文。
- [发现与调用补充](discovery-and-call.md)：真实进程内 MCP 协议、定义摘要与参数策略。

## 跨函数不变量

1. 配置保存与远端发现分开；已确认目录和员工明确选定的定义摘要共同决定工具许可。
2. 普通 Run 使用发起者的具体账号；快照无凭据，实际调用仍检查当前账号、许可、参数、预算和远端定义。
3. snapshot.tools 的描述、输入 schema 与 exposed_name 形成真实 StructuredTool，实际模型请求确有对应 function definitions。
4. 普通模型可以不给出工具请求而直接 stop；平台只对明确 URL 阅读建立窄证据检查。
5. 工具失败被正确保存并交回模型；是否取得本轮必需证据并非当前通用完成条件。
6. 草稿不是正式正文。明确 URL 核验失败后正文为空、执行失败，草稿断言仅留在过程；失败轮不进入后续成功问答。
