# Agent 基础工具契约

结构以当前正式迁移及模型为准。平台已接入原生工具、HTTP/可信 stdio MCP、标准 Skill 多文件资产、持久文件与 OpenSandbox 执行接口；外部服务能否使用取决于凭证、网络和沙箱主机验收。实现入口为 [工具模块](../../backend/app/mcp/README.md)、[文件服务](../../backend/app/files/service.py)、[沙箱服务](../../backend/app/environments/service.py)及 [Agent 工具入口](../../backend/app/execution/runtime/tool_calls.py)。部署步骤见[接入指南](../guides/agent-tools.md)。

MCP 服务、Token、账号隔离与装配的当前规则见 [MCP 接入契约](mcp.md)。

## 连接、目录与许可

1. 按角色权限登记远程 MCP 或管理本人账号；可信 stdio 程序另要求管理员且部署已开启。支持 `mcp_http`、`mcp_stdio` 和 `native/workspace`；HTTP 认证为 none/bearer/header/oauth，stdio 环境凭据独立加密。OAuth 支持标准浏览器授权及按需续期；通用插件执行协议未开放，完整账号边界见 MCP 契约。
2. MCP 连接先发现候选，再按候选摘要、配置/凭证修订和有效期批准；保存连接、发现成功、批准目录、授予员工是不同操作。原生目录来自受信代码。
3. 员工工具许可归 `agents`，独立于 Skill。写入完整许可集合时检查员工预期修订，并与员工修订一起提交。每员工最多启用一份原生工作区连接；每个连接只授权明确工具，新增工具不自动授权。
4. 接受 Run 时冻结工具、schema/元数据摘要、许可及连接修订和范围，最多 128 项/256 KiB。模型名称由连接 ID 与工具名摘要消歧；平台文件工具使用保留名称。
5. 每次调用原子复核身份、许可、预算并保存动作，成功后才开始网络访问或创建沙箱。MCP 重新发现当前目录，比较包含输入/输出 schema 的原始定义及 SDK 元数据；变化后保存待审核候选并停止相应调用。网络等待后、真正调用前再次检查撤权与取消。

秘密不进入快照、目录或步骤；工具密文使用独立工具密钥文件（模型密钥路径追加 `.tools`），配置稳定环境主密钥时共同使用该注入密钥。已有工具密文时不会因文件丢失而自动生成替代密钥。SDK 实例按当前连接身份创建，不修改全局环境变量切账号。

连接配置或凭证变化后旧绑定失效。当前已使用工具的许可在周期检查与发布时也会复核，不能在撤权后继续发布成功。已经发出的外部请求不能保证撤回。相同描述/schema 的上游实现变更，以及检查和请求之间的外部竞态，仍不是摘要能够证明的范围。

## 工具范围与网络

模型工具指引按本轮快照生成：MCP 目录提供原操作名、实际调用名及待连接状态；文件操作逐项列出读写根目录，目录用途仅说明已许可区域。长结果读取说明仅随 MCP 工具提供，沙箱说明仅随 execute 提供；Shell 访问范围由沙箱环境决定，不以文件工具根目录代替。服务方说明仅指导对应连接的工具操作，不定义员工身份、岗位职责或通用回答风格。工具指引要求依据真实返回说明完成情况，搜索摘要与页面正文分别处理；实际许可仍由代码逐次检查。

原生许可采用 `mode=workspace`，分别选择 `/inputs`、`/sources`、`/workspace`、`/outputs` 的读取，以及 `/workspace`、`/outputs` 的写入。工作方法文本不授予权限。`execute` 只能出现在沙箱连接，并以本轮明确输入和独占环境作为边界；任意 Shell 不受文件工具参数检查替代保护。

外部工具采用 `mode=provider`：管理员负责受限上游身份，平台执行已支持的参数约束（maximum/maxItems/maxLength/enum），空对象不作为授权。Tavily 搜索限制结果数量，工具 schema 支持时关闭自动答案/全文；域名限制必须能通过已支持参数强制实施。网页读取每次最多三个公开 HTTP(S) URL，拒绝 URL 用户名/密码和明显私网目标。第三方服务最终如何解析 DNS、重定向或访问上游，不属于平台本机网络控制的保证。

MCP 管理地址支持 HTTP(S)，不维护部署域名或私网主机白名单；允许回环、内网及代理 DNS 映射，地址不能包含用户名、密码、查询参数或片段。传输固定本次解析的地址并保留原域名的 TLS 校验，拒绝链路本地（含常见云元数据地址）、多播和未指定地址；业务请求不能切换配置的协议、主机或端口；OAuth 发现、注册和续期按每个协议目标分别校验，不转发 MCP Bearer，详见 [OAuth 生命周期](mcp.md#oauth-账号生命周期)。不跟随重定向或环境代理，不支持由 schema 触发外部引用读取。响应以 identity 编码有界接收，目录另有限额。该接入方式允许访问后端可达的本机和内网服务，不提供内网访问隔离。

## 文件与交付

| 区域          | 当前含义                                                                |
| ------------- | ----------------------------------------------------------------------- |
| `/skills/`    | 本轮冻结的技能，只读；完整正文成功读取后才激活                          |
| `/sources/`   | 本轮已保存资料的只读投影；来源含 URL、取得时间、逐页状态及摘要/全文区别 |
| `/inputs/`    | 用户上传或从当前对话显式选择的文件，只读                                |
| `/workspace/` | 本 Run 的临时脚本和中间文件                                             |
| `/outputs/`   | 本轮待正式保存和发布的文件                                              |

复用 Deep Agents 的文件工具，只装配一套 `read_file`。完整路径路由保留原技能键，普通读取不记录技能激活。原生文件/命令调用在本 Run 内串行，共用预算；MCP 可以并行，但各自原子记账。虚拟文件使用官方文件状态与 StateBackend，单文件 128 KiB、可写工作区总量 512 KiB。代码 Run 从首次工作区操作起使用同一份沙箱文件，不能中途切换另一份工作副本。

文件工具只在存在获准原生操作或需要读取已装配 Skill 时提供。只有 MCP、没有 Skill 和原生文件许可的 Run 不附带 `read_file` 或空技能目录。Skill 带来的 `read_file` 只用于已捕获的 SKILL.md 及包内冻结清单中的支持文件；来源、输入和工作区仍需对应原生许可。未装配的普通文件操作报 `tool_not_allowed`，`/skills` 中未获准文件报 `skill_not_allowed`；已有文件工具超出根目录报 `file_path_denied`。

该工具暴露与来源读取边界由[读取能力测试](../../backend/tests/test_tool_readers.py)验证。

MCP 长结果保留有界预览并持久保存完整资料。派生的 `read_tool_result` 按当前 Run 结果编号分段读取，并复核来源工具当前许可，不授予宿主文件权限。只有原生 `read_file` 许可包含 `/sources` 时才披露文件路径。页面下载仍通过对话与文件关联独立授权。明确网页读取的发布核验、支持格式及限制见[运行契约](runtime.md#外部读取证据与长结果)。

上传使用有界原始字节，仍检查 Origin、登录身份和配额。选择输入时固定文件 ID、哈希、归属和路径；清单送入模型，原始大文件不塞入对话正文。首批验收 CSV、JSON、UTF-8 文本；二进制和大文件由沙箱程序处理。

文件字节先落入受控持久目录并校验，再提交元数据；输出先取回并保存，然后在发布事务内关联助手消息、正文和 Run 终态。下载必须通过当前对话权限及文件关联检查，使用 attachment/octet-stream，不返回宿主或沙箱地址。取消、失败和未发布的临时输出不能作为成功文件下载。

文件上限来自 `FileConfig` 和部署配置。当前缺省为单文件 10 MiB、每 Run 保存总量 40 MiB、每用户持久文件 256 MiB；保留存储空间余量。未引用输入、失败暂存和孤立字节按保留期清理；已发布关联、活动 Run 和已记录来源保留。文件服务通过注入的引用查询决定清理资格，不反向驱动对话业务。

## 沙箱与命令

来源文件的阅读投影会将超长行分成可按行定位的窗口，单次读取有字节上限；下载仍返回原始字节。该投影用于模型阅读，不替代原始结构化文件。

沙箱生命周期由 `environments` 维护，文件/命令 SDK 装配归 `execution/runtime`，最终文件归 `files`。管理操作不作为模型工具，管理密钥不进入工作负载。使用固定 digest/image ID、UID/GID 1000、只读 root 所有的输入目录及独占工作区；没有宿主 Shell 回退。

OpenSandbox 创建前先保存资源申请，成功后保存远端身份、归属与期限。创建结果未知时按请求 metadata 查询并保留资源债务，禁止盲建或恢复旧环境。命令时限最高 60 秒；日志、传输、文件、进程、CPU、内存、磁盘及网络各有独立约束。命令退出码未知不当成功；非零退出码在步骤中显示失败，模型可继续解释失败或采取另一项获准操作。

成功前停止工作负载并收集输出；所有退出路径都尝试销毁。销毁失败保留资源与失败次数，周期和启动清理继续重试，TTL 作为补偿；已可靠发布的文件不因回收失败消失。未知创建没有可确认的远端 ID 时保守占用容量，过期后可按指南人工核对。清理不依赖发起人的会话继续有效。

代码能力须配置目标 Linux 主机的当前验收依据；缺失、过期或不匹配时未就绪，其他能力仍可用。验收文件是受信部署者在主机上的观测依据，不是模型给出的证明；更改服务或隔离配置后必须重新验收。

## 预算、恢复与接口

新快照版本为 4，仍支持旧 v2/v3 普通聊天的现有恢复。工具总预算缺省 32 次，实际技能读取也计入，预加载只用技能预算；失败尝试不退还预算。已有只读结果仅在指纹、绑定、当前授权及 checkpoint 证据一致时复用。原生写入、沙箱工作区和首版外部工具 Run 在重启后中断，不自动重放；远端 readonly 注解不被当作纯操作证明。

| 接口                                                   | 用途                            |
| ------------------------------------------------------ | ------------------------------- |
| `GET/POST /api/tool-connections`                       | 列出/登记连接，仅管理员         |
| `PATCH /api/tool-connections/{id}`                     | 条件更新配置、凭证或启停        |
| `POST /api/tool-connections/{id}/discover`、`approve`  | 发现候选、条件批准目录          |
| `GET/PATCH /api/agents/{id}`                           | 随员工详情读取/整体保存工具许可 |
| `POST /api/files?name=...`                             | 有界字节上传，返回文件引用      |
| `GET /api/conversations/{id}/files`、`files/{file_id}` | 列出可复用附件、授权下载        |

发送消息的 `file_ids` 为可选数组；用户/助手视图增加 `files`，实际步骤保存结果引用和来源。对话、停止、重试和 SSE 保持普通入口，CI 试验接口已退役。前端管理页为 `/tools`，从员工能力装配进入指定员工许可；输入区负责上传/选择，消息负责下载，过程区展示真实来源。
