# 员工资源配置摘要

本文维护当前已实现行为。实现与测试入口见正文；未来能力仅作为限制或链接，不构成已实现承诺。

## 当前数量范围

当前技能按启用的 AgentSkill 计数，通用工具按启用许可中的明确工具计数；公共知识计数仍为 0。每员工每技能保持一份配置。

通用工具已随[基础能力](agent-tools.md)落地；个人知识库通过独立装配接口提供，按当前账号读取，不并入共享员工投影。

## 目标与范围

员工列表与编辑页预览的卡片底部按固定顺序展示「技能、工具、智库」三类实际配置数量；设计样板复用同一组件。「智库」与领域中的知识库是同一概念。此处只概括员工装配资源，不统计运行时权限、审批、预算、调用次数或模型数量。

当前共享技能和工具数量分别来自启用关联及实际许可操作。知识采用当前用户使用共享员工时的个人装配，独立于共享员工配置，因此公共resource_counts.knowledge_bases保持0，不泄露其他使用者私有库数；“我的知识库（N）”显示当前用户的实际挂载数量。共享卡片的预留数不代表个人装配数量，也不根据演示资料或岗位名称推算。

工具配置与执行的详细规则见[基础工具](agent-tools.md)，本页只维护配置计数含义，不统计实际调用次数。

## 后端职责与实体边界

员工接口的读取模型增加只读 `resource_counts`，管理接口和游客展示接口使用相同来源。技能数量由当前 enabled=true 的 agent_skills 计算；AgentService 已批量读取当前页关系，不增加逐员工查询。

数量是配置关系的派生值，不给 Agent 表增加可编辑的 `skill_count`、`tool_count`、`knowledge_count` 或 `has_*` 标记，也不添加无有效目标实体的 ID 数组。工具关系由迁移 0006 建立；数量仍为只读聚合，不另存可编辑计数。

工具按启用许可中的操作数合计，同一许可内操作不能重复；MCP服务或账号连接数是另一指标。个人知识由knowledge自己的设置/关联维护，最多10库，数量按库而非文档或工具计数；独立接口返回当前用户的选库，修改不会伪装成共享员工资源变化。团队共享和公共知识计数尚未设计，不用个人数量替代公共投影。

## 读取与保存契约

详细接口字段在员工接口文档维护。响应示例：

```json
{
  "resource_counts": {
    "skills": 2,
    "tools": 0,
    "knowledge_bases": 0
  }
}
```

三个字段均为非负整数；全部员工读取及写入成功响应包含此对象。POST/PATCH 不接受 `resource_counts`，客户端不能写入统计值；未知只读字段继续返回 422。游客响应仅增加安全计数，不暴露凭证、工具参数、模型连接或工作指令。

## 兼容与投递

资源数量是基于当前配置的只读投影，不新增计数字段。前后端只使用当前 DTO，结构与初始化见[数据模型](data-model.md)。

## 前端与交互

配置读取时保留后端工具、智库计数，编辑草稿不编辑或提交这些计数。列表将其映射为统一 AgentPresentation；编辑预览的技能数随当前草稿的选择与启停实时重算，工具数按草稿中启用许可的操作数重算，智库保持已读取值，未配置时为0。保存响应替换本地配置后，列表重新使用后端结果。

共享卡片底部按技能、工具操作、知识库的顺序仅展示非零分类摘要；三类均为零时合为「未装配扩展能力」，仍可进入技能装配。隐藏零数量只是展示规则，DTO 三字段继续完整返回，零数量不限制对话。非零技能入口保留原有跳转，工具和知识库统计保持文字展示，独立工具许可从能力装配中的正式入口配置。编辑预览沿用禁用操作；游客复用同一卡片和公开投影。对话入口保留，窄卡片按需换行，无内容重叠或截断数量。

## 员工个人页统计

`/agents/:id/home` 在简介下方展示三项真实数据，文案为「N 技能」「N 知识库」「N 轮对话」。技能使用公开投影的启用技能数量；知识库使用当前账号为这位员工装配的库数，由 KnowledgeStore 订阅读取，独立于公共知识预留数；对话使用[对话统计](conversations.md#员工完成轮数)的当前可见范围内成功问答轮数。统计不包含任务交付数量。

统计项按内容宽度紧凑横排，使用日夜语义底色与陶橙资源图标，图标、数字和简短标签在同一行；空间不足时整项换行。窄屏头像与姓名并排，简介和统计排在下方。栏目复用原有 PageTabs。大数量使用紧凑中文单位，保留 `data` 原始值和完整数字提示。游客仍可查看技能，其余两项显示登录后查看；已登录但缺少对应权限显示暂无查看权限，不请求相应私有接口。初次读取以省略号表示，失败显示独立重试，不伪装成真实 0。身份、权限或员工改变时旧响应不能覆盖新内容。

有员工配置查看权限（`agents:read`）时，「技能」整项可点击进入当前员工编辑页的「能力装配」（`tab=capabilities`）；「知识库」在同时具备个人知识读取权限时进入「指令与知识」（`tab=instructions`）。可点击标签仅在整项悬停或链接键盘聚焦时显示品牌色文字与下划线，常态无下划线，保留整项焦点轮廓；纯统计项不显示链接效果。沿用正式编辑页，保留个人页完整 URL 为返回来源，数量为 0 时仍可配置；无对应权限时继续只读展示。「轮对话」不跳转，知识数量读取失败的重试按钮独立操作，不触发配置导航。

界面、统计和权限的实际覆盖见员工个人页验收。

## 验证与验收

- 后端：真实临时数据库验证空配置、多技能、解除、替换、幂等绑定和重新读取的计数；管理与游客响应一致；统计字段不能被 POST/PATCH 篡改；OpenAPI 标记只读。
- 前端：API 字段映射与写入白名单；预览技能变更、保存后回显；三类计数不混用；共享组件在列表、预览、游客及设计系统一致。
- 浏览器：桌面、窄屏、长姓名和大数量、键盘入口及两种主题（如当前已接入）无布局溢出。样板数据与真实后端验证分开记录。

## 历史验证入口

历史检查的日期、范围和限制见实施与验证记录，不作为本次重新验收。
