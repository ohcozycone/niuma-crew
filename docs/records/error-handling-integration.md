## 独立评审与修正

两名审查者先分别审前端与后端方案，修正后均pass，再分工实施；完成后交叉复核后端交付和中央模型，最终均pass。

| 实质问题                           | 修正                                                                |
| ---------------------------------- | ------------------------------------------------------------------- |
| SSE撤回无原因就退出身份            | 先重核身份，只在真实身份401时结束会话                               |
| 非预期Error或不合法元数据穿透UI    | 公开字段白名单；未知异常安全文案；ID/deadline/issues校验            |
| 非法HTTP日期、带自定义reason的取消 | 规范日期roundtrip；依调用signal区分主动取消与超时                   |
| 明确配置503误判成提交未知          | 已知配置拒绝保留原因；未知写入只提供核对策略                        |
| 响应开始后原异常可能进服务器日志   | 记录安全帧后在except外传播无原cause/context的安全异常，不发第二响应 |
| 资源请求可能收到错误HTML           | 精确文档导航判定、资源/点路径排除，缺静态错误文件保持原404          |
| Vite改写入口标签导致启动监听遗漏   | 支持生产module标签并覆盖解析阶段；真实React提交才清理观察器         |
| 代理warn日志可能包含OAuth查询参数  | 默认不持久化访问/错误日志，先过滤敏感内容才可另启日志               |
| SPA404混入HTTP事实                 | `client/status=null`，展示层独立逻辑404                             |
| 等待提示每秒进入读屏警报           | 页面和局部消息组单独alert，计时与操作不在其内                       |
