# 运行配置集中管理验收

日期：2026-10-24。范围：本次工作区的后端配置、执行预算、快照及相关文档；快照协议为 schema 6，未改变数据库结构。当前规则见[运行契约](../reference/runtime.md)，取舍见[实施方案](../proposals/runtime-configuration.md)。

## 实际改动

1. `recursion_limit`、`max_model_calls` 和 `max_skill_reads` 从执行及提交代码迁入 RuntimeConfig；由 AppConfig 统一装配，沿用 `.env` 与进程环境的既有优先级。默认值保持原行为，字段有中文含义与单位。
2. 提交冻结三项预算，Agent 和中间件从快照消费；图步数耗尽归为 `agent_budget_exceeded`。计数配置拒绝小数、布尔值和非正数，时间配置继续拒绝非有限或非正数。历史 schema 1—5 可读，不由当前执行器重放；显式重试捕获当前配置。
3. 应用、数据库、认证、OAuth 和模型连接配置补充中文说明。各配置类按模块维护，由 AppConfig 汇总；环境变量示例和后端指南提供统一入口。
4. 集成检查发现 FastAPI 的文档路由缺少开头 `/`，导致应用无法创建；恢复为现行文档与测试使用的 `/docs` 和 `/openapi.json`。启动测试的旧 API 标题断言同步为已有的 NiumaCrew 名称。
