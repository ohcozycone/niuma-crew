## 正文与导航接入边界

日期：2026-10-31。范围：当前工作区的 ConversationPanel、ConversationTranscript、ConversationMessage、ConversationOutline 及其测试；保持原有历史读取接口与消息滚动器。以用户确认的最小接入设计实施，当前入口与协议见[模块说明](../../frontend/src/pages/conversations/README.md#问题导航与消息窗口)。

1. 页面通过 ConversationTranscript 装配消息区；其私有 useConversationReading 统一维护节点登记、可见问题集合、滚动、焦点及气泡反馈。移除原 useVisibleQuestions 源码和测试，以正文组件的集成测试覆盖这些行为；未增加公共 Provider、全局状态或更多独立 Hook 文件。
2. ConversationMessage 通过登记函数显式提交消息 ID、问题 ID 与节点；回复使用 reply_to_message_id 归组，不依赖 data-question-id 或 DOM 内容扫描。滚动器的 ref 转发不传递清理函数返回值，因此在 ref 接到 null 时显式注销；同 ID 的旧登记不能清掉替换节点。前插消息按 DOM 阅读顺序计算可见组，不能沿用 Map 的登记顺序。
