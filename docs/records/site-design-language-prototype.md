# 全站语义原型与设计交付核验

日期：2026-10-31。适用范围为[语义对照与迁移清单](../proposals/site-design-language-design.md)及本轮会话中的独立原型，不是正式业务页面迁移验收。

## 来源与版本

- 需求延续员工三个 tab 的已认可方向，以及用户对全站稳定识别和先交付计划的要求；需求状态位于 `.requirements/site-design-language/state.json`。
- 原型文件为本会话可视化目录中的 `site-design-language-preview.html`，不进入正式前端构建。
- 原型源码 SHA-256：`9f46a46595800bf6c6a2db73af5b9f050080ac7ef29579d48f06614a7c97c5c9`，大小 517838 字节。
- 员工头像复用当前角色源，知识库图形由现有已认可文件夹资源生成小尺寸预览，正式资产未修改。
- 本轮只写设计方案、需求状态和独立原型，没有修改正式组件、数据库、业务接口或账号配置，没有调用模型/MCP。

## 实际方法与结果

使用本机 Chrome、会话原型的本地包装页，通过页面点击、填写、键盘关闭、截图和只读 DOM 几何检查核验。覆盖 1024×900、1024×760、390×844、320×800 等视口；临时浏览器尺寸在结束时恢复。

| 项目           | 方法与观察                                                          | 结果                                                                                     |
| -------------- | ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 共享对象标识   | 对比能力库、员工装配、技能详情与对话选择/执行；检查生成后的图形类型 | Skill 使用 `lucide-puzzle`，MCP 使用 `lucide-plug`，保留相同类型名称；动作与结果文字另列 |
| 姓名与大脑同页 | 在基础配置核对两个字段及实际可见宽度                                | 320px 下两字段宽度均为 254px，处于同一 tab；卡片预览默认折叠                             |
| 员工草稿隔离   | 修改名称但不保存，进入对话，再返回保存后进入对话                    | 未保存时保持原员工名称；保存后显示新名称                                                 |
| 取消添加       | 添加候选技能后取消配置，检查装配数量                                | 仍为 8 项，没有误添加                                                                    |
| 工具操作校验   | 移除后重新添加搜索服务，空选操作提交，再选择一项完成                | 空选出现补齐提示；完成后摘要为 1 项操作，页面显示有未保存修改                            |
| 类型直达       | 点击技能筛选                                                        | 直接显示 4 个技能，无需滚过工具列表                                                      |
| 搜索空结果     | 输入不存在的关键词，再清空                                          | 显示“没有匹配的能力”；清空后恢复列表                                                     |
| 分页           | 全部 8 项，切到下一页                                               | 显示 7–8 / 8 项，前后页操作状态正确                                                      |
| 取消与焦点返回 | 配置面板按 Escape                                                   | 面板关闭，焦点回到原“配置”按钮                                                           |
| 知识规划入口   | 窄屏打开绑定面板并关闭                                              | 类型与文件夹标识保持一致，明确是规划预览；关闭回到绑定入口                               |
| 窄屏布局       | 390px 检查知识辅区顺序、编辑器和横向边界；320px 检查基础字段        | 知识摘要在指令前，编辑器高 300px；所查容器没有横向溢出                                   |
| 资源与脚本     | 核对图片解码、JS 语法、源码网络调用                                 | 所查图片正常解码；JS 语法有效；原型没有 fetch/XHR/WebSocket 调用                         |

设计检测器对由脚本赋予真实资源地址的图片产生静态“缺少 src”告警；浏览器中已实际检查图片加载成功，未将该告警记为静态检查全绿。

## 未覆盖与限制

- 未迁移正式页面，未验证真实保存、修订冲突、后端事务、外部连接、账号权限、资料授权、模型生成或知识引用。
- 30 项压力情景、连接待核对、空装配及图形/主题/密度切换已作为宿主设计控件候选提供，本次本机包装页没有逐项执行这些控件；不将其写为通过。
- 本次几何与交互检查不等于完整可用性研究；未覆盖 Safari、Firefox、真实触屏、屏幕阅读器和完整日夜状态矩阵。
- 技能示例参数、分页行数和本地定义编辑用于设计演示，不代表新业务契约、容量限制或真实能力已上线。
