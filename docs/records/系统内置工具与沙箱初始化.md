# 系统内置工具与沙箱初始化

本文记录此前的插件装配实现。文件与代码工具的产品形式已由[Agent 基础文件与沙箱](Agent基础文件与沙箱.md)取代；配套密钥初始化继续使用。下文验证只对应当时版本。

日期：2026-11-08。实施已完成，验证结果见下文；真实沙箱主机未部署、未验收。当前行为以[文件与环境契约](../reference/files-and-environments.md)及[部署指南](../guides/agent-tools.md)为准。

## 决策与职责

内置工具是产品提供的执行能力，Skill 提供工作方法，MCP 提供外部接入；三者统一展示，不合并权限和执行协议。系统内置不等于自动授予员工权限，也不等于环境就绪。

首版沿用模块化单体、Deep Agents 文件工具和 OpenSandbox 适配，不新增自研 Sandbox Service、专用等待队列、预热池、跨任务环境恢复或通用插件框架。

| 所有者                     | 本次职责                                                            |
| -------------------------- | ------------------------------------------------------------------- |
| `environments/builtins.py` | 固定系统能力标识、用途和模式；读取本地就绪依据，不创建沙箱          |
| `environments/profiles.py` | 沿用 WorkspaceProfile；统一列出系统与当前账号的工作区，保护系统定义 |
| `capability_catalog`       | 合并内置工作区、Skill 和 MCP 的搜索、计数、分页与状态               |
| 员工装配                   | 继续保存 AgentToolGrant；每位员工最多启用一种工作区模式             |
| `scripts/init_sandbox.py`  | 配套同机部署显式初始化；持久保存两端一致的密钥，不启动服务          |

Agent、execution、files 沿用现有工具调用、授权、状态和成果交付链路。系统定义保护由后端执行，界面同时移除编辑和删除入口。

## 发布与兼容

正式迁移 `0025` 添加两项无个人归属的工作区：文件读写与文本成果、代码执行。固定标识与历史目录冻结在迁移中，不依赖后续应用模块；支持离线 SQL 和重复升级。旧连接、同名自定义配置及员工授权不被替换。新部署不需先建管理员再生成工具。

前端复用现有能力卡片、工具详情和员工装配。首次选择原生能力时预选常用工具供确认，不默认选择删除。代码执行包含文件操作，和虚拟模式不能同时启用。代码环境未就绪时保持可见并说明原因，新增装配不可选；就绪展示不代替远端实时可达或真实运行验收。

配套初始化命令首次生成随机密钥并保存到私有服务配置和应用 `.env`。重复运行保持原值；已有外部服务地址或两端密钥不一致时停止，不自行覆盖。配置目录 0700、文件 0600，不输出密钥。构建和应用启动不生成或轮换密钥；已有服务仍由部署者提供其凭据。具体命令和更换方式只在部署指南维护。

迁移可能已有员工引用，不提供有损降级；按部署指南备份并同批发布前后端。本机实际运行库已从 `0024` 升级到 `0025`；执行前通过 SQLite backup 保存一致性副本，迁移后仅连接数量由 2 增至 4，用户、员工、技能、MCP 服务、员工许可、对话、消息和 Run 数量均与迁移前一致，外键检查无错误。已在当前应用的能力库确认两项系统能力实际显示。未生成实际部署密钥或启动真实沙箱。

## 验证

离线用例覆盖新部署目录、搜索分页、系统定义保护、既有许可与回滚、虚拟模式实际交付、密钥持久与权限、外部配置拒绝覆盖。迁移用例覆盖同名历史配置保留、重复升级、离线 SQL、外键和模式检查。

前端覆盖系统只读展示、待配置能力不可选、原生工具预选供确认以及原有 MCP 流程。浏览器使用独立临时数据库核对空白部署的两项能力和只读详情；不使用业务库或真实上游。

实际结果：后端全量回归 1122 项通过（265.28 秒）；之后补充的迁移保留和系统工作区交付用例，与相关定向用例共 19 项通过。前端 97 个测试文件、713 项通过，生产构建通过；Python 静态检查、格式检查、49 个源文件的类型检查及改动前端文件的 ESLint 通过。文档 73 篇、1006 个本地链接检查无错误。浏览器核对桌面以及 390px 日间、320px 夜间布局，预览服务已停止。

常规 `make` 检查在本环境受到 uv 缓存权限和联网构建依赖限制，实际改用已有 `.venv` 内的相同工具执行。需要本机端口的后端测试在允许回环假服务的环境完成。上述限制没有通过删除检查或替换生产逻辑绕过。

目标 Linux 的容器隔离、资源限制、网络、脚本执行和远端回收仍未覆盖，不能以离线通过宣称沙箱已就绪。
