# 组件与反馈

基础控件统一复用正式实现，业务组件通过明确的数据和操作组合它们。尺寸、颜色和圆角以主题与组件源码为准，本文保留影响交互判断的规则。

## 文字与排版

页面标题、区块标题、字段、正文和辅助说明使用已有文字角色。名称说明对象，状态描述事实，按钮说明动作；不靠加粗和额外标题弥补层级混乱。长名称应能截断或换行并保留必要识别信息，完整数值查阅[规范定义](../../frontend/src/design-system/spec.ts)。

## 输入与操作

按钮、输入、选择、导航和浮层通过[基础控件](../../frontend/src/components/ui)复用交互。表单焦点由字段容器统一承接，组合输入不重复描边；焦点与弹层不能被外层裁切。错误关联到具体字段或操作，失败保留可恢复输入。

标签切换展示内容，筛选改变查询，链接负责导航，提交负责写入。批量操作明确选择范围，分页与搜索不暗中丢弃选择。业务资格由状态所有者提供，禁用外观不替代后端校验。

## 加载反馈

[加载组件](../../frontend/src/components/common/LoadingFeedback.tsx)与[延迟策略](../../frontend/src/hooks/useDelayedPending.ts)仅提供反馈，不发请求或拥有数据。

| 阶段               | 所有者与反馈                                                             |
| ------------------ | ------------------------------------------------------------------------ |
| 路由加载           | 外壳保留现有页面，延迟显示顶栏进度，不伪造百分比                         |
| 直接访问与身份确认 | 使用中性骨架，身份确认前不挂载业务数据范围                               |
| 页面首次读取       | 页面延迟显示贴合真实内容的骨架，确认空结果后才展示空态                   |
| 已有内容刷新       | 原所有者保留可用内容，区域或刷新按钮反馈等待；失败保留内容并说明恢复方式 |

视觉等待统一延迟 200 毫秒；操作资格与忙碌状态立即更新。结束或卸载清理计时器，迟到请求由原数据层判断。减少动态效果时使用静止反馈，读屏保留状态说明。保存、上传、连接测试和智能体执行仍表达各自操作进度，不机械替换为通用加载。

## 对象身份

员工、技能、工具、知识和执行记录使用各自名称与状态。头像和图标帮助识别，不替代名称。资源摘要只使用已确认计数，不把缺失数据展示为零，也不将摘要当作完整详情。

## 动作与生效时机

页面编辑先进入本地草稿，保存后使用服务端确认结果；弹层完成是否提交，由该业务明确。收藏等临时反馈与已确认记录分开，冲突保留输入，不能用成功提示掩盖尚未确认的提交。

## 危险操作确认

确认中说明对象、影响和可恢复条件。停用与永久删除使用不同动作名称；等待期间防止重复提交，失败保留原因。具体删除资格、引用保护和保留规则归所属业务，不在组件层另建一套判断。

## 接入与验证

跨页面复用真实组件及其状态，单页私有组合留在页面内。视觉值来自[主题](../../frontend/src/design-system/theme.css)，交互基于[基础库适配](../../frontend/src/components/ui)；修改后核对键盘、焦点恢复、日夜、长内容和窄空间，不复制组件属性表到文档。
