# 工作台共享数据 Provider 验收

日期：2026-10-30。范围：当前本地工作区的前端共享数据、员工状态操作、导航、技能写入及能力目录；仓库尚无 Git 提交，以相邻实现和测试作为复现入口。设计见[方案](../proposals/workspace-shared-data.md)，当前接入方式见[共享数据标准](../../frontend/src/state/README.md)。

## 实现与清理

采用 React Context 提供固定 WorkspaceData 实例，普通 TypeScript 数据模块持有数据和操作，useSyncExternalStore 按记录及查询订阅。员工摘要、目录 ID、收藏列表和提交锁统一进入 AgentStore；技能保存、导入、安装及目录同步进入 SkillStore。Resource 统一去重、取消、错误、保留内容的刷新、缓存和订阅生命周期。Provider 按身份、会话及权限隔离，跨业务的更新关系集中在 WorkspaceData。

删除原配置/导航失效版本广播、独立导航请求拼装，以及未路由的旧 SkillsPage 目录和 useSkillDirectory；技能编辑归 SkillEditorPage。员工编辑不再因搜索技能而重读完整员工，删除入口不再保留无用的多资源分支。全局搜索链接改为现行技能详情路由。

## 浏览器验证与限制

独立 Vite 端口 3001 配合仅监听本机 18081 的内存接口，使用三位虚构员工，列表延迟 1.5 秒、PATCH 延迟 2 秒。验证收藏立即切换且只锁当前员工、成功后侧栏与目录同步；模拟服务端已提交但返回 503，首次核对再失败，卡片出现“重新核对”，再次 GET 后正确恢复已保存状态并解锁。收藏筛选确认后移除卡片，刷新保留已有内容，页面内部导航后复用共享结果。搜索读取失败仍保留卡片和错误提示，清空条件后恢复缓存结果。验证后关闭本轮预览进程。

未修改真实业务库。接口使用离线替身和内存模拟，本次不证明真实后端持久化、授权或多客户端竞争；未修改后端 API 与数据库契约。未覆盖 Safari、Firefox、触屏实机或完整尺寸矩阵。共享范围为当前工作台，浏览器刷新重新读取，跨标签页及其他客户端没有新增实时推送。
