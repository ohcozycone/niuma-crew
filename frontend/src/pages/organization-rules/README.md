# 全员规范管理

管理员在 `/rules` 维护所有员工自动继承的 Markdown 工作规范。入口位于侧栏管理区域，与个人知识资料分开；旧知识库制度链接按权限兼容跳转。

`OrganizationRulesPage` 负责独立加载、按身份恢复草稿、版本冲突、明确保存和离页保护。页头右侧是主保存：无修改显示“已保存”并禁用，修改后显示“保存规范”，请求中显示“保存中…”。保存不会修改已提交任务的快照。员工页的继承摘要继续由共享 organization-rules 组件提供。

协议、权限、生效时机与限制见[全员规范契约](../../../../docs/reference/organization-rules.md)。[页面测试](OrganizationRulesPage.test.tsx)验证权限拒绝、修订提交和保存状态；旧链接兼容由知识页流程测试覆盖。
