# 下拉选择统一入口验收

日期：2026-10-31。范围：本次工作区前端 React 页面及共享组件；依据[增量方案](../proposals/unified-select.md)，现行规则见[输入、选择与反馈](../../frontend/src/design-system/components.md#输入选择与反馈)。

## 盘点与迁移

盘点 29 处 Select/SelectField 选择入口，全部迁移到单一 SelectField 配置入口。迁移前已共用 Base UI 底层，重复主要是页面拼装触发器/弹层/选项，以及 items 与 SelectItem 各维护一份选项。

| 入口                                                               | 数量 | 保持的行为                                                                           |
| ------------------------------------------------------------------ | ---- | ------------------------------------------------------------------------------------ |
| 员工目录（管理员岗位、其他身份状态/岗位）                          | 3    | URL 条件、分页复位、岗位图标及搜索防抖                                               |
| 员工编辑（岗位分类、模型连接）                                     | 2    | 岗位草稿，模型加载/刷新失败保留原值，失效或非对话连接禁用及反馈                      |
| 能力库、共享技能集合                                               | 2    | 能力类型与技能分类、既有筛选回调                                                     |
| 模型连接管理、知识检索、向量设置、处理预览文件                     | 4    | 预设选择与编辑禁用，向量未就绪禁用检索，连接名称与模型标识分别显示，文件预览失效逻辑 |
| 工具接入/账号配置、本人账号绑定、装配账号模式                      | 9    | HTTP/stdio 条件选项、账号权限、凭证输入切换与清空、连接切换确认                      |
| React 设计展示（基础组件、MCP 管理、模拟调用、能力演示、错误演示） | 9    | 本地演示与正式组件复用；基础样板展示 icon 配置                                       |

SelectField 统一生成触发器、选项和弹层，options 只声明一次；移除旧 option 子节点解析。图标、已选文字、宽度/尺寸及必要定位均通过同一入口配置。FormField 只识别完整选择组件，保留自动标签、说明和错误关联；表单隐藏值与键盘交互继续由 Base UI 提供。

操作菜单、主题单选菜单、Tabs 及不进入 React 构建的只读布局研究 HTML 保持各自语义，不计为表单下拉选框。底层 Select.tsx 作为共享 UI 内部实现保留，不是第二个业务入口。

## 可执行约束与验证

ESLint 的依赖边界阻止页面、设计展示及共享业务层直接导入/重新导出/动态导入内部 Select，覆盖别名和相对路径。原生 select/option JSX 由现有语法限制检查。配置测试覆盖允许的 SelectField 与内部适配，以及违规引用和标签。

共享选择组件的定向验证覆盖前置图标、短已选文字、标签/说明/错误关联、required、触发器 ref、表单值、空字符串选项、动态选项与禁用状态、键盘打开/移动/拒绝禁用项/选择，以及禁用整个字段。Base UI 允许键盘聚焦禁用选项以读取说明，但不会选中；沿用库语义。员工模型、知识、工具与账号页面使用现有回归核对业务边界。

## 展开位置修正

同日根据用户截图复核：上一轮统一了调用入口，但仍沿用 `alignItemWithTrigger=true` 的已选项重叠定位，因此弹层会遮挡触发器文字。将共享 SelectContent 的默认值改为 `align="start"`、`alignItemWithTrigger=false`，已有 4px 间距开始生效；同时删除员工模型字段中与共享默认重复的定位设置。生效规则已合入设计系统。

本机游客员工目录实测：触发器底部 194.80px，弹层顶部 199px，间距约 4.20px，矩形不重叠；展开后当前值与箭头完整可见，弹层与触发器宽度一致。管理员前置图标使用同一组件，图标/标签关系继续由共享测试覆盖，本轮未登录管理员进行浏览器核验。

本次 33 项定向回归、`make lint-frontend`、生产构建和文档检查均通过；构建保留大分包提示。工作区先前的临时文件/索引问题已不再阻断当前检查。仅修改定位默认，未重跑全量业务测试；碰撞翻转、窄屏及其他浏览器仍未在本轮实测。
