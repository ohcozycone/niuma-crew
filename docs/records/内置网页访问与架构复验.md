## 实施结果

- 员工只有一个 `allow_web_access`，默认 false，严格布尔 API、统一保存与修订校验。公开摘要只表达许可，不伪造供应商连接或就绪状态。
- `runtime/tools/web.py` 提供 Bocha `web_search` 和 Jina `web_fetch`；配置与 URL 策略分别归 web_config 和 web_policy。MCP 按需发现不负责装配这两项内置工具。
- 请求有独立超时、响应字节上限、正文字符上限，无自动重试或重定向；搜索摘要与网页正文分开。政策拦截的搜索结果单独计数，不能当作无搜索命中。
- 每次真实外部调用前后、缓存结果复用与同一 Run 恢复时检查当前许可。撤权后新一轮可继续普通聊天，但不继承已撤销的原始网页工具上下文。Web 运行不发布未经最终授权的失败部分正文。
- 长网页结果沿用既有归档与字符分页，web-only 员工也能读到单行 JSON 的后半段，不需要装配 MCP。
- 数据库仅新增 `0029` 向量任务/缓存表与 `0030` 员工默认关闭字段；不重置原数据、不转换历史执行快照、不自动变更旧 MCP 配置。部署前仍应备份并按正常迁移流程升级。

## 验证范围

全部供应商调用使用假 HTTP 与假 DNS，模型使用替身。覆盖成功、空结果、非法响应、目标失败、429、超时、响应超限、取消、混合大小写 URL、私网/凭据/令牌拒绝、调用中数据库撤权、已完成动作复用、长页末尾读取和同一 Run SQLite checkpoint 恢复后撤权。旧 v8 恢复样本先执行新增表结构迁移，并验证历史快照 JSON 原字节不变。

前端完成员工权限、向量进度/取消/重试和跨页签轮询的组件/API/store 测试，以及 ESLint、TypeScript、格式与生产构建。员工开关另在隔离环境核对桌面及 320/390px 界面。完整命令与当次计数以交付时运行日志为准，不用历史通过数替代当前结果。
