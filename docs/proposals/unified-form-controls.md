# 表单控件与主题焦点统一

设计状态：已采纳。实施状态：已实现。更新日期：2026-10-31。

以 [shadcn Field](https://ui.shadcn.com/docs/components/base/field) 的标签、控件、说明、错误组合为基线，沿用现有 Base UI 和 shadcn 输入适配，统一全站功能表单与搜索的聚焦反馈。

1. `Field` 提供通用字段视觉，`FormField` 复用其组成部分并保留现有 ID、说明和错误关联；不新增表单状态库或改变提交协议。
2. 输入、文本域、选择框默认边框沿用 shadcn 浅灰（日间 #e5e5e5、夜间白色 15% 透明度），聚焦时沿用中性灰边框和 3px、50% 透明度外圈；8px 普通圆角不套工程超椭圆。错误字段保留红色边框及 20% 外圈。
3. 全局键盘轮廓作为其他交互的兜底，不叠加到已有焦点样式的输入控件。输入组由外层承接焦点，内部控件不重复画圈，业务页不再覆盖焦点。
4. 登录保留现有品牌布局和底线输入结构，复用同一焦点颜色与外圈；禁用、移动输入字号和提交逻辑保持现有契约。

现行规则已回写[组件规范](../../frontend/src/design-system/components.md)、[颜色规范](../../frontend/src/design-system/colors.md)与真实组件样板。检查标签/说明/错误关联、表单值、Select 键盘与弹层、输入组和登录，覆盖日夜与窄屏；实际结果见[验收记录](../records/unified-form-controls.md)。
