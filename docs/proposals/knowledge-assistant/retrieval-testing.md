# 知识库检索测试与配置入口

状态：已实施。用户确认“大脑”面向数字员工，向量模型在知识库单独配置。

- 大脑页面只展示、创建对话连接；知识库的“检索设置”弹窗管理向量连接和索引。底层复用连接与加密凭证服务，保留已有连接，不迁移或重复保存 Key。
- 测试页优先展示检索方式、问题与命中片段。向量索引未就绪时保留 BM25，向量和混合选项不可用，并给出配置入口。
- 混合检索在同一库与同一读取快照中取 BM25、向量各前 30 个候选，按 RRF（k=60）合并去重，分数相同时按片段 ID 排序。最多返回请求指定的 20 条，默认 6 条；不生成回答。
- 模型设置仍仅管理员可写；成员只能选择已启用的向量连接。构建期间保护弹窗和页面离开，失败保留原索引。

验收覆盖入口隔离、密钥保存、弹窗开合、未配置降级、混合排序及已有隔离/失效校验。正式规则回写现行契约，实际证据见[验收记录](../../records/knowledge-retrieval-testing.md)。
