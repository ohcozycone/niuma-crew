# 搜索输入防抖增量

设计状态：已采纳。实施状态：已实施。更新日期：2026-10-31。

生效规则见[输入、选择与反馈](../../frontend/src/design-system/components.md#输入选择与反馈)，输入盘点与实际验证见[验收记录](../records/input-debounce.md)。本轮无剩余实施项。

## 目标与范围

实施前，员工目录、能力库及员工技能候选随每次输入请求服务器；全局搜索单独等待 150ms。统一为输入停止 300ms 后提交查询，保留输入即时回显、当前结果和已有请求取消/隔离能力。

共享 SearchInput 显式开启防抖，不改变基础 Input 或所有搜索的默认行为。清空和非输入法确认的 Enter 立即提交；组词期间暂停提交，确认后重新计时。外部查询值变化、禁用和卸载取消待提交内容；URL 仍只保存已提交查询，目录提交查询时沿用原有分页归零逻辑。

知识库、文档、模型连接、工具候选和已装配能力只在本地筛选，无需延迟。知识检索、登录、对话、配置表单、导入与切片预览由明确提交/预览动作请求，不增加输入防抖。

## 实施与验收

1. 提供共享防抖输入行为，由 SearchInput 接入；全局搜索复用同一控件，移除重复计时。
2. 仅在实际远程搜索入口启用，搜索条件与分页仍在原所有者中更新。
3. 用虚拟时钟验证连续输入只提交最终值、中文组词、清空、Enter、外部值同步、禁用与卸载；用目录/能力库/技能候选集成验证请求参数和分页。
4. 更新前端工程手册的现行接入规则，实际检查写入验收记录。

不修改后端接口、写入触发方式或请求缓存策略；防抖只合并尚未发送的输入，已发送请求继续由原数据层管理。
