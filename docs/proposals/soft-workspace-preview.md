# 柔和工作台与紧凑卡片试版

设计状态：已采纳试做方向，视觉效果待用户反馈。实施状态：已实现共享外壳、主题、标题和紧凑员工卡片，视觉效果待用户反馈。更新日期：2026-11-01。

## 需求与范围

用户要求先实现一版可直接查看的界面，同时保留本轮前完整设计存档，满意与否由用户体验后决定。目标为统一工作底色、右侧淡色圆角工作区，以及更轻的标题、导航和卡片排版。保留现有暖灰主题、牛马角色、业务内容、权限和所有操作。

## 实施增量

1. 共享外壳在桌面使用微间距、细边界与圆角承托右侧主工作区，顶栏与内容共用表面；移动端回到全宽，保留抽屉导航和滚动所有权。
2. 调整日夜语义背景与导航选中配对，减少橙色大面积填充；主操作、收藏和状态继续各自表达真实含义。
3. 页面与卡片标题适度收小，取消功能页标题装饰；正文保持14px，基础控件及触屏命中区保持原有预算。
4. 员工卡片使用更紧凑的人物构图与内容留白，头像、道具完整展示；卡片表面减少默认阴影，配置预览和设计目录消费同一正式组件。

## 用户反馈后的细节修正

2026-11-01继续实施：主外框保留1px，使用独立较弱边界颜色；恢复header下方分隔线；raised资源卡片与surface工作区使用轻微底色差。收藏员工不保留点击选中展示，编辑按钮和竖线只在鼠标hover时同时显示，键盘直接聚焦编辑链接时保留该入口的可见焦点，无hover设备保留触屏操作入口。实际对照与验收见[试版验收](../records/soft-workspace-preview.md)。
